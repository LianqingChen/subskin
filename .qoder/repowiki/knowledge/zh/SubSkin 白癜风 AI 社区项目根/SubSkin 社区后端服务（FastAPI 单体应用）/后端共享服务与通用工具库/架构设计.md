本模块按职责划分为 services/ 与 utils/ 两个并列子包，被 web/backend 下的路由层按需导入：
- services/ 以领域服务为中心，每个文件对应一个业务能力：auth.py / admin_auth.py / wechat_auth.py / alipay_auth.py / unified_auth.py 构成统一认证体系，unified_auth 作为 HTTP Bearer 入口委托 auth.py 的 JWT 实现；vasi*.py 系列通过 vasi.py 的 VASIService 编排预处理、质量检查、VLM+SAM 分割、公式计算等步骤，并依赖 vasi_segmentation / vasi_quality / vasi_formula / vasi_preprocess 等子模块；vector_store.py 定义 VectorStore 抽象基类，提供 SQLite/PgVector/Qdrant 三种后端并通过 get_vector_store 按环境变量切换；rag.py、medical/*、im_*、email_service、sms、recommendation、content_generation、monitoring、audit 等各自封装独立业务域。
- utils/ 提供无状态工具函数：timeutils 集中处理 UTC 时区序列化并在应用启动时 patch FastAPI/Pydantic 编码；llm_config 根据 DASHSCOPE/VOLCENGINE/DEEPSEEK/MOONSHOT/MINIMAX/ZHIPU/OPENAI 环境变量动态选择 LLM 提供商；redact 对手机号/邮箱/姓名/IP 做脱敏；cursor 提供 base64 游标分页；client_ip、uid 提供辅助能力。
- 依赖方向单向：services 可引用 utils，utils 不反向依赖 services；所有持久化访问通过 SQLAlchemy Session（web.backend.database）完成，外部 AI 调用通过 openai 客户端或 httpx 发起。
