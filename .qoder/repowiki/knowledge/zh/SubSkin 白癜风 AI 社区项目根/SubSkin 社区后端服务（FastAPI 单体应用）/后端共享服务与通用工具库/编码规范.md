- 外部可选依赖（如 VasiImagePreprocessor、nnUNetSegmentationService、qdrant_client）采用 try/except ImportError 延迟导入并以 None 降级，保证核心流程在无依赖时仍可运行。
- 敏感配置（SECRET_KEY、各 LLM API Key、BASE_URL、模型名）一律从 os.environ 读取，不提供硬编码默认值，便于多环境部署。
- 数据库访问统一通过 web.backend.database.get_db 注入的 SQLAlchemy Session 完成，避免直接创建连接。
- 对外返回的 datetime 统一经 utils.timeutils.iso_utc 或 patch_datetime_serialization 处理，确保输出带 +00:00 时区后缀。
- 用户输入校验失败时抛出领域异常（如 VASIAssessmentError）而非裸 ValueError，便于上层统一捕获并转为 HTTP 响应。
- 向量存储通过抽象基类 VectorStore + 工厂函数 get_vector_store 按环境变量切换后端，新增实现只需继承基类并注册到工厂。
