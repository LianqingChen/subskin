- 每个业务实体采用 Base/Create/Update/Response 分层命名：`*Base` 定义必填字段，`*Create` 继承 Base 补充写入字段，`*Update` 全部可选，`*Response` 增加 id/时间戳等只读字段。
- 所有从 ORM 对象序列化的 Response 模型都在内部 `class Config` 中设置 `from_attributes = True`，以便直接从 SQLAlchemy 实例构造。
- 字符串字段统一通过 `pydantic.Field` 指定 `pattern`、`min_length`、`max_length`、`ge/le` 等校验规则，并在 `description` 中注明枚举取值范围。
- 需要扩展数据库结构的模块都提供 `ensure_*_columns()` 函数，使用 `inspect(engine).get_columns()` 检测现有列后通过 `ALTER TABLE ADD COLUMN` 增量添加，保证多次调用安全。
- SQLAlchemy 模型通过 `relationship` 显式声明外键关系，并使用 `backref`/`back_populates` 建立双向导航，主键一律命名为 `id` 并加索引。
