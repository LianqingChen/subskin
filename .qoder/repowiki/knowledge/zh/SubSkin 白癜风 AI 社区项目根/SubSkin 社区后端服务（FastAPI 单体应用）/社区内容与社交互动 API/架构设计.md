模块由多个独立的 FastAPI `APIRouter` 组成，每个文件对应一个业务域：`community.py`（帖子 CRUD、标签、分类、收藏集、图片/音频/文件上传、IP 地理定位）、`content.py`（文档列表、每日简报、研究时间线）、`comment.py` 与 `comment_admin.py`（普通评论与管理员审核）、`social.py`（关注/取关、拉黑/取消、举报、公开主页）、`events.py`（用户行为事件埋点）、`moderation.py`（AI 自动审核结果的人工复核与违规处罚）、`notifications.py`（系统通知创建与查询）。路由层仅做参数校验、鉴权（`Depends(auth)` / `get_current_user_optional` / `get_admin_user`）、限流（`ReadRateLimit`、`limit_write_for_user`）和审计日志记录，核心业务逻辑委托给 `web.backend.services.*` 中的 Service 层（如 `CommunityService`、`RecommendationService`、`AuditLogService`），数据库访问通过 SQLAlchemy ORM 模型（`web.backend.database.models`）完成。跨模块协作通过函数调用实现，例如点赞/评论后调用 `notifications.create_notification` 生成通知，发帖后异步线程触发 `content_safety.moderate_post` 进行内容安全审核。
