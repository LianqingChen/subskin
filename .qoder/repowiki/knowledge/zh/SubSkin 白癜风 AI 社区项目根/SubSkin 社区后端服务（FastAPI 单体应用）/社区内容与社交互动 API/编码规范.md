- 每个路由文件独立定义 `router = APIRouter()`，并通过 `Depends(get_db)` 注入 SQLAlchemy Session，通过 `Depends(auth)` 或 `get_current_user_optional` 获取当前用户。
- 写操作统一先调用 `await limit_write_for_user(request, current_user.id)` 或 `ReadRateLimit()` 进行限流，再执行业务逻辑。
- 关键用户行为（发帖、删帖、收藏、关注等）通过 `AuditLogService(db).create_log(...)` 记录审计日志，失败时捕获异常并 warn 而非中断流程。
- 业务逻辑集中在 `web.backend.services.*` 的 Service 类中，路由层仅负责参数解析、鉴权、异常转换（`ValueError`→404、`PermissionError`→403）和模型转换。
- 跨模块副作用（通知、内容审核）通过函数调用或后台线程触发，且全部用 try/except 包裹并记录 warning，保证主流程不因副作用失败而中断。
- 管理员接口统一在路由内检查 `current_user.is_admin`，不满足权限直接抛出 `HTTPException(403, "需要管理员权限")`。
