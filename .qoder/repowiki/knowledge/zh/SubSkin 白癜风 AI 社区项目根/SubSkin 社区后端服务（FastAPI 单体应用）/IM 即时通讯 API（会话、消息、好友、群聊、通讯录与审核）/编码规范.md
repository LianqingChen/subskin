- 每个路由文件定义一个 `APIRouter(prefix="/api/im/<domain>", tags=["... "])`，并以同名字段声明请求体 Pydantic 模型（如 `CreatePrivateConvRequest`、`SendMessageRequest`）。
- 所有需要鉴权的路由统一使用 `current_user: User = Depends(auth)` 注入当前用户，并通过 `HTTPException(status_code=4xx, detail=...)` 返回错误。
- 涉及跨表或事务的业务逻辑封装在 `ImService(db)` 中，路由层仅负责参数校验、权限检查和异常转换。
- 数据库查询失败或业务约束违反时抛出 `ValueError`，由路由层统一捕获并转为 400/403 HTTP 异常。
- 敏感或可选字段使用 `Optional[...]` 标注，时间字段统一通过 `iso_utc()` 转换为 ISO 字符串返回。
