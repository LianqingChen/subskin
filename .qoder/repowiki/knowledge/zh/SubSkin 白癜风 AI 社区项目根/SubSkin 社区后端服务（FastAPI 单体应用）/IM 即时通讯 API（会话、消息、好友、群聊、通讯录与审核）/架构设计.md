模块由 7 个独立的 FastAPI `APIRouter` 文件组成，每个文件对应一个业务域（conversations、messages、friends、groups、share、contacts、admin），统一挂载到 `/api/im/*` 前缀下。所有路由通过 `Depends(auth)` 获取当前用户、`Depends(get_db)` 注入 SQLAlchemy Session，遵循“路由层薄 + 服务层厚”的分层：普通读写直接操作数据库模型（如 `ImConversationMember`、`User`、`ImFriendRequest`），复杂业务则委托给 `web.backend.services.im_service.ImService`；权限校验在路由层完成（如群聊 owner/admin 角色检查、帖子分享私密性检查、管理员 `is_admin` 判断）。依赖方向单向向下：router → services/auth → database/models，不反向依赖上层。
