应用以 `app/main.py` 为唯一启动点：加载 `.env`、创建 SQLAlchemy 引擎并 `Base.metadata.create_all`，随后在 `lifespan` 中启动临时文件清理与刷新令牌清理的后台任务；所有业务 API 均通过 `include_router` 按 `/api/*` 前缀集中挂载到同一个 FastAPI 实例，WebSocket `/ws/chat` 由同一进程承载。各子模块（user_auth_oauth、community_content、im_messaging、vasi_assessment、medical_domain、knowledge_rag、admin_analytics_llm 等）仅暴露独立的 `router`，不持有状态，依赖 `database_and_migrations` 提供的 ORM 模型与连接池，并通过 `shared_services` 中的认证、RAG、向量存储、LLM 配置、监控等能力完成跨域协作；Alembic 迁移与启动期 `ensure_*_columns` 脚本共同保证 schema 演进。
