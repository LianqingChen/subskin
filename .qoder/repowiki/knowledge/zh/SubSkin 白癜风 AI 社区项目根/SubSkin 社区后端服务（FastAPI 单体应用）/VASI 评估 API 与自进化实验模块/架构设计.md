模块由两部分组成：
- `web/backend/api/vasi.py`：基于 FastAPI `APIRouter` 暴露 REST 端点，统一通过 `Depends(get_current_user)` / `get_current_admin_user` 鉴权，并通过 `VASIService(db)` 委托业务逻辑；请求体使用 Pydantic 模型（如 `PromptableClickRequest`、`ContourSubmitRequest`、`AdminAssessmentListResponse`）校验；响应经 `VASIAssessmentResponse` 等序列化；图片质量检查、promptable 交互、轮廓修正等重计算路径通过 `asyncio.to_thread` 放入线程池执行，避免阻塞事件循环。
- `web/backend/experiments/`：实验性自进化子系统，默认全部禁用（各模块顶层 `get_*` 工厂函数直接返回 `None`，并由 `_require_evolution_service` 在调用处抛出 503）。内部按职责分层：`vasi_rl_optimizer.py` 实现纯 NumPy 的 Contextual Bandit 策略网络（16D 图像特征 → 24D 输入 → 2 层 MLP → 预测 Dice），`vasi_prompt_evolver.py` 从用户修正样本中选择 few-shot 示例并组装三段式 prompt（System/Few-shot/Task），`vasi_evolution.py` 的 `EvolutionOrchestrator` 作为中央编排器串联 FeedbackCollector → PromptEvolver → ParameterOptimizer → Evaluator，并提供 `evolve` / `scheduled_evolution` / `rollback` 等生命周期方法。
依赖方向单向：API 层 → `services.vasi*` → experiments 子模块；experiments 之间仅通过 `EvolutionOrchestrator._load_modules` 延迟 import 耦合，避免冷启动开销。所有持久化状态（RL 权重、训练缓冲）落盘到 `/root/subskin/data/rl_state` 下的 JSON/JSONL 文件。
