- API 路由统一通过 `Depends(get_current_user)` 或 `Depends(get_current_admin_user)` 注入当前用户，再构造 `VASIService(db)` 执行业务逻辑。
- 请求体使用 Pydantic `BaseModel` 定义（如 `PromptablePoint`、`RefineCircleRequest`、`BatchDeleteRequest`），并在 handler 中直接解包为 typed 对象。
- 对可能缺失的实验能力统一通过 `_require_evolution_service` 守卫，缺失时返回 HTTP 503 而非抛出 `AttributeError`。
- 耗时计算（promptable 分割、点击预测、圈选精修、图片质量检查）通过 `asyncio.to_thread` 包装同步调用，避免阻塞异步事件循环。
- 实验模块对外暴露 `get_*` 工厂函数，当前实现直接返回 `None` 以全局禁用该能力，调用方通过返回值判断是否可用。
- Prompt 文本拼接前对来自用户输入的字段调用 `_sanitize_correction_text` 进行 prompt 注入过滤，防止 few-shot 上下文被劫持。
