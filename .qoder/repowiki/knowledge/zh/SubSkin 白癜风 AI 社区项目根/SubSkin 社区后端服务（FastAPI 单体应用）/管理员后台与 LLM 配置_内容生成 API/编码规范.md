- 所有管理员端点通过 `Depends(get_admin_user)` 或显式检查 `current_user.is_admin` 进行权限校验，非 admin 返回 403。
- 每个 Router 文件顶部声明 `router = APIRouter(prefix=..., tags=...)`，按功能域划分路由命名空间。
- ORM 对象到响应模型的转换统一通过独立的 `_serialize_*` 函数完成，并使用 `iso_utc` 格式化时间字段。
- Pydantic 请求/响应模型集中定义在文件内，使用 `Field(..., description=...)` 提供字段说明，复杂对象采用嵌套 BaseModel。
- 外部系统调用（systemctl、journalctl、tail、OpenAI API）均包裹 try/except 并以 HTTPException 或结构化错误字典返回。
- 敏感信息（API Key）一律通过 `mask_api_key` 掩码后返回，明文仅在内部加密存储，接口不暴露明文。
