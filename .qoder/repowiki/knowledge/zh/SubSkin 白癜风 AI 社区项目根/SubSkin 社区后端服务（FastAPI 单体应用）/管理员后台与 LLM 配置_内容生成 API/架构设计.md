本模块由五个 FastAPI Router 文件组成，均通过 `APIRouter` 定义独立路由前缀（`/api/admin`、`/api/admin/llm`、`/api/admin/content`、根级 `/logs`），按职责拆分：
- `admin_general.py`：综合管理端点，包括简报列表/触发生成、系统资源与服务状态监控（通过 `subprocess` 调用 `systemctl`/`journalctl`）、批量向量化入口。
- `analytics.py`：纯查询型分析接口，所有端点仅构造 `AnalyticsService(db)` 并转发参数，无业务逻辑。
- `audit.py`：审计日志 CRUD，使用 `auth` 依赖进行用户鉴权，并通过 `_log_to_response` 统一序列化 ORM 对象为 Pydantic 响应模型。
- `llm_config_admin.py`：LLM 模块配置的完整管理面，包含增删改查、测试连接、环境变量刷新、JSON 备份/恢复、预设模板应用与预览，密钥通过 `encrypt_api_key`/`decrypt_api_key`/`mask_api_key` 处理。
- `content_generation_admin.py`：管理员内容生成管理，草稿 CRUD + 批量操作 + 基于 OpenAI 兼容接口的 AI 辅助生成（意图理解→知识库检索→原始数据检索→百科检索→内容生成）。

依赖方向：Router → Service 层（`LLMConfigService`、`AnalyticsService`、`AuditLogService`、`generate_daily_posts`/`publish_post`）→ SQLAlchemy ORM；鉴权通过 `get_admin_user`（admin 专用）或 `auth`/`get_current_user`（普通用户）依赖注入；系统级操作通过 `subprocess` 直接调用宿主机命令。
