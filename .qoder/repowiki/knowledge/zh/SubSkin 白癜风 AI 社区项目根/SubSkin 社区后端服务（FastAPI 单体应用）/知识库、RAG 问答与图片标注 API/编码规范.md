- 所有写操作通过 `Depends(get_db)` 获取 SQLAlchemy Session，并在 commit/refresh 后返回 Pydantic response model。
- 敏感或用户输入字段统一用 Pydantic `Field(..., min_length/max_length/pattern=...)` 做服务端校验，而非依赖前端。
- 鉴权采用依赖注入模式：普通接口用 `Depends(auth)` 或 `Depends(get_current_user)`，管理员接口用 `Depends(get_current_admin_user)`。
- 文件路径权限校验集中在 `files.py` 的 `_assert_path_ownership`，按 bucket 分支判断 owner/admin/public，越权统一抛 403。
- 临时文件通过 `data/uploads/temp/<filename>.meta` 旁路文件记录所有者 user_id，读写时先校验 meta 再放行。
- 错误处理统一通过 FastAPI `HTTPException(status_code=..., detail=...)` 抛出中文消息，避免裸异常泄露。
