四个 FastAPI Router 模块各自独立注册路由：
- `encyclopedia.py`：以 `/api/encyclopedia` 前缀暴露百科文章、修订提交/审核/投票、评论树等接口，使用 Pydantic 模型做入参校验，通过 `get_db` 依赖注入 SQLAlchemy Session，并复用 `unified_auth.get_current_user` 做登录态校验。
- `rag.py`：核心聊天入口 `/ask`、`/ask-public`、`/ask-stream`、`/ask-public-stream` 等，将鉴权、访客指纹与每日配额限制、会话所有权校验、速率限制放在路由层，实际 LLM 调用、文档检索、附件分析委托给 `web.backend.services.rag` 中的函数；临时上传走 `data/uploads/temp` 目录并通过 `.meta` 文件绑定所有者。
- `image_label.py`：管理员专用的 `/admin/image-labels` 系列接口，支持分页筛选、三级标注（AI/用户/管理员）详情、批量状态更新、训练数据导出，并使用 Pillow 在服务器端合成标注预览图。
- `files.py`：统一的文件服务 `/api/files/serve/{path}`，通过短生命周期文件访问 token 与 bucket 级所有权检查（avatar/community/reports/files/im/temp/vasi）实现细粒度鉴权，并提供 PDF 分页预览与 HTML viewer。
依赖方向：router → services（业务逻辑）→ database.models（ORM），router 之间无直接耦合，仅共享 `database.database.get_db`、`services.auth` 与 `models.*`。
