- 所有模型类继承 `Base`，通过 `__tablename__` 显式指定表名，字段使用 `Column(Integer/String/Text/DateTime, ...)` 声明，主键统一为 `id = Column(Integer, primary_key=True, index=True)`。
- 时间字段统一采用 `_utcnow()` 返回 `datetime.now(timezone.utc)`，并通过 `default=_utcnow`、`onupdate=_utcnow` 自动填充创建/更新时间。
- 多对多或唯一关系通过 `__table_args__` 中的 `UniqueConstraint` 防止并发重复插入（如点赞、书签、关注、投票等），并在关联列上建立 `Index` 加速查询。
- 一对多关系使用 `relationship(..., cascade="all, delete-orphan")` 保证级联删除，外键引用通过 `ForeignKey("users.id")` 显式声明。
- Alembic 迁移文件在 SQLite 下必须使用 `with op.batch_alter_table(...) as batch_op:` 包裹 DDL 操作以兼容 SQLite 的 ALTER 限制。
- 一次性历史迁移脚本（如 `migration_auth_v2.py`）直接 import `engine`、`Base`、`SessionLocal` 并调用 `Base.metadata.create_all(bind=engine, tables=[...])` 或原生 SQL 执行，不纳入 Alembic 版本链。
