模块以 `web/backend/app/main.py` 为唯一应用入口：在模块加载阶段通过 `Base.metadata.create_all` 建表，并调用多个 `ensure_*_column` 函数对存量数据库执行幂等的 `ALTER TABLE` 增量迁移（如 `users.avatar_url`、`medical_reports.*`、VASI/feedback/image_label 表）；随后创建 `FastAPI` 实例，注册 CORS 中间件、Sentry/Prometheus 监控、LLM 配置默认值及 datetime 序列化补丁，并通过 `app.include_router` 集中挂载全部业务路由（user/content/comment/rag/oauth/community/medical-report/im_* 等）。`lifespan` 上下文管理器在启动时清理临时上传与过期 refresh token，并以后台 `asyncio.Task` 周期执行；关闭时取消任务。WebSocket 聊天通过 `@app.websocket("/ws/chat")` 路由到 `web.backend.ws.chat.chat_websocket_endpoint`，由 `ConnectionManager` 单例维护用户连接映射，按消息 type 分发 ping/read 逻辑。`web/backend/app/middleware/rate_limit.py` 提供基于进程内存的令牌桶 `RateLimiter`，暴露 `ReadRateLimit`/`WriteRateLimit`/`ChatRateLimit` 三个可复用的 FastAPI 依赖类，分别按 IP、user_id/IP、chat:user_id/IP 限流。`web/backend/sitecustomize.py` 将仓库根目录插入 `sys.path`，确保从 `web/backend` 子包运行也能解析顶层 `web.backend.*` 导入。`web/backend/exceptions.py` 定义领域异常基类 `SubSkinException` 及凭证相关子类，供服务层抛出并由 API 层统一转换为 HTTP 响应。
