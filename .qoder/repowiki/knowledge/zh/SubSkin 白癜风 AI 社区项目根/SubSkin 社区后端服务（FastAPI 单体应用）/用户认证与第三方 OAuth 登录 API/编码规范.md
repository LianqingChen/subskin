- 所有需要鉴权的端点通过 `current_user: DBUser = Depends(auth)` 或 `get_current_user_optional` 注入当前用户，未认证请求抛出 401/403。
- 登录成功后的统一响应通过 `_login_response(user, db)` 构造，包含 access_token、refresh_token、token_type 和用户信息。
- 用户字段从 UserCredential 表同步到 User 模型时使用 `_sync_legacy_user_fields(db, user)`，随后 `db.commit()` + `db.refresh(user)` 保证一致性。
- 敏感操作（手机号/邮箱修改）强制走独立绑定接口并通过验证码校验，禁止在通用 `/me` 更新中直接修改 phone/email。
- HTTP 异常统一使用 `fastapi.status.HTTPException` 并附带中文 detail 消息，错误码遵循 REST 规范（400/401/403/404/429/500）。
- 异步后台任务（如内容安全审核）通过 `threading.Thread(daemon=True)` 启动，避免阻塞主请求流程。
