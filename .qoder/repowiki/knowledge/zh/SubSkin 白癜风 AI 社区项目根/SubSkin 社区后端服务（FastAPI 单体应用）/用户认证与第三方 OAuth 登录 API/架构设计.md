本模块由四个独立的 FastAPI `APIRouter` 组成，分别暴露不同职责的 HTTP 端点：
- `user.py`：核心认证与用户管理路由（`/login`、`/register`、`/me`、`/bind-phone`、`/set-password`、`/refresh-token`、`/logout` 及管理员 `/users` 列表），通过 `Depends(auth)` / `Depends(get_current_user_optional)` 注入当前用户，依赖 `services/auth` 生成 JWT、`services/credential` 管理多凭证绑定。
- `oauth.py`：第三方 OAuth 扫码登录入口，封装微信 (`WechatAuthService`) 与支付宝 (`AlipayAuthService`) 的授权 URL 获取、回调处理、状态轮询，复用 `user._sync_legacy_user_fields` 同步历史字段并返回统一 Token。
- `wechat.py`：微信公众号 JSSDK 签名服务，缓存 access_token 与 jsapi_ticket，对外暴露 `/jssdk-config` 供前端调用。
- `consent.py`：用户同意记录（隐私政策、服务条款、AI 数据、医疗照片），提供单条与批量记录接口，版本常量集中管理。

依赖方向单向向下：API 层仅依赖 `services/*`、`database.models`、`models.user` 等子模块，不反向被 services 依赖；各 router 之间通过导入 `user._sync_legacy_user_fields` 共享登录响应构造逻辑，避免重复代码。
