本模块由五个并列的 FastAPI `APIRouter` 组成，每个文件对应一个业务子域：
- `medical_report.py`：通过 `CommunityService.upload_file` 将 PDF/图片上传至对象存储，并借助 `report_parser`、`report_interpreter`、`indicator_normalizer` 完成 OCR/文本提取、结构化指标抽取、多份报告对比及 LLM 解读；同时用 `fitz` (PyMuPDF) 将 PDF 逐页转 PNG 存入 `data/uploads/pages/{file_id}/` 供前端分页浏览。
- `patient_profile.py`：管理 `PatientProfile` CRUD，强制“本人”关系唯一性，并通过 `User.default_tracker/report/diary_profile_id` 维护各模块默认关联档案。
- `medication.py`：CRUD `MedicationReminder`，并提供 Web Push 订阅（VAPID）注册/取消与公钥获取，用于定时用药提醒推送。
- `doctor.py`：实现医生认证申请流程（含邀请码校验）、管理员审核（批准时回写 `User.is_doctor`），以及邀请码生成与管理。
- `diary.py`：支持自然语言/语音/快捷三种输入创建 `DiaryEntry`，异步调用 `services.diary_ai.extract_diary_structure` 做结构化提取，并提供日历视图、周汇总（带 LLM 摘要缓存 `_weekly_llm_cache`）与统计接口。
依赖方向单向向下：API 层仅依赖 `database.models`、`services.auth`、`services.*` 与 `utils.timeutils`，不反向被其他业务模块引用；所有路由统一通过 `Depends(get_db)` / `Depends(auth|get_current_user)` 注入会话与当前用户，并以 Pydantic 模型作为请求/响应契约。
