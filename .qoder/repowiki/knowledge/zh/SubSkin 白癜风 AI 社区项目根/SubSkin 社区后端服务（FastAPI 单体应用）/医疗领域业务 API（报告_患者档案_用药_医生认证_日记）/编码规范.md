- 每个业务文件独立定义 `router = APIRouter()`，并在文件顶部集中声明该模块的 Pydantic 请求/响应模型，再在路由函数中以 `response_model=` 标注返回类型。
- 数据访问统一通过 `Depends(get_db)` 获取 `Session`，并通过 `db.query(Model).filter(...).first()/all()` 配合 `user_id == current_user.id` 实现按用户隔离的数据查询。
- 鉴权通过 `Depends(auth)` 或 `Depends(get_current_user)` 注入 `User`，对敏感操作（如删除、管理员接口）额外使用 `_require_admin` 或直接检查 `user.is_admin`。
- 数据库写入遵循 `db.add(obj); db.commit(); db.refresh(obj)` 三段式模式，确保返回对象包含自增 ID 与时间戳。
- 可选字段在更新接口中使用 `model_dump(exclude_unset=True)` 后遍历 `setattr` 增量更新，避免覆盖未传入字段。
- JSON 数组字段（如 `reminder_times`、`proof_images`、`treatment_events_json`）在入库前 `json.dumps`、读取时 `json.loads` 转换，保持 SQLite Text 列存储。
