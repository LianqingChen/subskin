模块为独立的前端工程，入口 `src/main.ts` 通过 `createApp` 挂载 Pinia、Vue Router 和 Naive UI。
- 路由层：`src/router/index.ts` 使用 `createWebHashHistory` 定义 `/login` 与嵌套在 `Layout.vue` 下的各业务页面；通过 `meta.public` 标记公开路由，并在 `beforeEach` 守卫中强制要求 `is_admin` 才能访问。
- 状态层：`src/stores/auth.ts` 用 Pinia 管理 token、用户信息与登录/登出逻辑，token 持久化到 `localStorage('admin_token')`。
- 网络层：`src/api/request.ts` 基于 axios 创建实例，统一设置 baseURL `/api`、120s 超时、Bearer Token 注入以及 401 清理 token 的响应拦截器；`labeling.ts` 按业务域封装 API 调用。
- 标注子系统：`src/components/labeling/` 为核心标注能力，采用插件化工具架构——`BaseTool.ts` 定义 `BaseTool` 接口与 `ToolContext`，`useCanvasTools.ts` 维护工具实例注册表与生命周期（激活/停用），具体工具（BrushTool、EraserTool、FloodFillTool、LassoTool、PolygonTool）各自实现指针与键盘事件处理；`MaskEditorAdmin.vue` 作为宿主协调多 canvas（皮肤/病灶/叠加）与工具切换。
- 视图层：`src/views/` 下每个 `.vue` 对应一个路由页面，复用 `Layout.vue` 作为外壳。
- 构建与部署：`vite.config.ts` 将别名 `@` 指向 `src`，开发代理 `/api` 到 `http://127.0.0.1:8000`，生产输出到 `/usr/share/nginx/html/subskin-admin`。
