- API 调用统一通过 `src/api/request.ts` 的 axios 实例发起，所有请求自动携带 `Authorization: Bearer <token>`，错误码 401 时清除本地 token 但不自动跳转。
- Pinia store 使用 Composition API 风格（`defineStore('auth', () => {...})`），状态以 `ref`/`computed` 声明并通过对象形式返回。
- 路由采用懒加载 `() => import('@/views/xxx.vue')` 并按 `meta.public` 标记公开页面，所有非公开路由由 `beforeEach` 守卫校验 `isLoggedIn && is_admin`。
- 标注工具遵循统一的 `BaseTool` 接口与 `ToolContext` 上下文约定，新增工具只需实现 onActivate/onDeactivate/onPointerDown/Move/Up/onKeyDown/getCursor 方法，并通过 `toolInstances` 注册表暴露给 `useCanvasTools`。
- 快捷键映射集中在 `ALL_TOOLS` 与 `handleToolShortcut` 中，通过大写单键（B/L/G/S/P/E/C）与数字 1-6 两种方式切换工具，Shift+L 作为皮肤画笔快捷别名。
