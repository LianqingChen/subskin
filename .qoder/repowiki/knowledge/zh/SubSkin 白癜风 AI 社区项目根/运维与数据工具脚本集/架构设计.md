本模块为扁平的脚本目录，每个文件是一个独立可执行的 CLI 工具，按职责大致分为四类：
- 部署与配置：`deploy.sh`（阿里云 ECS 一键部署，创建 venv、安装依赖、生成 crontab）、`deploy_website.py`。
- 数据库迁移与修复：`migration_*.py`（基于 sqlite3 直接执行 DDL，如 `migration_add_collections.py`）；`fix_llm_double_encryption.py`（通过 Fernet 解密/重加密修复 LLM 模块 api_key）。
- 数据导入与飞轮：`import_to_db.py`、`import_encyclopedia_md.py`、`create_encyclopedia_posts.py`（从 VitePress Markdown 导入百科到数据库并生成社区帖子草稿）；`vasi_data_flywheel.py`（从用户修正的 VASI 评估中提取标注 mask 构建训练集）。
- 测试与诊断：`create_e2e_test_user.py`（幂等创建 E2E 专用账号及关联数据并输出 token）；`diagnose_vasi.py`、`test_vitiligo_segmentation.py`、`vlm_compare_qwen.py`、`vlm_compare_render.py`（VASI/VLM 管线诊断与对比）；`validate_data_sources.py`（校验数据源配置）；`rotate_admin_password.py`、`generate_weekly.py`、`run_crawlers.py`。

所有脚本均通过 `sys.path.insert(0, ROOT)` 将项目根加入路径后，直接 import `web.backend.database.*`、`web.backend.services.*`、`web.backend.models.*` 等内部模块，不经过 API 层，属于“旁路”操作脚本。依赖方向单向指向 `web/backend` 与 `src`，脚本之间相互独立无调用关系。
