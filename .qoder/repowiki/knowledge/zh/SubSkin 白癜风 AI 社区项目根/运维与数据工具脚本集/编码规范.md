- 脚本入口统一使用 `if __name__ == "__main__":` 或 `raise SystemExit(main())` 模式组织主逻辑。
- 通过 `sys.path.insert(0, str(ROOT))` 并将项目根设为工作目录后，再 import `web.backend.*`，避免相对导入问题。
- 数据库操作统一通过 `SessionLocal()` 获取会话，并在 `try/finally` 中确保 `db.close()`，异常分支使用 `db.rollback()` 回滚。
- 幂等性设计：涉及 upsert 的脚本（如 `create_e2e_test_user.py`、`import_to_db.py`）先查询是否存在再决定 insert/update，支持重复执行。
- CLI 脚本普遍使用 `argparse` 解析参数，并提供 `--dry-run` 选项用于预览而不写入数据。
- 敏感信息通过 `dotenv.load_dotenv` 从 `web/backend/.env` 加载，而非硬编码在脚本中。
