根目录作为 SubSkin 项目的顶层编排层：
- 通过 pyproject.toml 将 src/ 下的 web_backend、crawler_pipeline、data_processing、notifications、settings_and_utils、data_assets、scripts、tests 等子模块打包为单一 Python 包，并暴露 test/format/lint 等可执行脚本。
- Makefile 提供跨子模块的统一工作流：setup/install/dev-install 安装依赖（含 dev/web/ai extras）、test 运行 pytest（覆盖 src 与 tests）、db-init/db-migrate 驱动 Alembic 迁移、crawl-* 与 generate-weekly 触发爬虫与内容生成任务、run-dev 启动 FastAPI 服务、docs-serve/docs-build 构建 VitePress 文档站。
- scheduler_config.json 集中定义每周日凌晨 3:00 的爬取+增量向量化计划，被 cron/systemd（subskin-scheduler.service）调用 scripts/generate_weekly.py，串联 crawler_pipeline → data_processing → data_assets 的数据流水线。
- settings_and_utils 中的 Pydantic Settings + .env 是各子模块共享的配置来源；pytest.ini 与 .coveragerc 统一测试与覆盖率规则（≥67% 覆盖率要求、asyncio_mode=auto）。
- 前端 admin_interface 与 documentation_site 通过独立构建流程（Vite/VitePress）产出静态资源，由后端或部署脚本托管，形成“后端 API + 管理后台 SPA + 百科站点”的三端架构。
