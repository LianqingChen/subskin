测试目录按被测模块镜像组织：`tests/backend/` 下分 `api/` 与 `services/` 两个子包，分别对应 `web.backend.app.main` 的 HTTP 层与业务服务层；根级 `tests/*.py` 直接测试 `src.*` 下的爬虫、导出器、CLI、配置等无状态或纯函数模块。

- 三层 conftest 共享夹具：根 `conftest.py` 提供通用数据（`sample_paper`、`sample_trial`、`temp_cache_db`、`mock_api_response`）；`backend/conftest.py` 提供 SQLAlchemy 内存会话、用户/评论/SMS/文档等数据库夹具；`backend/api/conftest.py` 在此基础上叠加 FastAPI `TestClient`、依赖注入覆盖 `get_db`、以及 `auth_headers`/`admin_headers`。
- 所有后端测试通过 `SECRET_KEY`、`ALGORITHM`、`SMS_PROVIDER`、`RAG_USE_VECTOR` 等环境变量初始化，避免导入时 KeyError。
- API 测试使用 `app.dependency_overrides[get_db]` 将真实数据库替换为内存 SQLite 会话，确保请求级隔离。
- 外部依赖（OpenAI、短信发送、HTTP 请求）统一通过 `unittest.mock.patch` 或自定义 `MockAPIResponse` 拦截，不发起真实网络调用。
