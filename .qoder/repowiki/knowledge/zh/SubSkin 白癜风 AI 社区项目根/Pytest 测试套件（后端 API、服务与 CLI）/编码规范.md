- 每个被测模块在 `tests/` 下有同名 `test_*.py` 文件，保持测试与源码的一一对应关系。
- 数据库相关测试统一通过 `db_session` 夹具创建内存 SQLite 会话，并在 fixture 中完成 `Base.metadata.create_all` 建表与 `drop_all` 清理。
- 需要认证的场景通过 `auth_headers` / `admin_headers` 夹具生成 Bearer Token，而非手动拼接请求头。
- 外部服务（OpenAI、短信、HTTP）一律使用 `unittest.mock.patch` 或 `MagicMock` 进行替换，禁止在测试中发起真实网络请求。
- 测试数据通过工厂风格的 fixture（如 `test_user`、`test_comment`、`sample_paper`）集中构造，测试用例只负责断言行为。
- 涉及时间的断言使用 `datetime.utcnow()` 并允许秒级容差，避免因服务器时区差异导致测试不稳定。
