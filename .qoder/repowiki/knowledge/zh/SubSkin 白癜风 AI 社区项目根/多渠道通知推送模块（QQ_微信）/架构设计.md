模块以 `__init__.py` 统一暴露 `QQBotNotifier` 与 `WeChatNotifier` 两个对外类，内部按渠道拆分为独立文件：
- `qq_notifier.py`：基于 go-cqhttp 的 OneBot v11 HTTP API，通过 `requests.Session` 封装重试逻辑（`_make_request`），提供私聊/群消息发送；内置 `NotificationManager` 聚合 daily report / error alert / system status / custom message 四类通知，并配套 `format_*` 格式化函数；通过 `create_notifier_from_env` 从 `CQHTTP_*` 环境变量装配实例。
- `wechat_notifier.py`：主路径将格式化后的简报写入 `/root/subskin/data/briefings/daily_<date>.md` 由 Hermes cronjob 投递，回退路径直接调用 `openclaw message send` CLI；提供 `format_daily_summary`（按 S/A/B/C/D 权威分级映射数据源）与 `send_daily_summary` / `send_error_alert` 两类入口。
依赖方向单向向外：仅依赖 `src.exceptions.APIError`、`src.utils.incremental_tracker.DailySummary`、`src.utils.logger`，不反向引用上层业务，便于被调度器或爬虫任务调用。
