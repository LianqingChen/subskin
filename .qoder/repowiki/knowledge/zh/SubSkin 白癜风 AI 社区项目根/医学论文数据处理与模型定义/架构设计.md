模块由两个平行的子包组成：`src/models/` 存放所有 Pydantic `BaseModel` 实体（Paper、ClinicalTrial、DataSource 及其枚举与辅助类），作为整个项目的统一数据结构；`src/processors/` 存放面向这些模型的 AI 处理组件（Deduplicator、Summarizer、Translator），依赖方向单向从 processors → models，不反向依赖。
- 每个 processor 都是独立类，通过构造函数注入 OpenAI/Volcengine 客户端、Cache、RateLimiter 等横切能力，对外暴露单一主方法（`translate` / `summarize` / `deduplicate`）。
- `__init__.py` 统一导出公共类，形成稳定的模块 API 边界。
- 处理器通过 `src.config.settings` 自动探测 VOLCENGINE_API_KEY 或 OPENAI_API_KEY 以选择后端，对上层屏蔽具体 LLM 实现差异。
- 去重器内部按 DOI > PMID > 标题+作者哈希的优先级分组，再按 PaperSource 偏好顺序合并字段，保持 source 溯源。
