- 所有数据模型均继承自 Pydantic `BaseModel`，并通过 `Field(..., description=...)` 标注字段含义，可选字段使用 `Optional[...] = Field(None, ...)` 形式声明。
- 字符串校验统一通过 `@field_validator` 装饰的类方法实现，对 URL、DOI、日期格式等进行宽松解析与规范化后再返回。
- 每个处理器类在构造函数中通过 `src.config.settings` 自动检测 VOLCENGINE_API_KEY 优先于 OPENAI_API_KEY，未配置时抛出明确异常。
- 对外 API 调用统一采用「缓存命中 → 获取限流令牌 → 调用 LLM → 写回缓存」的顺序，缓存键通过 `hashlib.sha256` 对输入文本生成确定性 key。
- 可重试的临时错误（速率限制、超时、连接失败、5xx）被单独列出并在 retry 循环中以指数退避重试，最终失败时包装为领域异常（`SummarizerError` / `APIError`）。
- 模块级 `__init__.py` 集中 `from .xxx import ...` 并显式声明 `__all__`，仅暴露稳定公共 API。
