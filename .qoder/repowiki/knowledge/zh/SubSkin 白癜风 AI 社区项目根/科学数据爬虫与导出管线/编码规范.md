- 每个外部数据源对应一个独立的 Crawler 类，封装查询、分页、解析为统一的 `Paper`/`ClinicalTrial` 模型，并通过包的 `__init__.py` 集中 `__all__` 暴露。
- 所有网络请求统一经过 `RateLimiter` 上下文管理器限速，并以 `Cache.get/set` 配合字符串化 cache key（含 query、offset、limit 等参数）进行响应级缓存。
- 对第三方 API 调用采用指数退避重试：捕获超时、连接错误及 5xx HTTP 错误，按 `backoff_base_seconds * 2^(attempt-1)` 递增等待后重试。
- 导出器统一按 `data/exports/<YYYY-MM-DD>/` 日期目录组织输出，文件名默认使用时间戳或业务标识符拼接，并记录日志说明导出数量与路径。
- Markdown 导出为每篇论文生成独立文件，内容包含 YAML frontmatter（title/date/source/authors 等字段）以及末尾固定的免责声明引用块。
- crawler 内部使用静态辅助方法处理可选字段（如 `_safe_optional_str`、`_first_non_none`、`_normalize_authors`），保证来自不同源的异构字段能稳定映射到 `Paper` 模型。
