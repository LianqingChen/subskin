# VLM labeling — results overview

编号分区判读与本地像素融合是当前方法。多个分区密度的预测独立运行，再以像素投票生成初稿。相同输入下的判读仍会波动。固定辅助分割在多组归档对照中改善结果，边界细化和小斑候选筛选只对部分样本有收益。

早期实验包括逼近区域划分上限、同图颜色锚定、整图填充复核、跨模型投票和小斑候选。整图填充复核及简单多数模型融合出现过回归。独立验收仍需新模型回执、逐图逐层对照和人工复核证据。原始结果与私有样本信息留在服务器研究目录。
