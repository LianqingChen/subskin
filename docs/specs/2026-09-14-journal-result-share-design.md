# 手帐结果页与一体化分享设计

状态：用户已确认并授权实施；前端测试环境与共享后端已部署，合成数据验收完成。

## 目标

用户确认涂层后，先看到可信的照片记录，再看到由自己的轮廓生成的创意作品。无需选档案、主题、画幅、文案或勾选分享内容，即可完整分享到「分享」板块，也可单独保存或转发创意卡。

## 现状核对

- `AssessmentObservationResult.vue` 同时展示大标题、重复日期和部位、状态、占比公式、重复解释段落、颜色/边缘占位文字、多组操作与引导，创意卡被推到页面下方。
- `AssessmentStoryCard.vue` 包含主题选项和「调整文案、档案和分享内容」折叠块，需要用户理解并选择多个参数。
- `useAssessmentStory.ts` 调用前端 `makeStory()` 模板，当前并非大模型生成文案。
- `useStoryShare.ts` 只上传创意海报；`useVasiShare.ts` 是另一条照片/标注图分享路径，两套流程没有整合。
- 记录目前没有明确的照片所属档案关联；不能自动把当前登录人的年龄、性别套在每一张照片上。
- 现有公开发布使用 `confirmPublish`。新入口复用公开确认，自动准备内容，无需重新进入编辑器逐项组装。

## 方案比较与选择

| 方案 | 体验 | 取舍 |
| --- | --- | --- |
| A：紧凑结果＋自动创意卡＋统一分享（推荐） | 从可信记录自然过渡到作品；三个直接操作 | 同时兼顾基础记录和传播价值 |
| B：大海报优先，测量信息后置 | 第一眼视觉冲击强 | 容易掩盖记录结果与范围核对状态 |
| C：测量报告与创意海报拆为两个页面 | 每页职责单一 | 增加跳转，延续现在内容分散的问题 |

采用 A。手机单列，桌面以紧凑结果区和创意卡并排呈现；不设计冗长表单或多主题选择器。

## 页面顺序与示例

以下数值和文案仅为排版示例，不是任何真实用户的结果。

```text
本次记录                         已保存
左手 · 2026.09.14

[ 照片与用户确认的皮肤 / 白斑涂层 ]
标注 / 原图                       调整范围

照片内白斑占比                    12.4%
可见标注区域                       3 处
仅限本张照片中的可见皮肤

我的轮廓故事
[ 自动生成的轮廓艺术画面 ]
把一片晴空，轻轻握在手心。
[ SubSkin · 小二维码 ]

[          分享到分享          ]
[ 保存图片 ]          [ 更多分享 ]

继续拍                         查看记录
```

- 标题改为「本次记录」「我的轮廓故事」，手机使用 16–18px，不再用长标题和大段英文占空间。
- 海报主句最多 24 个汉字、最多两行，按实际字体测量自适配。页面栏目标题保持单行；海报短句允许有意的文学分行。
- 记录区域：日期、部位、保存状态只出现一次；占比只突出一次。去掉重复公式解释、重复保存提示、空白颜色/边缘占位项、制作海报跳转按钮和就诊评价引导卡。
- 照片以等比适配呈现，保留清楚的原图/标注切换及小型「调整范围」入口。
- 只在真实存在异常或边界未拍全时显示一行必要提示；「测量说明」作为弱入口容纳公式和依据，不占主要阅读区。
- 页面与海报各保留一处简短「照片记录仅供参考」或「创意表达」说明，避免层层重复。

## 准确性边界

1. 基础结果直接读取用户确认并保存后的后端测量快照。图、皮肤层、白斑层、统计信息与分享内容使用同一记录版本。
2. 只有已核对、测量状态允许且数值有效时显示占比；待核对、历史口径不一致或无法量化时显示相应状态，不能显示成 0%。已确认空白斑蒙层得到的有效 0% 可以显示。
3. 分母仍为照片内正常皮肤＋白斑。只展示照片内占比；没有有效标尺时不提供 cm²。不将照片结果表述为诊断、分期、严重程度或疗效。
4. 大模型只写创意内容、选择表现主题，不计算或改写测量值，也不重新绘制医学涂层。
5. 创意画面继续从确认后的二值轮廓生成，保留孔洞、各块形状和相对位置。允许画面纹理和配色变化；不增加或删除白斑区域。
6. 再次调整并保存后，旧创意和分享资源失效，只接受当前版本的生成结果。零白斑或无可用轮廓时仍提供正常的记录结果，不制造虚构轮廓。

## 自动创作

- 核对保存成功后自动发起独立的创意请求，基础结果立即可看；创意耗时或失败不影响已经完成的记录。
- 移除「调整文案、档案和分享内容」折叠块以及档案、主题、画幅、自定义短句、内容勾选控件。
- 默认生成 3:4 创意卡：轮廓画面＋一句中文主文案＋低干扰品牌/公开入口二维码。删除默认英文译文、长篇生成依据及多段鼓励性说明。
- 服务端调用项目现有的大模型配置，输入经核对的部位与轮廓描述，输出有长度限制的主题和短句。按记录版本缓存，重新打开不反复调用。
- 不自动推断照片所属人。当前没有明确档案关联时使用中性称谓，不读取全家档案供模型猜测。
- 模型不可用时诚实显示「创意暂未生成」和重试入口；可继续查看或分享基础记录。若采用模板降级，必须标明模板创意，不能冒充 AI 生成。
- 模型仅返回纯文本和限定主题值；过滤诊断、疗效保证、歧视或凭空推断身体信息的内容。

## 三个分享操作

### 分享到分享：自动合成一条完整帖子

- 自动打包：创意卡作为封面＋原图＋原图融合确认涂层的标注图。
- 帖子正文：创意短句＋一行部位/日期/照片内占比＋必要的测量限定。无大段说明，无重复文案，无填写「今日感受」的空字段。
- 用户点击后直接看到已组装内容的小型发布预览，缩略图明确显示包括原始照片，复用既有公开确认；确认后完成发布并进入帖子。无需分别分享，也无需跳去编辑页重新填文案、选图。
- 原图与涂层分享采用现有上传/发布接口，不能把需要登录才能访问的私有记录链接当成公开图片。
- 连点、失败重试和账号切换不能造成重复帖子、错用户发布或不完整素材发布。未完成公开确认时不创建公开帖子。
- 创意失败时，该按钮可以发布基础记录，预览如实展示实际包含的内容。

### 保存图片

直接保存当前创意卡 PNG，不包含原始皮肤照片或医学测量表格。保留轮廓、短句、SubSkin 小型品牌和公开首页二维码，便于二次传播。

### 更多分享

调用系统图片分享，可选择微信等系统支持的应用；浏览器不支持文件分享时回退为保存图片，明确反馈。用户主动取消不显示成功。站外图片同「保存图片」，无私有记录链接。

## 实施范围

- 前端：结果布局、创意卡、自动创作状态、一体化发布与导出；提取共用测量摘要和确认涂层合成逻辑。
- 后端：新增与测量逻辑隔离的创意接口，执行身份/记录归属校验、当前版本校验、输出校验和缓存，复用当前模型配置。
- 后端属于三站共享服务。上线此新增接口需要按项目流程处理共享后端；不会重跑历史测量，不修改现有算法或用户记录结果。
- 前端先部署测试环境，记录部署日志；正式前端按既有确认流程发布。

## 验收

- 375/390px 手机和桌面下，短标题不意外换行，正文无堆砌；照片不失真、按钮不遮挡，亮暗主题均清晰。
- 覆盖正常测量、部分取景、待核对、无法量化、有效 0%、缺轮廓、再次调整等状态，核对显示与分享数值来源一致。
- 验证模型成功、超时、无效输出、缓存命中、旧请求晚到；生成失败不影响基础记录。
- 合成数据模拟完成：确认保存 → 自动创作 → 一次打包三张图 → 预览确认 → 一条完整帖子；保存图片与系统分享分别可用。
- 测试不得创建真实公开帖子或使用真实患者照片。验证导出图片无文字溢出、轮廓孔洞和相对位置保留、二维码指向公开首页。

## 自审

已覆盖用户提出的取消选择、自动创作、合并分享、单独图片导出和精简排版。基础数据与文学创作各自来源明确；缺失状态不伪装成功；没有默认套用家庭档案。推荐方案中公开确认沿用网站现有机制，不引入新的多步编辑流程。
