- 需检查现有地图服务、坐标及公开评价数据能否支持本次需求。
- brainstorming 技能明确要求设计展示并获批准后才可开始实现。
- HospitalMap 使用 ECharts 全国省界图，44/54px 城市圆点，已有基础缩放但没有街道底图或院区坐标。
- useHospitalDirectory 已有省市区、关键词、医院特征、收藏与有评价筛选，可复用。
- 高德 JSAPI 官方要求 key + 安全密钥，建议服务端代理安全密钥；需核查部署配置（不输出密钥）。
- 市场监管总局 2025 年《医疗广告认定指南》与《医疗广告监管工作指南》说明：不能仅凭“公益/非广告”字样排除医疗广告风险；科普和导流应分离，排名不可暗示疗效或医疗实力。
- 六维体验已存在，但公约明示禁止排名；新体验排序需同步所有说明。
- 后端种子也使用城市中心坐标，且现有统计按条数（approved/flagged + 冷处理）汇总。不能拿现有计数冒充独立人数或近 12 个月排名。
- 仅检查 .env 中地图变量名是否存在，未输出值；未发现高德专用配置。
- 医疗广告指南第八条明确涉及科普附加相关医疗机构/服务跳转等情形，因此设计科普独立页面，避免医疗服务导流混排。
