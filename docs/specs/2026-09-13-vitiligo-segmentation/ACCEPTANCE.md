# 实施验收清单

这份清单用于未来实现。Schema自检仅验证合同，不是模型精度测试。

| 场景 | 必须行为 |
|---|---|
| 清晰普通RGB照片、已核对Mask | 按有效皮肤分母计算；原图/边界/Mask重合 |
| 反光、阴影或背景被圈中 | 干扰标记或待核对，不能以SAM高分强行放行 |
| 自然模糊边界仍可局部辨认 | 局部推理或用户点选；保持原图证据 |
| 严重失焦、过曝使边界消失 | 重拍；不生成缺失边界 |
| 皮肤候选错分/漏掉浅色皮肤 | 核对分母，不能按错误皮肤自动裁剪目标并称成功 |
| 目标超出ROI或皮肤 | 先验证原始越界程度，超容差转待核对 |
| 目标存在内部正常皮肤岛 | 孔洞保留，不作椭圆/凸包/大闭运算填充 |
| 第5个及更多病灶 | 每个区域有状态；预算不足的仍保留，不能静默漏计 |
| 没有目标 / 分割工具失败 | 区分无候选与服务失败；都不能被LLM写成“确诊无白癜风” |
| 用户修正 | 新revision重新测量，保留原始Mask；不得自动进训练集 |
| 同时修改同一记录 | base_revision冲突返回409，不覆盖最新结果 |
| 两用户/两图并发SAM | predictor和embedding不串图；缓存访问验证owner和revision |
| 图像旋转、镜像、裁剪、缩放 | 正反坐标变换后边界一致；面积单位与测量网格明确 |
| 无尺度参照 | 允许可靠的像素面积/比例，cm²保持null |
| 两天照片取景改变 | 共同ROI/配准证据不足时不计算变化率 |
| LLM改写门禁/面积/工件URL | 服务端拒绝；重新调用可信结果，不能接受模型自造结果 |
| 新大模型、相同分割结果与算法 | Mask、像素数、占比和测量状态完全相同；只允许解释措辞变化 |
| 普通手机、无额外光源设备 | 全流程可完成，不出现专业光源必填或购买引导 |

运行时必须执行、JSON Schema无法独立证明的条件：

1. 从鉴权上下文核对所有图像与Mask归属，拒绝任意远程URL和其他用户工件；短时授权不能被长久缓存成公开访问。
2. 工件的sha256、图像revision、ROI revision和尺寸必须一致，二值Mask只含0/255，概率数据不能冒充二值Mask。
3. 校验Mask像素数与统计完全一致，0≤lesion_pixels≤skin_pixels，百分比与计数相符，分母不可为0。
4. 确保模型ID对应已注册不可变权重、标签字典和预处理；原始模型分数不能被当作校准概率。
5. 有标尺的扩展测量必须验证calibration_id、同平面条件、坐标变换、公式与单位；无尺度不得用解剖部位平均尺寸或LLM估计代替。
6. 所有资格判断由服务端策略产生。JSON中写着decision_by=server_measurement_policy不构成可信凭证。
7. 测量与解释绑定同一个结果revision；迟到的模型结果、取消任务结果和旧编辑事件不得覆盖当前结果。
8. 接触画面边界、不可见组织或质量信息丢失不能仅靠勾选“已核对”解除限制。

模型Benchmark应独立报告接受样本的误差、全量覆盖率、拒绝率和子组区间；不以全量拒绝或只评估好照片通过验收。
