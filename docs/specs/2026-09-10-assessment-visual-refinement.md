# 测评页面：保留原版设计的优化

用户明确纠正：此前双入口改造增加负担、文字过多、视觉过于简陋。此次以原版的部位参考图与功能卡片为基础优化，不再按首次/多次记录分流。

## 已实施

- 复用原版 DigitalHuman 与 butterfly_mascot.png 部位参考图，恢复图片与操作卡片的层次。
- 首页统一“白斑记录”：拍照记录、相册选择、照片对比。首次自然成为第一条记录；历史缩略图“继续拍”保留位置基线。
- 相册选择一张进入单次记录，选择2–4张一次带入对比页面，不必重复选择。不立即上传，多图仍在用户点击上传保存后上传。
- 移除“我刚发现白斑／我想看看白斑变化”双入口与首页长段引导；收减拍照、结果、历史及对比页面文字。必要的失败原因保留，专业标定与测量说明折叠。
- 顶部“白斑记录／体检解读”醒目并列；体检有独立路由和View：/assessment/exam；复用原有报告上传/历史功能。
- 旧 /assessment?tab=exam 和 ?tab=report 保持兼容；新路由仍属于原有测评主导航，不新增或改名全站模块。原站点模块清单链接继续可用。
- 保留先前修好的相机资源释放、质量检查、日期确认、观察位置关联、测量口径、可比性和隐私保护逻辑。

- 13项前端回归通过：旧体检链接兼容、单次/多次记录路由、多图有序一次性传递，以及10项相机生命周期测试。
- npm run type-check / npm run build通过。
- 已部署测试环境；仅前端改动，无共享后端重启、无生产前端部署。
- 浏览器页面读取再次超时，未获得本次真实浏览器截图；不将源码/构建测试视为实际视觉或手机实拍验收。

## 设计取舍

保留原版的图形选位和有层次的操作区；用自然页面滚动替代此前整卡拖动，保证小屏内容可达。内部保留首次/连续记录元数据是测量所需，不再要求用户选择身份或学习流程。没有删除历史测评、报告或患者照片。
