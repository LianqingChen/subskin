# 图片优先的白斑范围核对

用户明确指定：上传后直接进入编辑，原图融合浅蓝皮肤/浅粉白斑（透明度60%，即opacity0.4），四工具（皮肤笔、白斑笔、橡皮、竖向粗细）。确认按钮提交当前范围并生成评估，结果引导主动分享。无需二次设计确认。

实现：独立轻量双层像素编辑器，候选并入可编辑白斑层但未确认前不测量；后端保留原候选审计与revision门禁。橡皮作用于最近选中的画笔，擦皮肤同步擦其上白斑。涂白斑受皮肤范围约束。确认按钮即明确acknowledged，不再单独勾选。加载失败不能确认。纯显示色与测量mask分离，PNG alpha为明确二值。照片使用稳定svh高度，不绑滚轮/双指缩放，不随地址栏变化重新fit。上传同样用稳定svh上限。结果只用一张融合图，突出分享草稿，无自动发布。

验收：新照片直接编辑；候选预填；4工具与竖向粗细；改动不破坏mask子集/色彩独立/版本保存；双层默认40%不透明度；失败保留编辑状态；滑动无zoom事件；类型/像素算法/组件行为/上线PWA验证。手机真实浏览器若无法连接，单独报告验收缺口。
