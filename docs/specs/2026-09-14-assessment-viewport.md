# 手帐首屏布局修复

按用户要求实施，无需额外设计确认。上传页及新照片核对页使用稳定小视口高度，扣除全局56px顶栏、移动端55px底栏与安全区。内部保留48px页内导航和必要按钮，照片按剩余空间等比缩小，画笔坐标和二值Mask不变。手机默认日期/开始分析、编辑四工具/确认均无需页面滚动。更多设置是用户主动展开的可滚动区域；极小高度/放大字体允许操作区内部滚动以免裁掉控件。

分析增加90秒参考倒计时（任务处理预算，不是速度预测），用时间戳而非逐次减1，后台切换后不漂移；结束/取消/卸载停止计时，归零提示耗时较长并保留取消。取消分析使用独立大按钮、边框与对比色。纯前端，不改后端时限/模型/测量。

验证：375/768/1024/1440布局约束、日期和工具交互、计时清理与归零逻辑、type-check、build和线上PWA。实机视觉验收依赖浏览器控制可用性，不能用布局公式代替真实截图。

补充：iOS全局html已有顶部安全区padding，新工作页同时扣除该顶部空间；iPad无底栏仍扣除顶部padding。历史详情中的编辑页也使用相同首屏策略。
