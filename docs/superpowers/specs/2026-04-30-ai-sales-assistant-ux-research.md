# AI销售助手（DigitalHuman）UI/UX 优化调研方案

> 调研时间: 2026-04-30 | 项目: SubSkin | 组件: TrackerPage + DigitalHuman.vue

---

## 一、当前系统现状分析

### 1.1 3D数字人 (DigitalHuman.vue)

**现有特征：**
- Three.js 构建的完整人体模型（头、颈、躯干、四肢、手、脚）
- 面部细节丰富：眼睛（含虹膜/瞳孔/高光）、眉毛、鼻子、嘴巴、耳朵、腮红
- 身体部位可点击交互（Raycaster）
- 语音气泡（3D云朵+AI徽章）→ 点击打开AI对话
- 听诊器挂件 → 点击打开体检报告
- 呼吸动画、气泡浮动、听诊器摇摆
- OrbitControls 自动旋转 + 手动拖拽
- 空闲问候系统（5条轮流提示，8秒间隔）
- 评估后部位着色（面积百分比插值）+ 轮廓线（红/黄/绿）
- ACES 胶片色调映射，3点光源系统
- 场景背景色：#f5f0eb（暖米色）

**当前问题：**
1. 材质质感较普通 — 仅使用 MeshStandardMaterial，无环境贴图、无次表面散射模拟
2. 角色风格偏向写实但精度不足，产生"恐怖谷"效应
3. 动画较为单调 — 仅呼吸 + 悬浮，缺乏姿态变化和情感表达
4. 场景背景色单一且与网站主题色系统关联弱
5. 灯光过分均匀，缺乏戏剧性和层次感
6. 移动端性能 — 阴影贴图 512x512，在低端设备上仍有压力

### 1.2 UI布局 (TrackerPage.vue)

**现有特征：**
- 4个视图切换：home / assessment / chat / report
- Home: 3D模型 + 4个统计卡片（VASI评分、累计改善、评估次数、变化趋势）
- Assessment: 返回按钮 + 上次结果 + 上传区 + 部位面板 + 轮廓编辑 + 历史记录
- 视觉隐喻转场（环形涟漪、气泡展开、听诊器发光）
- 响应式布局（max-w-lg → max-w-6xl）

**当前问题：**
1. Home视图信息密度偏低 — 3D模型占据大量空间，下方仅4个统计卡
2. 导航依赖"隐喻交互"，新用户存在认知门槛
3. 缺少快捷操作入口（如快速查看历史、查看百科）
4. 卡片设计偏传统，缺乏现代感（圆角、渐变、毛玻璃、微立体）
5. 暗色模式适配不完整（部分硬编码颜色）

## 二、3D角色设计调研与优化建议

### 2.1 风格方向：走向"温暖医疗风"而非"写实风"

**研究结论：** 医疗健康应用中，3D角色的最佳风格是 **"亲和卡通风格"（Affable Cartoon）**，避免：纯写实（恐怖谷）、过于可爱（缺乏专业信任）、抽象几何体（降低情感连接）。

**三个可行的风格方向：**

| 方案 | 描述 | 优点 | 缺点 | 推荐 |
|------|------|------|------|------|
| A. Soft Clay | 柔和黏土质感，磨砂表面，圆润比例 | 温暖亲和、技术实现简单、性能好 | 可能过于稚嫩 | ⭐⭐⭐ |
| B. Flat Shade | 扁平着色+清晰轮廓，2.5D插画风 | 现代感强、风格独特性高、极低性能开销 | 缺乏立体感 | ⭐⭐ |
| C. Premium Gradient | 渐变玻璃+金属质感，类似Apple健康 | 高级感强、医疗专业感、可复用品牌色 | 实现复杂、性能需求高 | ⭐⭐⭐⭐ |

**推荐方案：** C. Premium Gradient 为主，融合 A 的部分元素（圆润比例+柔和表情）。

### 2.2 材质升级清单

| 改进项 | 当前状态 | 建议优化 | 优先级 |
|--------|----------|----------|--------|
| 皮肤材质 | 单色 MeshStandardMaterial | 添加 roughnessMap + normalMap 制造微妙皮肤纹理，使用 subsurface 近似（emissive warm glow） | 🔴 高 |
| 环境贴图 | 无 | 使用 PMREMGenerator 生成环境贴图，让金属/光滑表面有真实反射 | 🔴 高 |
| 眼睛 | 基础球体 | 添加角膜凸起层（transmission 模拟），虹膜辐射纹路 | 🟡 中 |
| 头发 | 无 | 添加简洁的卡通发型（几何风格），提升角色辨识度 | 🟡 中 |
| 服装 | 无 | 添加简单的医疗风格外套（白大褂简化版），强化"助手"身份 | 🟡 中 |
| 阴影质量 | PCFSoftShadowMap 512x512 | 升级到 1024x1024，或使用 contact shadow（地面投影贴片）替代 | 🟢 低 |

### 2.3 灯光系统重构

**当前：** 3灯系统（环境+主光+补光），偏均匀，缺乏戏剧感

**建议：** 采用 **摄影棚3点光源 + Rim Light（轮廓光）**

```
Key Light（主光）: 右上方45°，强度2.5，暖白色(#fff5ee) → 塑造立体感
Fill Light（补光）: 左下方30°，强度0.6，冷白色(#e8f4ff) → 减弱阴影
Rim Light（轮廓光）: 后方上方，强度1.2，蓝紫色(#c8d6ff) → 角色从背景分离
Ambient（环境）: 强度1.0，暖色 → 基础照明
```

*加上Rim Light后，3D角色立刻从背景中"弹出"，质感提升明显。*

### 2.4 动画增强方案

| 动画 | 当前 | 建议 | 实现方式 |
|------|------|------|----------|
| 空闲姿态 | 呼吸+悬浮 | 添加轻微身体摇摆、头部微转、眨眼（随机间隔2-5秒） | GSAP / 自定义缓动 |
| 部位点击 | 无专属动画 | 被点击部位放大脉冲(scale 1→1.05→1)，伴随涟漪粒子 | geometry scale + 粒子系统 |
| 对话模式 | 仅打开ChatOverlay | 角色转身面向摄像头，气泡UI从3D空间过渡到2D面板 | 相机tween + CSS transition |
| 报告模式 | 仅打开Report | 听诊器胸件发光脉冲，角色低头做"倾听"姿态 | rotation tween + emissive pulse |
| 过渡动画 | 视觉隐喻（600ms） | 角色微表情变化（微笑/关切）+ 部位高亮扫过 | morph targets 或 color/scale tween |

### 2.5 性能优化

- **LOD (Level of Detail):** 为低端设备提供简化版模型（减少面部网格分段）
- **条件渲染：** 移动端降低阴影分辨率至256×256，桌面端保持1024×1024
- **纹理图集：** 将所有材质纹理合并为一张图集
- **requestAnimationFrame 节流：** 在非活跃标签页时降低帧率至10fps

## 三、UI/UX设计调研与优化建议

### 3.1 信息架构重构

**当前流程：**
```
Home (3D Model) → 点击部位 → Assessment → 上传 → 结果
                 → 点击气泡 → Chat
                 → 点击听诊器 → Report
```

**建议流程（增强版）：**
```
Home (3D Model + 快捷操作卡片)
├── 核心区：3D数字人（可旋转/缩放）
├── 快捷卡片轮播：最近评估 / AI推荐问题 / 健康小贴士
├── 底部操作栏：📷拍照评估 | 💬问AI | 📋查看报告 | 📖百科
└── 下拉：评估历史时间线

点击部位 → 部位聚焦（相机zoom）+ 底部弹出Sheet（非跳页）
  ├── 该部位历史趋势迷你图表
  ├── 📷拍照 或 📁上传
  └── 其他部位快捷切换标签

点击气泡 → 聊天面板从右侧滑入（非全屏跳转）
点击听诊器 → 报告面板从底部弹出（非全屏跳转）
```

**核心理念：** 减少页面跳转，用 **Sheet/半屏面板** 维持用户的"空间感"，保持3D角色始终可见作为"锚点"。

### 3.2 卡片设计现代化

**参考：** Apple Health、Dribbble 医疗类设计、Linear 的任务卡片

| 元素 | 当前 | 建议 |
|------|------|------|
| 圆角 | rounded-2xl | rounded-3xl（更大更柔和） |
| 背景 | 纯白/灰 | 磨砂玻璃效果（backdrop-blur + bg-white/70） |
| 阴影 | 默认 shadow-sm | 彩色柔和阴影（shadow-primary-500/10） |
| 边框 | 无或灰色边框 | 微妙渐变边框（border-gradient） |
| 数据展示 | 纯数字 | 添加迷你 SVG 趋势图（sparkline） |
| 状态指示 | 文字标签 | 发光圆点+文字（● 改善中） |

### 3.3 色彩系统优化

**当前品牌色：** Primary（蓝紫系）

**建议扩展健康数据色板：**

```css
--health-improving: #22c55e → 保持
--health-stable:     #f59e0b → 改为更温暖的 #f2a841
--health-worsening:  #ef4444 → 保持
--health-neutral:    #6b7280 → 改为 #94a3b8

/* 新增语义色 */
--skin-warm:   #fef3c7  /* 温暖肤色调 */
--medical-teal:#0d9488  /* 医疗蓝绿，用于图标/强调 */
--calm-lavender: #c4b5fd /* 安抚色，用于健康建议 */
```

### 3.4 移动端交互模式（面向中文用户）

**微信/小程序风格的交互模式：**
- **底部ActionSheet** 替代弹窗（更符合中文用户习惯）
- **下拉刷新** 历史记录（已有，保持）
- **左滑操作**（删除历史 — 已有，保持）
- **长按预览**（在历史记录上长按查看详情缩略图）
- **骨架屏**（Skeleton Screen）替代 spinner
- **触觉反馈**（vibrate on success/error）

### 3.5 暗色模式完善

**当前问题：** 3D场景背景色 `#f5f0eb` 硬编码，与暗色模式冲突。

**解决方案：**
1. 监听 Tailwind `dark` class 变化
2. 暗色模式下场景背景改为 `#1e1e2e`（深蓝灰）
3. 灯光色温相应调整（暖色 → 冷色）
4. 轮廓线发光强度翻倍（暗色背景下需要更亮）
5. 地面平台改为半透明深色

## 四、AI助手交互设计调研

### 4.1 对话面板优化

**参考产品：** ChatGPT app、Poe、文心一言、豆包

| 特性 | 建议 |
|------|------|
| 欢迎状态 | 显示3个推荐问题 + 角色打招呼动画 |
| 输入框 | 语音输入按钮（微信用户习惯）+ 图片上传 |
| 消息气泡 | 圆角不对称（AI左对齐16px圆角，用户右对齐16px圆角），体现对话感 |
| 打字指示器 | 跳跃圆点动画（比纯文字"对方正在输入"更优雅） |
| 快捷操作 | 消息长按→复制/分享/反馈 |
| 上下文指示 | 顶部显示当前对话上下文（如"关于面部白斑的讨论"） |

### 4.2 主动式AI建议

**当前：** 空闲问候系统（文字气泡，8秒间隔）

**建议增强：**
1. **情境感知：** 根据用户最近活动推送相关建议（如"你上次评估了面部，需要对比最新照片吗？"）
2. **时间感知：** 早晚不同问候（早晨："新的一天，记得检查白斑变化哦~"）
3. **里程碑庆祝：** VASI评分改善时，角色做🎉动画（粒子/纸屑）
4. **健康提醒：** 基于上次评估时间间隔，提醒"已经3天没有评估了，来拍张照吗？"

### 4.3 情感化设计

| 场景 | 角色表情/动作 | 视觉反馈 |
|------|--------------|----------|
| 用户打开页面 | 微笑 + 挥手 | 星星粒子飘过 |
| 评估结果好转 | 开心跳起 + 撒花 | 金色粒子爆发 |
| 评估结果恶化 | 关切表情 + 靠近 | 柔光笼罩 |
| 长时间未评估 | 期待眼神 + 挥手 | 呼吸光晕 |
| 错误/失败 | 低头 + 摇头 | 灰色波纹 |

## 六、优先级排序与实施路线图

### Phase 1 — 快速见效（1-2周）

1. **灯光系统重构** — 添加Rim Light，瞬间提升质感
2. **环境贴图** — PMREMGenerator 生成，金属表面反射
3. **场景背景色暗色模式适配** — 修复硬编码
4. **卡片现代化** — 磨砂玻璃效果 + 柔和阴影
5. **空闲动画增强** — 添加眨眼 + 身体微摇
6. **统计卡片添加趋势迷你图** — sparkline SVG

### Phase 2 — 体验升级（2-4周）

7. **部位交互增强** — 点击后相机聚焦+底部Sheet
8. **3D角色添加服装/发型** — 提升辨识度+亲和力
9. **情感化动画系统** — 表情变化 + 粒子效果
10. **主动AI建议** — 情境感知推送
11. **导航优化** — 底部快捷操作栏
12. **皮肤材质升级** — roughnessMap + subsurface模拟

### Phase 3 — 品质打磨（4-8周）

13. **角色表面散射模拟（SSS）** — 皮肤透光感
14. **语音交互** — 微信语音消息集成
15. **AR模式探索** — WebXR 人体部位映射
16. **A/B测试框架** — 数据驱动优化

## 八、总结与核心建议

1. **3D角色：** 保持现有几何结构，重点升级材质（环境贴图+皮肤纹理）和灯光（Rim Light），添加服装和发型提升辨识度
2. **交互模式：** 减少页面跳转，用 Sheet/半屏面板保持空间连续性，增加情感化动画反馈
3. **UI视觉：** 全面应用磨砂玻璃+柔和阴影，添加迷你趋势图，完善暗色模式
4. **AI体验：** 从被动问答升级为主动情境感知助手，增加语音输入和庆祝/安抚动画
5. **性能：** 移动端提供 LOD 降级，3D 场景根据设备能力自适应

> **最重要的3件事：** Rim Light（立竿见影）> 交互模式重构（减少跳转）> 情感化动画（用户粘性）
