# 问题

用户反馈：手帐（`/assessment`）页面的白斑面积识别非常不准确，希望用「逐像素颜色 +
相邻像素颜色差异」把白斑的范围和边缘识别准一些。

# 复现与量化（4 张真实上传照片，768px 工作分辨率）

用 `build_skin_mask` / `expand_skin_mask_to_include_vitiligo` /
`detect_vitiligo_within_skin` 逐步跑，并导出掩膜叠加图肉眼核对：

| 照片 | 旧 skin% | 旧 region% | 旧 vitiligo%（占整图） | 旧阈值 |
|---|---|---|---|---|
| 1778982996（面部） | 51.5 | 63.5 | 12.9 | 171 |
| 1778999494（手部） | 81.8 | **100** | 16.5 | 209 |
| 1779529119（面部） | **100** | **100** | 20.9 | 170 |
| 1780413603（面部） | 99.2 | **100** | 22.9 | 191 |

肉眼可见：粉色（白斑）落在额头、眼周、**衣领、窗帘、显示器支架**上。

# 根因（4 个独立缺陷）

1. **皮肤掩膜**用 `HSV ∪ YCrCb` 并集。YCrCb 的 `Cr∈[133,180]` 覆盖了几乎所有暖色，
   墙面/窗帘/木色桌面/衣物全部命中，且没有空间连贯性约束（无连通域筛选）。
2. **分析区域**对「膨胀后的最大轮廓」做**凸包**。拍摄时皮肤必然贴到画面边缘，
   凸包就等于整幅图 → 面积分母 = 整图（region 100%）。
3. **白斑判定**用**全图单一阈值** `max(median_L+12, p75_L+5)`。真实照片存在侧向光照/
   阴影，亮侧皮肤整体高于该阈值 → 整片亮侧被判为白斑。这是「面积不准」的主因。
   而且阈值随全图统计浮动，**同一用户不同次拍摄结果不可比**。
4. **完全未使用邻域色差**，且 `_mask_to_polygon` 最多 40 点、`epsilon=0.005`，
   边缘被压成粗块。

# 方案

新增 `web/backend/services/vasi_edge_segmentation.py`（纯 cv2/numpy，无新依赖）：

1. **逐像素颜色**：LAB 的 L 与 `chroma=‖(a*,b*)‖`。
2. **局部光照校正**：把图切成 48×48 网格，用直方图求每格分位数；
   再用 **mean-shift（带宽 = 1.5σ 的对称窗口）** 迭代求**局部众数参考肤色**。
   注意：不能用「比局部中位更暗的像素再求中位」——那会系统性收敛到局部 p25，
   即使全是健康皮肤也会留下 ~12 L* 的 ΔL 偏移（第一版实现踩过这个坑）。
3. **相邻像素颜色差异**：对 L/a*/b* 做 Sobel，亮度权重 1.0、a/b 各 0.8，合成梯度幅值。
4. **白斑似然** = `0.55·norm(ΔL) + 0.45·norm(Δchroma) − 0.18·norm(局部梯度)`，
   归一化使用**固定感知尺度**（ΔL 除 12、Δchroma 除 8，各减去死区）而不是按图自适应，
   保证同一用户跨照片/跨时间阈值一致。
5. **滞后双阈值**（Canny 思路）：只保留与高置信核心连通的候选。
6. **分水岭边缘吸附**：以颜色梯度为高程、以「白斑核心 / 健康皮肤核心」为两个标记，
   边界自然收敛到**色差脊线**；变更幅度限制在 ±4px。
7. **连通域过滤**：过小、贴边背景、彩度高于周围（红疹/血管）、细长高光、
   内部纹理杂乱、**外环缺少肤色证据**（真实白斑四周一定有皮肤）、边界对比度不足。

同时修掉分母与阈值缺陷：

- `build_skin_mask`：改为 `HSV ∩ YCrCb`（+ 亮肤色补 Kovac RGB 规则）+ 按长边比例
  开运算断桥 + 排除近纯白参考物，并加工作分辨率（≤1280px，输出还原原尺寸）。
- `expand_skin_mask_to_include_vitiligo`：**取消凸包**，改为「色彩候选 ∪ 脱色素候选 →
  中心主体先验连通域选择（面积 × 中心接近度，惩罚贴边背景色）→ 填洞 → 有界膨胀」。
- `detect_vitiligo_within_skin`：委派边缘感知算法（签名与 stats 字段向后兼容）。
- `consolidate_segmentation` / `_segmentation_result_from_mask`：对**任意来源**
  （U-Net / SAM / CV）的掩膜统一做边缘吸附 —— 这样无论用哪个模型出初稿，边缘都贴合色差。
- `_mask_to_polygon`：顶点上限 40→120、`epsilon` 0.005→0.0025。

# 结果

| 照片 | 新 region% | 新 vitiligo%（占皮肤） |
|---|---|---|
| 1778982996 | 51.7 | 32.2 |
| 1778999494 | 90.9 | 20.4 |
| 1779529119 | 87.6 | 10.2 |
| 1780413603 | 70.5 | 15.1 |

- 分析区域不再等于整图；白斑不再落在衣领/窗帘/桌面上。
- 放大对比图显示：旧边界是噪声锯齿，新边界贴合真实色调过渡。
- CV 回退路径全分辨率耗时 3.61s → 1.28s（局部参考与区域精修都在 ≤1280px 上做）。

健康皮肤误检<1%、背景亮块被拒、边缘吸附单调改进、滞后阈值连通性、多边形细节、
工作分辨率形状、小图不被面积比例阈值拒之门外。

# 已知边界（未解决）

- 分析区域（分母）在部分照片上仍会包含一些背景；真实「身体部位面积」从单张特写无法
  可靠推得，目前仍以可见皮肤面积近似。
- 占画面比例极大的融合性白斑，局部参考会被自身主导，中心可能漏检（窗口 13/48 ≈ 27% 长边）。
- 侧向光照极强（>70% 亮度差）时校正后仍有残余偏差。
