# 白斑轮廓可靠性修复 pixel-refine-v2

## 发布范围

仅发布测试前端；共享后端重启会同时影响两站的标注与测量接口。无数据库迁移、无模型配置替换，不改原照片和既有AI原始几何。旧版未人工核对的几何结果在读取时隐藏面积，已经人工核对的记录保留其测量。

## 修复与验收

| 缺陷 | 修改 | 验证 |
|---|---|---|
| 正点位于环形空洞、矩形没有负点 | 距离变换内部点、明确外侧负点，局部框约束 | 合成非凸/矩形回归 |
| 精修范围进入颈部/背景 | 皮肤范围锁定到候选作用域、局部ROI门禁 | 合成门禁与2例原图回放 |
| Lab色度计算错误、SAM否决后仍保留 | 浮点Lab，所有引擎共用颜色/边界门禁，否决清空 | 灰色/低对比/拒绝SAM回归 |
| 超过4区静默遗漏 | 全部区域登记，未处理区域转待核对 | 第5区域保留回归 |
| 粗几何或CV降级被完整测量 | 统一测量可用性门禁，旧记录读取同样生效 | 服务测试与前端无数字断言 |
| 编辑器仍显示无效占比、旧CV不能核对 | 勾选核对后计算；兼容旧CV协议 | 前端确认事件/后端人工修正回归 |
| 模型拒答反复重试、来源丢失 | 统一超时，只重试格式错误一次，保留provider/model | not_assessable不重试回归 |

## 验证结果与限制

后端78项通过，前端16项通过。两个授权真实病例在本地使用现有SAM权重、原图与已存模型几何回放；不是重新请求大模型，也不是在线完整上传测试。原版分别refined/partial，新版均candidate-only、4/4待核对，禁止自动面积。SAM阶段约12–13秒（已加载权重）；冷启动、服务器并发、VLM延迟未纳入此耗时。

自动边界准确性尚未达标。主要问题仍是VLM候选偏移、通用SAM选择语义对象/正常皮肤、CV无法稳定分离低对比色素变化。当前图像证据阈值是工程门禁，不是经过临床验证的概率；形状规则不应全面禁止真实矩形病灶。人工核对也不等于医学确诊。

继续提升需要按身体部位/肤色/拍照条件收集经授权双人逐像素标注，独立测试Dice、Boundary F1、面积误差和拒绝率；随后训练专用分割器。不能用这2例门禁成功报告识别准确率提升，更不能保证任意大模型通用精确测量。
