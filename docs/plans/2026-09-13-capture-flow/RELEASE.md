# 手帐上传和日期简化

## 本批修改

1. 日志中09:01两次质检均401，原UI将鉴权错误显示为换照片。现区分401、403、图片格式/大小、超时和网络错误；提供登录入口与原图重试。没有改变后端鉴权和照片不合格的拦截。
2. 移除角度选择和前端必填要求。保留已有基线视角字段，不为新照片伪造“正面”。不同取景的量化对比仍受原后端可比性规则约束。
3. 相册照片优先读EXIF日期；无有效日期、未来日期或读取超时默认今天，明确来源可修改。相机照片使用捕获事件时的本地系统日期。读取过程中不可开始分析，避免错用今天。
4. 根据用户后续要求，日期改为始终可见的单行年月日滚轮，滚动即更新，无单独修改/确认按钮；隐藏常规说明。手帐可选1900年至今天，其他使用者默认范围保持2000年起、五行外观；滚轮按钮44px并支持键盘。
5. 重拍换图合入照片底栏，部位、备注和标尺收进“更多设置”；手机紧凑纵排，桌面照片/操作并排。
6. 换图、手工改日期、重新质检均有请求顺序保护，不让旧异步结果覆盖新照片。

## 验证

16项前端回归通过（质量错误/重试/换图/日期/确认交互/路由）；合成JPEG的真实EXIF解析返回2025-06-07。类型检查、构建、部署状态见progress.md。
