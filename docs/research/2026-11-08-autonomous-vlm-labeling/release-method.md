# 日记白斑分析与候选涂层

日记分析使用千问 3.8 对编号区域判读。五档投票生成白斑初稿，本地辅助模型在存在反向票的像素上修正白斑或正常皮肤。边界细化与小斑补查作为可撤销的可选初稿，经用户核对后保存。离线回归发现叠加边界细化存在跨照片退步。尚未验证日记产品的整体准确率。

小斑先用局部颜色差提出候选。模型三轮判读过半、且本地条件白斑概率至少 0.90 时，候选才进入小斑初稿。白斑、正常皮肤、总可见皮肤需分别评分。小斑以普通 Dice 和实际误标、漏标像素为主。临床候选与可见外观分开记录。

照片外发需在说明实际服务商、模型、用途及处理范围后获得本次主动授权。应用使用独立按量付费凭证，账号白名单控制入口。用户可继续选择本地分析。完整研究、回执和复算记录在服务器的研究目录按权限管理。

服务部署定义在 `web/deploy`。工作进程依赖服务器配置的公开训练辅助权重和本地人体解析资产。上线前核对权重 SHA-256，并分别验证按量凭证、授权、队列、候选读取与用户保存。

测试站和正式站使用同一个白名单服务。两个 Nginx 虚拟主机均引用 `web/deploy/nginx-bailian-assessment.conf`。现有账号范围和密钥配置由服务端维护。
