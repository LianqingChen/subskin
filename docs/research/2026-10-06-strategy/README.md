# SubSkin 数据库、AI测评与研究协作总体方案

版本：v1.5（草案，待决策）；调研日期：2026-10-06；首期预算：用户确认人民币50万–100万元，不含创始人薪酬。

这是一套基于当前源码和公开原始资料的决策方案。文中的数量、价格、转化率和模型门槛为待验证目标，不代表SubSkin当前用户规模、营收或临床性能。本文不构成医疗建议。

## 一页结论

| 问题 | 结论 |
|---|---|
| 做什么 | 把SubSkin定位为“白癜风患者长期记录与可信知识平台”：患者自愿贡献 + 医生/医院协作 → 高质量纵向数据库 → 专用图像测量、辅助鉴别和研究服务 |
| 先做什么 | **授权与数据治理 → 标准化记录和标签 → 可信百科与复诊资料 → 分割模型独立验证 → 付费机构试点** |
| 暂不做什么 | 全面自动诊断、全身分型和活动期判断、药物研发平台、生物样本、站内电商、从零训练基础模型 |
| 现有最大资产 | 记录、照片对比、用户修正、后台标注、RAG问答、社区 |
| 最大缺口 | 对象级研究/训练授权、医生参考标签、统一数据集版本、独立验证 |
| 首年能证明什么 | 授权覆盖、标签质量、独立测试、长期随访完成度；**不能**证明“全球最大/最完整/最精确” |
| 首年赚钱吗 | 不赚钱。基准情景一年稳态毛收入约14.5万元，对80万投入；首年目标是验证价值与合作，不是盈利 |

**当前最优先事项：建设图像数据库。** 细化结果见[06](06-image-database-label-plan.md)：先修4个阻断级缺陷（撤回授权无效、有日记账号注销报错、注销残留白斑数据、后台queue/export接口被路由遮蔽），再做分用途授权、标签字典和角色拆分，然后才扩大贡献征集。**前4项缺陷、授权服务、微询问后端、训练闸门均已于2026-10-07部署，授权已开放；前端仅在测试环境，等你验收**；按角色的行动清单见[07](07-execution-by-role.md)。“最大/最全/最准确”按06第1节的指标度量，对外表述须限定检索范围和日期。

## 决策建议

首年优先顺序见上表。全面自动诊断、全身分型和活动期判断、药物研发平台放在达到前置条件之后。

调养中的普通食材、铜器、泛商品导购与研究目标贴合度低，建议收敛投入；对应页面不删除，先降低新增投入并观察对留存的真实贡献（见03第1节）。

## 12个月建议交付

按80万元基准预算设计，50万元版缩减样本和模型范围，100万元版增加机构与外部验证：

| 目标（均为待验证的伸展目标） | 50万版 | **80万基准** | 100万版 |
|---|---:|---:|---:|
| 独立自愿贡献者 | 500 | **1000** | 1500 |
| 去重授权照片 | 2000 | **4000** | 6000 |
| 临床参考审核照片 | 未单列 | **1500** | 未单列 |
| 像素标注 | 约500 | **1000** | 1500 |
| 3次合格同部位记录的人数 | 未单列 | **250** | 未单列 |
| 经审核知识主题 | 100 | **150–200** | 未单列 |
| 合作机构 | 1 | **1–3** | 2–3 |
| 模型范围 | 单一主要部位 | **面/手优先** | 增加外部验证 |

“未单列”表示02/04只给出了80万基准或总体缩放原则，执行前需另行核定。后两项可重叠，不能把1500与1000相加称为2500张；照片数按去重和漏斗核算，不用一位患者几十张照片夸大样本量。

预算（万元，不含创始人薪酬）：50 / **80** / 100。80万基准中工程约30万（37.5%）；医学审核9万、标注与质控10万、运营与患者支持8万，合计约27万；云5万、合规咨询5万、试点3万、调研增长3万、预备金7万。完整分项和季度节奏见02第6节。

核心交付：

- 1套独立于社区公开授权的贡献/训练/研究/撤回流程，具有不可覆盖的授权事件和数据谱系。
- 1套分割与变化测量研究基线、固定测试集及失败分析；达到预设门槛后才开放限定用途。
- 1–3家合作机构、至少1个实际付款试点；验证医生资料准备时间和病友复诊使用价值。
- 150–200个经审核的知识主题、可追溯来源及问题反馈流程。

## 阶段门槛：继续、缩减还是停止

数量是伸展目标，门槛才是继续投入的条件（详见04第2节和01第9节）：

| 时点 | 必须成立 | 不成立时 |
|---|---|---|
| 第90天（SS-12） | 授权/删除/权限检查通过；出现第二次记录和复诊资料的真实使用；30–50名自愿用户试运行 | 先改记录流程，不扩大招募 |
| 第6个月（M6） | 每个样本授权与参考标准完整；标注质量和单位成本可承受；1家机构试点启动 | 缩小部位和任务范围，不继续扩大成本 |
| 第9个月（M9） | 模型按预设范围达标，或明确保留人工核对；1个机构付款 | 保留人工核对并做失败分析；无机构预算则不用虚构意向支撑预测 |
| 第12个月（M12） | 数据权利、性能、商业交付均可复现 | 年度评审决定扩张或保持小规模 |

## 主要风险与待决事项

| 项 | 说明 | 处理 |
|---|---|---|
| 合作医院与PI | 尚无已签约机构；临床参考标签、伦理路径和付款试点都依赖它 | 首轮访谈3–5名医生，确定1名PI和1名预算负责人；未落实前不承诺机构收入 |
| 人工参考标准有噪声 | 同图重复手绘也会差出百分点级面积；Dice/MAE门槛可能比人工自身可重复性更严 | SS-08盲双标时同步测评分者内/间差异，**再冻结**模型门槛（已补入01与04） |
| 现有“测评”不是自动测量 | 记录页面积来自用户核对的掩膜；`final_vasi_score`固定为0.0；RGB模型`enabled=false` | 对外只称“范围记录与对比”；不称VASI或AI测量（见03第2节） |
| 共享后端风险 | 模型激活和DB变更同时影响正式用户 | 先建隔离训练环境；模型发布需审批（SS-11、SS-23） |
| 授权颗粒度 | 现有同意类型较粗，不覆盖训练、研究、合作方 | SS-03/04为P0，先于一切训练与导出 |
| 法规定性 | 测量/辅助诊断软件在中国的监管定性、跨境、未成年人、人类遗传资源均未形成书面结论 | 对应阶段前取得书面意见；首年不涉及的不预支预算 |
| 付款渠道 | 当前无交易模块 | 先用合规的小规模订单渠道和人工履约试验 |
| 创始人产能 | 多模块并行易延期 | 保留记录与数据核心，减少3D/电商/泛内容开发 |

源码核查显示四个主导航为问答、记录、发现、调养；独立百科入口已下线，但百科文章/修订模型和API仍存在。RGB模型注册配置当前为`enabled=false / training_source=not_trained`；旧U-Net链路已有训练与激活接口，两条链路不能混称为已验证的白癜风大模型。

## 术语

| 术语 | 含义 |
|---|---|
| PI | 临床研究负责人（Principal Investigator），本方案指合作医院的皮肤科医生 |
| mask / 像素标注 | 在照片上逐像素标出皮肤、脱色区等类别的标注；本项目RGB标准为五类，unknown=255 |
| Dice / IoU | 模型分割与参考标注的重叠度，越接近1越一致；不等于诊断准确率 |
| VASI / F-VASI / T-VASI | 临床白癜风面积与脱色评分体系；局部照片的像素占比**不是**VASI（见01第6.3节） |
| T0–T4 | 标签可靠度分层：未核实、用户事实、受训标注员、专家临床参考、争议仲裁（01第4.3节） |
| manifest | 版本化的数据集清单，逐样本记录授权、来源、split和哈希；训练只读它，不再随机重切 |
| 去标识 vs 匿名 | 哈希、裁剪、遮脸都只是去标识；面部白斑照片仍可能识别到个人 |
