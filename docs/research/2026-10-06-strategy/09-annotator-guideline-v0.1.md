# 白癜风图片标注员指南（v0.1 草案）

状态：**草案，须经PI（临床负责人）审定并签字后才可用于正式标注**。草案中的示例图、边界判定细则需由医生提供或确认；在此之前只用于培训和校准试运行。本文不构成医疗建议。

适用角色：受训标注员/管理员（非临床角色）。对应[06](06-image-database-label-plan.md)第3节中标为**S**的任务。

## 1. 你的角色与边界

你负责：看图并做**客观、可复核**的工作：画范围、判断图片质量、记录能直接看到的外观。

你**不做**：
- 不判断“是不是白癜风”、是什么类型、稳定还是活动、治疗有没有效。这些只能由医生判断。
- 不修改或猜测患者自述的内容。
- 不把任何样本设为“可用于训练”，也不激活模型。这些权限不在标注员账号上。

拿不准就选“**无法判断**”或“**升级给医生**”，这是正确的选择，不会扣分。

## 2. 数据安全（必须遵守）

- 你看到的每张照片都是患者的敏感健康数据，面部和身体照片可能被认出是谁。
- 只处理系统分配给你的任务；不下载、不截图、不拍屏、不转发、不在公共场合打开。
- 不尝试查找图片的主人，不把图片内容告诉任何人。
- 发现图片里有可识别信息（证件、姓名、手机号、背景文件）：**立即标记“含可识别信息”并停止，不要继续处理**，并通知数据负责人。
- 你的所有访问都会被记录，用于审计。
- 离岗后账号立即停用，保密义务继续有效（以签署的保密协议为准）。

## 3. 你会做的任务

| 任务 | 做什么 | 产出 |
|---|---|---|
| T-Q 质量复核 | 判断图片是否可用于对比和标注 | 通过/不通过 + 原因 |
| T-P 像素标注 | 画出皮肤、脱色区等五类区域 | mask |
| T-V 可见体征初标 | 记录照片里能看到的外观特征 | 有/无/无法判断 |
| T-S 肤色 | 按Monk色阶选择 | 1–10或不确定 |
| T-D 近重复复核 | 判断两张图是否同一次拍摄 | 是/否/不确定 |

## 4. 质量复核（T-Q）

对每张图依次看：

1. **清晰**：病灶边缘是否能分辨？模糊到看不清边缘 → 不通过（原因：模糊）。
2. **光线**：是否过曝（白斑和皮肤都发白）或过暗？→ 不通过（原因：曝光）。
3. **反光**：有没有亮斑盖住病灶？→ 范围较大不通过；局部反光在标注时标为“不可判读”。
4. **遮挡**：衣物、头发、饰品、遮盖产品、手指是否挡住病灶？→ 挡住的区域标“遮挡”；挡住大部分 → 不通过。
5. **视角**：拍摄是否斜得严重、病灶被拉伸？→ 不通过（原因：角度）。
6. **是否看得到目标部位**：与用户选择的部位明显不符 → 标“部位存疑”，升级给管理员。

AI给出的质量分只是参考；**不通过的最终决定由你做**，不能只因为AI分低就拒绝。

## 5. 像素标注（T-P）

沿用现有五类（`ml/rgb_segmentation`）：

| 类别 | 含义 | 怎么标 |
|---|---|---|
| normal_skin | 正常肤色的皮肤 | 目标部位内、颜色正常的皮肤 |
| depigmented_skin | 疑似脱色区域（白斑候选） | 比周围皮肤明显更白、边界可辨认的区域 |
| background | 背景、衣物、非皮肤 | 不属于皮肤的一切 |
| occlusion | 被遮挡的皮肤 | 头发、手指、饰品、遮盖产品覆盖处 |
| unreadable | 看不清、无法判读 | 过曝、严重反光、模糊区域 |
| unknown（值255） | 没有标注 | 未处理或确实拿不准的区域 |

要点：

1. **先画皮肤范围，再画脱色区**；脱色区必须在皮肤范围内。
2. **边界模糊的过渡带**：不确定就留给 unknown，不要硬画；宁可少标，不要多标。
3. **颜色接近但不确定是不是脱色**（例如晒后发白、遮盖产品、反光）：不标 depigmented；标 unreadable 或 occlusion，并勾选相应的外观提示。
4. **小而散的点状区域**：能清楚分辨的逐个标出；分辨不清的整片留 unknown，并在备注写“点状密集”。
5. **口唇、黏膜、生殖器等**：首年不采集；若出现，标“超出范围”并升级，不要标注。
6. **画完检查**：脱色区是否超出皮肤范围？是否有未标的明显脱色区？撤销重画比留着错误更好。
7. **盲标任务**：系统不会预先显示AI或用户的结果，请从零画。非盲标任务可以在AI预填基础上修正，但仍须逐处核对，不能直接整体采纳。

## 6. 可见体征初标（T-V）

只记录**照片里能看到**的外观，不代表诊断。每项选 **有 / 无 / 无法判断**。医生会复核其中多项。

| 体征 | 你看什么 | 说明 |
|---|---|---|
| 彩纸屑样（confetti）样小白点 | 病灶周围散在的细小白点 | 医生会仲裁 |
| 边缘低色/多色 | 白斑边缘出现比周围浅但不全白的过渡带 | 医生会仲裁 |
| 边缘发红 | 白斑边缘看起来发红 | 医生会仲裁 |
| 毛发变白 | 病灶范围内的毛发是白色 | 只记录“看到白色毛发” |
| 线状/沿某条线分布 | 病灶呈线状或带状分布 | 只记外观，不判断类型 |
| 遮盖/晒伤/化妆 | 皮肤上有遮盖产品或明显晒红 | 用于排除不可比 |

示例图由PI提供后附在本文末尾；**没有示例图的体征，培训阶段不要求你判断，一律选“无法判断”。**

## 7. 肤色（T-S）

- 按Monk色阶（1–10）选择最接近的一档，**以未被病灶和晒伤影响的正常皮肤**为准。
- 照片偏色或曝光异常时，选“不确定”。
- 不使用Fitzpatrick分型。

## 8. 近重复复核（T-D）

系统会提示“可能是同一张照片的不同版本”。你判断：同一次拍摄 / 同部位不同次拍摄 / 不同。只在**同一次拍摄**时合并；拿不准选“不确定”。

## 9. 什么时候升级给医生

- 你觉得图片可能不是白癜风，或看到明显不寻常的皮肤改变。
- 出现红肿、渗出、破溃等明显炎症表现。
- 部位存疑、疑似儿童、疑似黏膜或隐私部位。
- 两张图对比时变化很大，你无法判断是真实变化还是拍摄差异。

升级时只写你**看到的**，不要写“我觉得是××病”。

## 10. 流程与质量

1. 每次提交会生成新的版本，不会覆盖旧版本；**不能改别人的标注**。
2. 普通任务约20%会被另一名标注员重复标注；测试集任务100%双标；两人不一致由医生仲裁。
3. 每月一次校准会（约30分钟）：医生展示分歧样本并说明标准，大家对齐。
4. 一致性指标（Dice、类别一致率）按月反馈给个人；不达标的任务类型需重新培训。**这是培训依据，不是处罚依据。**
5. 记录每张图的用时；用时过长的样本会被抽出来讨论规则是否需要改。

## 11. 常见错误

| 错误 | 正确做法 |
|---|---|
| 把晒后发白、反光、遮盖产品当脱色区 | 标 unreadable/occlusion，并勾选提示 |
| 皮肤范围画太大，包进头发、衣服 | 沿真实皮肤边缘，头发归 occlusion，衣服归 background |
| 边界不清硬画一条线 | 过渡带留 unknown |
| 把AI预填结果整体点“同意” | 逐处核对，不确定处修改 |
| 对“是什么病”写评论 | 只写看到的，升级给医生 |
