# 白癜风图像数据库专项：标签体系、分工与缺口清单

日期：2026-10-06。本文是01–05的专项细化，回答五个问题：数据库要达到什么标准、现在差什么、图片有哪些标签、谁来打标（用户/管理员/医生/AI）、SubSkin和管理后台还要做什么。本文不构成医疗建议。

依据：①本地源码只读审计（后台标签体系、用户端采集与授权，关键断言已在源码中复核）；②外部文献和同类库调研。未读取真实用户或病例数据。外部来源中，ISIC总数和10篇关键文献（见第9节）已逐条复核；其余来自调研子任务读取，标注为“未复核”。

## 1. 先把“最大、最全、最准确”变成可度量的指标

只比图片张数既不能证明“全”，更不能证明“准”。同一患者的几十张照片也不等于几十个样本。建议用下表作为库的头部指标，每月出报表：

| 维度 | 指标 | 说明 |
|---|---|---|
| 大 | 授权独立患者数；授权去重图片数 | 以患者为单位，不以图片为单位 |
| 全 | 覆盖矩阵格数：部位 × 肤色(MST) × 设备 × 年龄段 × 成像方式 | 不要求稀疏格子全覆盖，但要公开缺口 |
| 全 | 医生确认的相似疾病负例数（mimic） | 没有负例就无法训练或评估鉴别 |
| 准 | **带医生参考的患者占比**（头号质量指标） | 医生确认诊断，且记录依据（现场/照片回顾/Wood灯/随访月数） |
| 准 | 双标一致性（像素Dice、类别kappa）；医生盲评一致性 | 先测后定门槛，见01第6.4节 |
| 准 | 从不被AI预标注的医生盲标评估集规模 | 避免模型与人互相确认造成伪标签污染 |
| 时间 | 同部位≥3次合格记录的患者数；随访跨度 | 稳定性、复色、治疗反应都依赖它 |

**对标事实（截至2026-10-06检索，范围有限）**：ISIC共553,019张，但167个诊断取值中没有白癜风类条目；Kaggle的白癜风集3,628张，页面标CC0，但作者自述图片来自图谱和图库网站，版权存疑，不能当许可使用；一篇论文的全身白癜风数据集1,740张，按国际拍摄标准采集，但数据不公开；SCIN约1万张，其中白癜风病例数未核实；GloW-VSNet仓库无数据；GLOVA官网未见图像库。本次**没有找到许可清晰、可下载、带医生参考的白癜风专用大库**。因此，达到“授权清晰 + 带医生参考 + 成套标准化照片 + 纵向随访”的数千张规模，就有明确的差异化；但“最大/最全”须限定检索范围和日期后再对外使用，不能写成绝对结论。

## 3. 白癜风图片标签字典与分工

### 3.1 角色与AI等级定义

| 代号 | 含义 |
|---|---|
| **U** 用户 | 患者本人/合法监护人；只回答自己知道的事实，所有题都允许“不知道” |
| **S** 管理员/受训标注员 | 非临床角色：整理资料、质量复核、画像素mask、做可见体征初标；**不做诊断、分型、稳定性判断** |
| **D** 皮肤科医生 | 经资质认证（可复用`DoctorVerification`流程）；给临床参考，记录依据 |
| **AI·直** | 程序或模型直接写入，因为是确定性计算或元数据；抽样复核，错误可追溯 |
| **AI·辅** | AI给候选，必须经人确认后才算标签；候选与确认版本分开存储 |
| **AI·示** | AI只给提示（如重拍建议），不写成标签 |
| **AI·禁** | 不得由AI写入；在盲标环节也不向标注者展示AI/用户结论 |

标签可靠度沿用01第4.3节：T1用户事实 → T2受训标注员 → T3医生临床参考 → T4争议仲裁。

### 3.5 D. 像素标注（沿用`ml/rgb_segmentation`五类标准）

- **流程**：AI候选（SAM点选/粗定位/传统候选）→ 用户核对（T1）→ 标注员精修（T2）→ 医生审核固定测试集（T3）。AI候选与人工确认版本分别保存，永不覆盖。
- **面积占比**：由已确认mask**程序直接计算**，属AI·直；定义为`visible_lesion_fraction`，不称VASI（01第6.3节）。
- **盲标**：测试集与评估集的标注环节**不得预填AI或用户结果**，并记录每次标注的预填来源。
- **抽检**：普通样本随机20%双标；固定测试样本100%双标（01第4.3节）。

### 3.8 AI能做什么：一页汇总

| 等级 | 标签 | 现有能力 | 证据与限制 |
|---|---|---|---|
| **直**（确定性计算/元数据，抽检） | 哈希、尺寸、EXIF时间、设备、质量分、近重复候选、面积占比（由已确认mask计算）、配对可比性 | 质量门禁`vasi_quality`、`find_duplicate_image`、`ReferenceCalibration` | 质量门禁偏弱：全图清晰度、无皮肤也可能判“可接受”；拒收需人复核 |
| **辅**（AI预标注+人确认） | 皮肤/白斑mask、部位、肤色MST、拍摄类型、治疗事件提取、遮挡/反光 | SAM点选精修、AI粗定位、传统候选、旧VLM、日记AI | 内部评测多为合成图或小样本，没有对医生金标准的评测。文献：皮肤临床图上SAM类流程“人工评为可接受”约77%；没找到针对白癜风低对比皮损的定量评估。结论是预标注+人修，不是自动金标 |
| **示**（只提示） | 重拍建议、confetti等可见体征提示、近期变化提示 | 部分 | 无独立证据，不写入标签 |
| **禁**（不得写入标签） | 诊断、分型、稳定性、活动期、Wood灯、临床评分、复色分级、治疗反应 | — | 小样本研究报告的高准确率来自网络图或单中心，不能外推；活动度类研究用回忆型VIDA当标签，本身不是金标 |

## 4. 质量体系：让“最准确”可验证

1. **角色拆分**：标注员、管理员（数据负责人）、医生、仲裁医生、发布批准人五个权限，互不隐含。标注员不能把`training_eligible`置为真，也不能激活模型。
2. **盲标与双标**：医生环节看不到AI和用户标签；固定测试集100%双标；分歧由第三人仲裁；全部保留。
3. **评估集隔离**：评估集样本从不接受AI预填，并记录“预填来源”字段，防止伪标签污染。
4. **标签版本化**：每次提交生成不可覆盖的新版本，带标注者、角色、资质、协议版本、依据、耗时；取代现在“同图admin标注先删后插”。
5. **“不知道”必须是合法值**：所有字段允许“不知道/无法判断”；导出时不自动补齐。
6. **一致性度量先测后定**：像素Dice、类别kappa、医生间一致性先在首100张测出，再冻结门槛。文献显示：即使医生，不同体征的评分者间一致性差异也很大（confetti高、其他中等），不能假定所有标签都同样可靠。
7. **mimic比例**：获得临床参考的图片中至少20%覆盖正常皮肤及相关鉴别病例（01第4.4节）；由医生确认，不由AI补标。
8. **公开数据只作外部对照**：不把Kaggle/Roboflow直接并入训练；DDI仅限个人非商业研究；SCIN、Fitzpatrick17k按各自条款，且已知存在重复和标签问题。

## 5. 采集策略：数据从哪里来

| 来源 | 提供什么 | 做法 |
|---|---|---|
| SubSkin用户记录（主渠道） | 纵向手机照片、自报事实、用户核对mask | 分用途同意；先对本人有用，再邀请贡献 |

| 公开数据集 | 外部对照 | 仅在许可允许时用于评测 |
