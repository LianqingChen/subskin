# 第六十九轮：生成控制图程序配对与离线续训

日期：2026-10-30。**结论：加入生成控制图上的自动程序配对后，已观察诊断图上的小斑召回提高，但无斑误报也增加；两模型均未通过旧开发集联合门槛，不能启用。** 这是可继续研究的线索，不是对真实日记效果的证明。

## 数据与训练

按[预设方案](round69-protocol.md)，使用第61轮两张已有虚拟源 leg/hand 的6张生成控制图，每张控制图自动构造16组有斑／无斑程序配对，共96对。四种亮化比例各24对，包含大、小圆及模糊边缘；自动皮肤核心以外及不确定混合边缘标记为忽略，未使用第61轮的生成编辑候选作为标签。生成前的干预区域外像素保持不变；缩放到128后大小核心均未消失，小核心最小16像素。该小斑尺度可能大于诊断图中的最小斑。

以第68轮两个种子的普通最优权重为起点，各固定续训3轮：每轮96个新配对，加96个第47轮原训练配对回放；CE+Dice与0.1配对排序损失不变。保存最后一轮，未使用第65轮诊断图选择模型或参数。第65轮源和本次新生成训练源的文件哈希互不相同，但这些源此前在其他研究中已被观察，不是盲测。

## 已观察生成控制图诊断

沿用第66轮的512画布评估，对第65轮两张虚拟源的12个程序阳性、两张无斑控制进行续训前后对照；四模型共56次推理均成功，续训前基线逐项复现。四个低色差场景来自两源及两位置，并非独立患者。

| 指标 | 种子19：续训前 → 后 | 种子43：续训前 → 后 |
|---|---:|---:|
| 12例小核心平均召回 | 0.093 → 0.542 | 0.082 → 0.577 |
| 4例低色差小核心完全漏检 | 4/4 → 3/4 | 4/4 → 2/4 |
| 12例平均区域 Dice | 0.128 → 0.360 | 0.142 → 0.313 |
| 无斑臂部核心内预测占比 | 0.148% → 1.105% | 0% → 2.211% |
| 无斑手部核心内预测占比 | 0.082% → 0.439% | 0.103% → 0.868% |

低色差的手部两个位置续训后仍完全漏检。两张无斑图是生成器输出，可能包含生成漂移；百分比是这两张图的像素占比，不是独立患者误报率。程序参考alpha≥0.5为约定边界，不是实际病灶金标。12例平均相对面积误差 seed19 为0.807→0.417，seed43为0.817→0.685，仍相当大。

## 原开发验证及核验

第47轮320张开发图上，小核心平均召回 seed19 为0.501→0.519、seed43为0.389→0.408；阴性任意误报分别63/80→61/80、64/80→67/80。两种子仍不满足原联合验证门槛；开发集曾参与第68轮早停，与本次模型并不独立。

[数据生成](round69_prepare.py)、[续训脚本](round69_train.py)、[逐例结果与样本](round69-artifacts/)均已保存。96配对和384图／掩码哈希核验，干预局部性及位置安全两项测试通过（pytest有 asyncio 配置警告）；438个归档文件、模型哈希和来源哈希检查通过，registry前后相同且禁用。未启用、修改共享后台或部署。

模型仅在虚拟图和程序标签上训练，没有真实患者照片或人工病灶标注；生成模型的预训练数据来源未知。新增生成控制、采样和续训同时改变，不能单独归因。两张重复观察的诊断源、与C共享的阳阴图及约定性圆形边界不足以证明真实场景效果、临床测量精度或99.99%。下一步应优先降低无斑误报并保持新增的小斑召回，同时固定方法，在更多来源隔离、未用于调试的虚拟图上验证；真实效果仍需可信的独立真实场景评估。
