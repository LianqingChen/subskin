# 第六十五轮：新增生成控制与完整区域评分

日期：2026-10-30。**结论：换用另外两张虚拟源及六张新生成控制图后，单差分和平滑差分各仅有 2/12 场景通过全部预设条件；不能作为自动训练标签。** 整体区域重叠度高也可能掩盖小斑完全漏检。

## 试验方法

按[预设方案](round65-protocol.md)，对虚拟源 test24-arm 与 test24-hand 分别调用内置 imagegen 三次，生成要求不改变皮肤、光线及背景的控制 A/B/C。两张源此前在第24轮被观察，但未用于第56–64轮差分测试，因此这是换源开发性检查，不是完全未见过的最终测试。六次均成功；[原图、控制图、确切提示及哈希](round65-artifacts/input-provenance.json)已保存。

分别在未对齐 C 图叠加大／小已知程序色变，三种色差和原／镜像位置形成每源6例；配准时同步变换参考 alpha。比较第62轮单差分与第64轮 σ=2 平滑差分，原有核心精度、大小核心召回、控制变化与未知门槛不变。新增以变换后的 **alpha≥0.5** 作为约定性完整区域参考，要求确认掩码 Dice≥0.8 且面积相对误差≤20%；该边界是合成规则，不是医疗金标。两个方案共24条记录，均完成处理。

| 来源及情况 | 单差分 | 平滑差分 |
|---|---:|---:|
| 总通过场景 | 2/12 | 2/12 |
| 手部原位置低色差：完整区域 Dice | 0.255 | 0.903 |
| 同一场景：小核心确认召回 | 0.018 | 0 |
| 手部镜像低色差：小核心确认召回 | 0.055 | 0.691 |
| 手部镜像低色差：完整区域 Dice | 0.015 | 0.508 |
| 手部原位置高色差：面积相对误差 | 7.3% | 35.4% |

两方案通过的是不同场景：单差分通过手部两例高色差，平滑差分通过手部两例中等色差。上述 Dice=0.903 的平滑场景仍因小核心召回为0等条件而失败。手部阴性控制右半确认变化为0%，仍无法保证低色差小斑被识别；低控制变化和高整体重叠均不足以单独证明可靠。

## 复核及限制

[逐例结果、完整参考和预测图](round65-artifacts/completed/)、[脚本](round65.py)已归档；完整区域指标的两项自动测试通过（pytest 有 asyncio 配置警告），缺失输入预检将所有对应场景记为失败。8 个输入及73个输出文件哈希验证通过，registry 前后哈希一致且禁用；没有训练、启用或部署。

本轮程序色变不是生成模型编辑产生的真实病灶真值；阳性与阴性共享 C 图，两来源、各色差和位置也不能视为独立患者样本。模型预训练数据来源未知，无法保证预训练未使用真实患者图。模拟结果不能证明真实日记识别精度、医疗测量可靠性或99.99%；要证明真实使用效果，仍需可信的独立真实场景评估。下一步应避免继续只在这两批小样本上调整阈值，扩大独立虚拟来源与拍摄变化，并预先固定逐斑、完整边界和面积指标；保持未确认区域的独立处理。
