# 第八轮预设方案：生成手臂轮廓与自动标签

在任何模型评估前固定。通过图像生成模型独立生成两张虚拟手臂、纯青色背景图，分别用作训练和测试；采用程序按青色阈值和图像边缘连通性提取背景，自动推导皮肤范围；轮廓附近标记 255 忽略，统计忽略比例。无真人照片、无人工病灶圈选；自动皮肤掩码不保证真实金标准，生成模型和 SAM 预训练来源未知。

训练、测试各从不同生成图生成 128、64 个具有透明边界处理的仿真图：旋转/缩放自动提取的轮廓，替换青色底为随机背景，自动合成色减退候选、不可判读高光、遮挡，并生成五类标签（背景、正常、浅色候选、遮挡、不可判读），边界不确定为 255。仅在有效像素评估 Dice、面积比例误差及无病灶误报；记录忽略比例、预测皮肤为空数量，面积定义保持第七轮。合成几何、背景、遮挡和标签仍不是真实医学图像；不将有效像素结果冒充全图准确度。

比较第七轮两个 seed 的冻结 U-Net 与 SAM 五类模型（不修改权重），以及分别使用新增训练集从头训练的相同结构、同 seed 的 U-Net 和冻结 SAM 五类头；每组训练 128 张、15 轮、相同类别权重，忽略 255。全部用相同新测试图比较，不根据测试调整参数。测试图只来自一个独立生成底图的相关变体，非 64 个独立用户；与第七轮变化包含形态、皮肤来源和标签机制，不能单独归因。

青色提取检查：背景需覆盖四角，剩余掩码面积需在 10%～90%，对每图记录提取掩码和不确定边缘预览；若基础自动提取明显错误、255 像素比例过大或出现虚假白斑区域，停止并记录。预先统计合成各类、正负例、标签互斥、来源哈希和有效区域分母。离线研究，不启用模型，不改后台或生产。

第一张候选测试图 `test8-arm.png` 在右上和左下角不是青色背景，未通过预设四角条件；在模型训练和评估之前排除它，并生成新的独立测试图。该次排除基于预先写出的自动掩码有效性门槛，不涉及模型性能。
