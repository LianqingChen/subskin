# 第十七轮预设方案：离线调用现网推理与候选模型

目标是把先前只比较分割头的研究接到日记页的真实纯函数链，仍只用自动合成图和掩码，不访问患者图片、人工白斑标签、数据库或线上 API。事先固定两张新 image_gen 虚拟底图（手臂、无指甲手背），按 r8/r9 自动青幕分割并构造程序色块、背景、遮挡和 255 忽略带，每底图 32 张、种子 1100000 和 1200000 起；来源必须与训练源哈希不同。每张原始程序图为 64×64，以最近邻放大到 512×512 再按 `canonical_image` 读取，模拟工作输入大小但保留了低分辨率块状细节，不代表高分辨率真实照片。放大标签也采用最近邻；记录有效/忽略比例和阳性阴性数量。

用只读本地进程调用实际的 `frame_information_lost → infer_rgb → apply_soft_quality → measure_rgb(reviewed=False)`；不调用持久化任务处理、数据库或部署。模型 registry 事先必须 disabled，并固定其哈希；实际 `infer_rgb` 会根据 MediaPipe 是否识别人物自动选择解析或交互回退，逐例记录真实返回的 source，不以假解析替代。若硬质量检查拒绝或测量策略要求重拍，按产品行为保留拒绝记录，不将它当作正确测量。测量策略在未经用户复核时应保留 review_required，研究中另对算法掩码计算显式标明非产品输出的候选像素占比，不伪造 reviewed=True。

候选对照使用第九轮两份 SAM 加权 CE 头和第十轮两份 CE+Dice 头（哈希核对），使用同一冻结 SAM 256 编码及 64 输出 logits，将 logits 双线性放大后按照 `infer_rgb` 当前的 argmax、最大概率 <0.7 标为 uncertain、3/4 类 excluded 的相同规则映射为皮肤/病灶/不确定/排除，再调用相同质量和测量策略。此映射为离线模拟，候选不是当前 registry 中 TorchScript 模型，不假称已接入线上。

仅对未被质量拒绝的样本统计程序标签有效像素内的皮肤 Dice、阳性病灶 Dice、病灶像素精确率/召回率、无病灶误报、候选占比与合成参考占比的绝对误差、未确定区域、质量拒绝和政策状态。拒绝、空预测和 255 像素都单独计数；这些不能视作正确。按手臂/手背分别报告，以及实际推理返回的 source 分布。模型与现网真实流程同时评估条件是输入一致、输出与策略均成功；不选择性删去弱样本。发生依赖失败或与生产版本不一致明确记录，不得称生产等价或上线依据。

每类仅一张新 AI 生成底图的 32 个相关样本，合成掩码来自程序，不是真实白癜风参考，无法支持真实人群准确率及 99.99%。生成模型、SAM 与 MediaPipe 的预训练来源无法核实是否包括真实病例。无部署、无后台服务重启、无用户数据写入。

运行后发现现网交互式回退有意将区域保留在 uncertain 而非 lesion 层；为避免把它误称“没有任何候选”，新增事后诊断 `proposal = lesion ∪ uncertain`，重跑相同图像、阈值和政策，并保留首次输出。该合并仅为离线覆盖率检查，未经用户复核，不是现网可测量结果；不得用其冒充产品测量。
