# 第三轮：生成式虚拟底图与 SAM 特征探索

日期：2026-10-29（Asia/Shanghai）

## 结论

本次受控合成测试中，预训练 SAM 特征组在单张独立虚拟底图的裁剪上表现高于随机初始化 SAM 对照，在固定色偏下表现更稳定。这是早期探索信号，不是白癜风真实识别的准确率，也不能证明 99.99% 目标；生成机制简单、底图只有一张、未评估真实患者或端到端流程。

## 数据与方法

内置图像生成工具生成三张虚拟无明显病灶皮肤图，medium、light、dark 分别只用于训练、验证、测试；基于随机裁剪程序叠加形态和强度可控的浅色模拟区域，自动产生 `alpha >= 0.5` 的合成编辑区域掩码。分别生成 128、64、64 张；测试包含 47 个正例、17 个无斑例，其中 13 个小斑。程序编辑区域标签不保证等于临床白癜风范围。测试是一张虚拟底图的相关裁剪，绝不能当作 64 个独立人群样本。

比较从零训练的 RGB 小 CNN、冻结随机 SAM ViT-B + 分割头、冻结预训练 SAM ViT-B + 同结构分割头，各训练 15 轮、两个随机种子。SAM 输入缩至 256×256、位置编码从 64×64 插值至 16×16；这不同于 SAM 的标准 1024 输入。两组冻结 SAM 的分割头结构相同；CNN 是轻量参考。阈值仅用验证集选取，优先无斑平均误报面积 ≤2%，从可行阈值选最高正例 Dice。

训练/测试未使用实拍图片或人工白斑掩码；图像生成工具和 SAM 的预训练来源无法核实是否包括白癜风相关图片，因此不能声称模型全生命周期绝对未见过真实患者图。生成式模型只生成皮肤底图，模拟斑块与标签由程序生成；这并非已实现生成模型直接输出可靠病灶和掩码。

## 样本与工具来源

- `generated/train-medium.png`、`val-light.png`、`test-dark.png` 是内置图像生成工具分别生成的无明显病灶虚拟皮肤，未输入真实用户图；对应 SHA256 记录于 `round3-results.json`。
- 另一张 `generated/direct-unlabeled.png` 是图像生成工具直接生成的虚拟浅色斑块示意图。它不含可信像素掩码，未用于本轮训练、验证或测试，不代表医学真实性。
- SAM 权重 SHA256：`ec2df62732614e57411cdcf32a23ffdf28910380d03139ee0f4fcbe91eb8c912`。 CPU 运行约 265.51 秒；依赖与复现命令见 `README.md`。
- 底图来源、掩码非空及确定性、分区哈希与种子范围已通过两项自动检查。

## 局限与下一步

1. 扩展由不同提示和独立生成调用产生的底图数量，并按生成来源而非裁剪划分；保留未用于模型选择的全新测试组。
2. 降低模拟斑块的轮廓和合成规则特征依赖，覆盖浅色高光、阴影、自然肤色差异、弱对比、多个部位与遮挡；验证不同生成机制、照明变化和假阳性。
3. 用统一的真实日记端到端输入约定验证皮肤、遮挡和白斑分割；本轮假定全图皮肤，只支持二分类。
4. 明确 99.99% 的指标口径（如逐图 Dice、病灶召回、误报、面积误差），并以独立样本及可信参考衡量。仅凭未标记合成图、像素准确率或单图裁剪无法证明真实患者照片上达到该值。此前真实图像及标注仅用于评估的授权问题仍无答复，本轮未使用。
