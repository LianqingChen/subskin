# 第六十三轮：双生成控制亮度均值基准

日期：2026-10-30。**结论：使用两张生成控制图的亮度均值，在这批已观察开发样本上没有提高通过率，且部分低色差小斑召回下降；目前不应作为自动训练标签。** 第 62 轮单控制基线的全部已处理逐例指标与阈值已复现。

## 试验

沿用[第 62 轮](round62-report.md)两张虚拟源及其生成控制 A/B/C、12 个已知程序干预场景、配准和门槛，不重新训练或生成图片。按[预设方案](round63-protocol.md)，原方案使用 A 的 Lab 亮度作为对比基准；候选方案使用 A、B 各自 Lab 亮度的浮点均值。两个方案都用 B−A 校准确认/未知阈值及局部不稳定性，独立生成的 C 图用于阴性检查；正例为程序干预后的同一 C 图。真实生成病灶无独立参考，因此这些数值只评价程序干预。

| 指标 | 单控制基线 | 两控制均值 |
|---|---:|---:|
| 全部质量门槛通过 | 5/12 | 5/12 |
| 干预位置不合格、拒绝处理 | 3/12 | 3/12 |
| 腿部低色差原位置：小核心确认召回 | 0.107 | 0.161 |
| 手部低色差原位置：小核心确认召回 | 0.309 | 0.145 |
| 手部低色差镜像：小核心确认召回 | 0 | 0 |
| 腿部低色差原位置：小核心确认∪未知覆盖 | 0.643 | 0.804 |
| 手部低色差原位置：小核心确认∪未知覆盖 | 0.545 | 0.491 |

控制右半确认变化：腿部 0.066%→0.039%，手部 0.0067%→0%。**控制指标更低并没有保证低色差召回改善。** 高色差腿部场景确认精确率从 0.735 到 0.751，仍低于 0.8 门槛。未知覆盖不是确认圈选结果；混合边缘不计入评分，不能说明完整边界准确度。

## 复核与局限

[逐例结果](round63-artifacts/completed/results.json)、[研究脚本](round63.py)与确认/未知图已归档；原基线各项指标复现，37 个归档文件哈希验证通过，两项测试通过（pytest 有 asyncio 配置警告），registry 保持禁用且前后哈希一致。未训练、启用或部署模型。

这只是对两个已观察虚拟来源的开发性配对分析；A/B 同时用于均值与校准，正负样本共享 C，同一源的场景不独立。由于多次尝试使用同一批数据，不能把任何局部提升当成泛化证据。程序合成变化并非真实生成编辑病灶的独立真值，模型预训练数据来源未知；不涉及真实患者图片或人工圈画，但也无法估计真实白斑识别率、面积误差或 99.99%。下一步需要独立来源、独立对照及预设方案，重点测试低色差的信号强度与伪影之间的可分性；通过前不将候选用于训练。
