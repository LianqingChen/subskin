# 第十轮预设方案：病灶重叠损失与跨部位评估

在模型输出前固定。对照是第九轮 `round9-heads` 中的两个 SAM 五类头：以 64 张虚拟手臂、64 张虚拟手背合成图、固定 15 epoch 和加权交叉熵训练。实验组使用完全相同的 128 张、模型、优化器、类别权重、批次、随机种子和轮数，仅在加权交叉熵上增加 0.5 倍病灶软 Dice 损失；只对有病灶像素的训练图计算 Dice，255 区域从两项损失排除。此设定用来检验区域重叠信号能否改善精确率和召回，不代表模型已应用至日记页。

由内置 image_gen 独立生成两张新虚拟青幕底图：一张手臂、一张无指甲手背；不使用真实患者图片、人工病灶标注。按第八/九轮方法自动提取背景与皮肤，检查源哈希、青幕条件、轮廓预览、五类齐备、正负例及忽略比例；平均忽略 >20%、自动轮廓明显不正确或标签不足即停止。每张底图 64 张程序合成测试图，两类均按 255 忽略像素计算皮肤 Dice、病灶 Dice、病灶微精确率/召回、无斑误报和占比误差。另计算 2 像素边界 F1：忽略区及其一像素邻近区域不参与边界构造，对有有效真值病灶边界的图片平均，并报告可计算数量。边界是合成编辑区域边界，非临床边界。

旧模型哈希必须与第九轮结果匹配，两个新组种子为 0 和 1；冻结预训练 SAM 和 256 输入、位置编码插值均不变。不针对新测试结果调参；每组 64 张只来自一张生成图，不是独立患者。对照组及实验组分别有两个初始化，报告所有结果，不作统计显著性声明。底图、自动轮廓、程序斑块都只是仿真；生成模型及 SAM 预训练资料不能证明未包含真实白癜风照片。不部署、不声称真实 99.99%。
