# 第九轮预设协议：虚拟手部形态扩展

预先固定目标：检验自动生成的手部样本是否改善未见虚拟手部的五类分割；不声称真实患者效果。使用两个独立 image_gen 调用生成虚构手部训练和测试图，纯青色背景，均未提供患者照片。自动青色分割按第八轮 `source()` 实施，四角必须为背景、皮肤面积 10%～90%，并检查轮廓预览。若自动分割明显错误、测试集的平均忽略像素大于 20%、五类或正负例缺失，则停止并报告，不以删选模型表现弥补。

比较两个预训练 SAM 编码器加相同五类头：对照组加载第八轮两个保存头（原始 128 张均来自虚拟手臂）；多形态组从头以 64 张同一虚拟手臂样本及 64 张新虚拟手部样本训练，15 epoch、类权重、优化参数、随机种子与第八轮一致，合计 128 张。训练、测试每张来源的图哈希不重复，自动生成种子互不重合。训练素材数和形态同步改变，结果只说明该具体组合的区别，无法归因于单一部位。

保留测试只用新生成虚拟手部底图，64 个程序化合成样本（五类及忽略边界），不在测试集选权重或调参。对相同样本按第八轮有效像素协议报告皮肤 Dice、阳性病灶 Dice、微平均精确率/召回率、面积占比绝对误差、无斑图平均误报面积和忽略比例。另在先前已公开的手臂测试素材上作开发性回归，不能当盲测。每类 64 图源于单个生成素材及可重复的程序编辑，互相关联，不是独立患者样本；用图像生成模型合成手部与程序合成病灶、伪标签的临床真实性未经验证。预训练模型可能见过真实患者图像，来源无法核实。研究权重不上线。

模型训练前的源图质量检查发现第一对候选图有指甲，青色背景法会把指甲误标为皮肤，因此依据预设的“自动分割明显错误则停止”条件排除。重新生成仅含手背和部分手指、无可见指甲的图，并进行同样检查；若仍出现明显指甲或边界不可信，停止而不把伪标签当金标准。此排除不依据模型结果。

在任何模型训练/评估之前，预览显示原先的角落连通域方法漏掉与角落不连通的指间青色背景，错误标成皮肤。依预设标签质量门槛停止；针对青色生成手部，改为对图中所有满足同一青色阈值的像素直接标为背景，然后重新执行轮廓预览和 20% 忽略率检查；手臂源图仍使用原方法。该修订基于数据质量问题，而不是模型结果。此方法只适用于这种人工青幕生成图，色边仍需忽略。
