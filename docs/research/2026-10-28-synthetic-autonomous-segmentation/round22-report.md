# 第二十二轮：增强病灶训练损失的对照结果

日期：2026-10-30。结论：**本轮没有找到可用的改进；新增病灶损失使原始分割指标和面积误差变差，不能推广到日记页。** 这是合成图上的探索性结果，既不能证明真实患者照片有效，也不能证明无效。

## 方法与数据

按 [预设方案](round22-protocol.md)，固定第 20 轮对照组的 192 张合成训练图、32 张合成验证图、网络、训练设置和种子，逐项核对训练及验证样本的图像和掩码哈希。对照模型使用原始 CE + 五类 Dice；候选模型额外加入 0.5 倍的阳性图病灶软 Dice。模型选择使用各自的验证损失，因此早停和最佳 checkpoint 也可能不同：对照训练 13 轮，候选训练 9 轮。这是训练损失及 checkpoint 选择的联合比较，不是仅修改权重而其他一切保持相同的严格比较。

新测试集由两张不同于前两轮及训练/验证来源的 AI 虚拟底图自动生成，共 32 张，23 张阳性、9 张阴性；程序生成的病灶掩码是参考，12.13% 像素被设为忽略。合成先在 64×64 进行，再放大至 128×128。没有真实患者图和人工病灶标注。两个来源内的变体彼此相关，不能当作 32 个独立病人，也未做多随机种子试验。

## 项目 evaluator：原始 argmax 输出

| 指标 | 原训练方法 | 加病灶 Dice |
|---|---:|---:|
| 阳性图平均病灶 Dice（23 张） | 0.399 | 0.265 |
| 阳性图平均召回率（23 张） | 0.442 | 0.391 |
| 阴性图至少一处误报（9 张） | 8/9 | 9/9 |
| 白斑面积占比平均绝对误差（32 张，百分点） | 4.08 | 11.28 |
| 模型推理失败 | 0 | 0 |

Dice 和召回越高越好，误报和面积误差越低越好。面积误差是分割预测占比相对程序参考占比的差异，**不是患者体表面积的临床测量误差**。

策略组的 Dice 和召回仅计算已处理的阳性图，分母不同；未处理的 3/2 张不能忽略为成功。候选的阴性误报虽降至 0，但阳性召回同时下降，且没有图片自动输出面积；这不能解释为实现了可靠识别和测量。上述策略是离线模拟，未对用户运行。

## 后续判断

当前证据只说明自动合成与训练流程可以运行，未证明能显著提升真实白斑识别，也无法验证 99.99% 准确率。下一步宜先研究阴性误报和病灶形态偏差，预先固定多个生成源和多个训练种子，分开记录病灶召回、负例误报和拒绝率；不要用本轮测试集反复调参。即便合成指标改善，真实场景的准确度仍需要独立、可信的真实场景参考才能确认；在用户当前约束下不能声称已完成临床验证。
