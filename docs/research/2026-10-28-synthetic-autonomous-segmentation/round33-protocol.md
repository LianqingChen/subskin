# 第三十三轮预设：同形状逐级色差响应

固定第30轮 seed43 原配对训练模型和第27轮 control seed43 白斑加权模型，均为未通过验证门槛的研究模型；不修改、不选择、不训练。用全新 imagegen 虚拟手臂和手背各生成8组自动合成有斑/无斑对，每组基于 round29 同源同变换及遮挡的程序生成器。每组构造四档图：无斑 clean，以及 clean + (positive-clean)×0.25、×0.50、×1.00；统一128×128，正例核心掩码一致、模糊边缘忽略（255），无斑使用 clean 的正常掩码。允许亮度低到人眼不可辨，程序核心标签是干预参考而非可见性或临床真值。跨档同源图高度相关，共16组、64图，不是独立患者。

每档统计程序白斑核心处合成图与同组无斑图的平均 CIE ΔE76（OpenCV 浮点 sRGB 转 Lab，非光谱测量）；报告数值是该干预的像素色差，不是皮肤颜色校准。原版 project evaluator 按四档分别报告阳性 Dice/召回、无斑图任何误报、面积占比误差、逐部位、失败；0.7 未复核日记策略另行记录正式白斑召回、重拍、复核及面积释放。冻结模型和档位、所有样本保留，不依测试调整。确保两个新来源与所有已归档底图及训练验证来源哈希不同。不得以低色差条件的未确定当作正确识别，不能声明统计显著、真实场景有效或99.99%。

图像生成、程序标签均不使用真实患者照片和人工白斑标注，生成模型预训练来源未知；未改后台或 registry、registry disabled 且哈希前后一致，不部署。
