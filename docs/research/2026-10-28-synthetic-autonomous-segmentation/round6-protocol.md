# 第六轮预设方案：模型分歧与选择性预测

目的：评估上一轮保存的四个 SAM 分割头能否用模型分歧提示用户核对，重点同时报告覆盖率与未拒判错误，禁止把拒判当成预测正确。该研究不重新训练，也不修改模型。图像、掩码均为合成素材；用户病例未使用。SAM 和图像生成模型的预训练来源仍未知。

使用 `round5-heads` 中 original 和 hard_examples 各两个种子；SAM 编码器与前一轮一致，输入 256、位置编码插值。四个概率图均值在固定阈值 0.90 生成候选；0.90 是上一轮各模型预设回退值，并未达到误报门槛，故无拒判基线本身不可上线。

图像级不确定性得分定义：计算原始训练组两个头的平均概率，与困难训练组两个头的平均概率逐像素绝对差，取全图第 95 百分位。分歧大则拒判；此分数是启发式，不是校准后的错误概率。利用第四轮已公开、现作开发/校准用途的 test4-light 和 test4-dark 两张生成底图，各 32 张标准斑块、32 张弱斑块、32 张高光负例；在这 192 张校准图的得分上分别确定 20%、50%、80% 分位阈值。阈值一旦固定，不根据新测试图调节。

保留测试用全新 image_gen 虚拟底图，仅用于测试；生成 32 张普通斑块、32 张弱斑块、32 张高光负例，使用第五轮非多边形几何和新种子。按各阈值分别报告实际图像覆盖率、正例条件 Dice 与像素召回、高光负例误报超过图像 1% 的比例、各类的拒判率及拒判作为不可用结果计算的全体正例有效召回；无样本时记 null。对照不拒判（覆盖率 100%）。校准和测试底图哈希、生成种子、标签检查；样本图像来自一张底图的相关裁剪，不能统计推断真实患者人群。

不同合成病灶与高光可能在视觉上不可区分，弱斑有时不可见；模型分歧不能保证捕捉共同的自信错误。测试仅限合成图片、全图皮肤二分类，不能证明真实日记端到端表现、自动测量安全性或 99.99% 准确率，不部署。
