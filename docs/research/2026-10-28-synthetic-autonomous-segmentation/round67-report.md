# 第六十七轮：冻结模型重叠小块推理

日期：2026-10-30。**结论：在同一批虚拟开发图上，128像素重叠分块推理没有找回任何低色差小斑，不能解决第66轮的漏检。** 四模型的整图基线逐例复现；所有112条配对推理记录成功。

## 试验和结果

按[预设方案](round67-protocol.md)，保持第66轮的四个冻结模型与12张程序阳性、2张生成阴性不变。整图基线用研究评估函数对512画布推理；候选将画布分为128×128、步长64的49个重叠块，对各块5类概率逐像素等权平均，再取最大类别。所有阈值和权重固定；阳性、阴性均同样处理。模型训练时将整图缩小到128，**裁取128块与训练时整图缩放不是同一输入尺度**，且分块改变可见上下文和 GroupNorm 统计，不能把差异归因于单一因素。

| 模型 | 小核心平均召回：整图→分块 | 小核心完全漏检：整图→分块 | 无斑手部核心内预测占比：整图→分块 |
|---|---:|---:|---:|
| mixed-19 | 0.258 → 0.128 | 8/12 → 10/12 | 1.33% → 0.41% |
| mixed-43 | 0.302 → 0.220 | 7/12 → 9/12 | 1.69% → 0.84% |
| safe-19 | 0.207 → 0.185 | 8/12 → 9/12 | 0.41% → 0.50% |
| safe-43 | 0.057 → 0.147 | 10/12 → 10/12 | 0.49% → 1.25% |

四模型在4个低色差场景均为 **4/4 小核心完全漏检**，分块前后不变。safe-43 平均召回上升，但完全漏检数量未减少，且手部无斑控制预测占比上升。平均完整区域 Dice 整图→分块依表中模型顺序为 0.239→0.135、0.250→0.193、0.256→0.189、0.116→0.148；平均面积相对误差分别为 0.630→0.708、0.760→0.534、0.622→0.693、0.714→0.751。各指标均针对程序参考，并非真实体表测量误差。

## 复核及限制

[逐例结果及分块预测](round67-artifacts/completed/)、[研究脚本](round67.py)已保存；整图基线逐项复现，分块覆盖与尺寸拒绝的两项测试通过（pytest 有 asyncio 配置警告）。57个本轮输出及73个前轮输入文件哈希核验通过，模型和源图哈希与前轮一致，registry保持禁用且前后哈希相同。未训练、启用或部署。

仅两张已观察虚拟源，同一 C 生成控制被多个正例复用；程序化 alpha 边界是约定而非医疗病灶真值。该分块方法也不是现有日记页面的生产流程，不能外推真实患者或99.99%准确率。下一步应优先探索提高低色差信号与无斑纹理可分性的训练策略，再以来源隔离的虚拟图和完整边界、逐斑和误报指标验证；真实场景效果仍需独立可信的真实场景评价。
