# 无真实病灶和人工标注训练：合成试点报告

日期：2026-10-29（Asia/Shanghai）

## 问题与边界

探索仅靠程序生成的图像及自动掩码训练白斑候选分割的技术管线。此次没有读取真实白癜风照片或人工病灶标注，也没有使用真实正常皮肤照片；所有训练、验证与测试图像均由程序生成。没有用预训练模型，因此本试验不是大模型自主学习的结果。未部署、未修改现网注册配置。

本实验是受控仿真，而不是临床准确率评测：64×64 的图仅是颜色、平滑噪声、斑块与光照干扰，没有真实纹理、人体轮廓、背景、遮挡或手机拍摄细节。测试换用了多椭圆斑块而不是训练的极坐标形状，但仍共享其他生成假设。见 `samples.png`。标注是合成定义的掩码，不代表医学真值。

## 方法

冻结现网 `draft_lesion` 为 `baseline_lesion_draft.py`，SHA256 为 `a820d3529ac83e308fe44a9fe280a9297559f09b1cda69fc9dc92cd5f4445e06`。评测时人为提供全图皮肤范围，只比较白斑初稿算法；这不是 `infer_rgb` 的端到端结果。

512 张训练、128 张验证、128 张测试，生成种子集合分离，正样本 91、无斑 37，小半径正样本 43。四种方法都使用同样结构的轻量 CNN，随机初始化，不依赖预训练：simple 为简单合成；diverse 增加形状和干扰；diverse_augmented 再加入光度增强；diverse_consistency 再加入一致性损失。训练各运行种子 0、1。每次只在验证集上以正例 Dice 最大选择阈值，没有把负例误报纳入选择目标；报告无斑样本误报面积以及全图面积占比误差。训练运行环境为 CPU、Python 3.14、PyTorch 2.13.0+cu130、OpenCV 5.0.0、NumPy 2.5.2。

## 数据检查

生成器确定性、图像及掩码形状、二值标签、无斑图掩码为空、分区种子不重叠的 2 项自动测试通过。第一次试跑的独立 RGB 采样产生明显不自然的绿色样本，已终止、舍弃，改为肤色近似色板插值后重新运行。近似色板仍不能证明样本具有医学真实性。

## 结果

### 5 轮训练（探索性）

每格两个数字分别为随机种子 0 和 1；无斑误报为无斑图片中平均被错误预测为白斑的面积百分比。

| 方法 | 正样本 Dice | 小斑 Dice | 面积绝对误差（百分点） | 无斑误报面积（%） |
|---|---:|---:|---:|---:|
| 现网白斑初稿（理想皮肤） | 0.403 | 0.045 | 15.35 | 17.72 |
| 简单合成 | 0.679 / 0.379 | 0.544 / 0.177 | 4.42 / 21.01 | 5.13 / 20.72 |
| 多样合成 | 0.567 / 0.418 | 0.409 / 0.202 | 3.40 / 19.07 | 3.46 / 18.38 |
| 多样 + 光度增强 | 0.538 / 0.385 | 0.344 / 0.196 | 3.45 / 20.02 | 3.52 / 19.86 |
| 多样 + 增强 + 一致性 | 0.554 / 0.382 | 0.421 / 0.176 | 2.47 / 18.98 | 1.13 / 18.67 |

### 15 轮训练（探索性）

每格两个数字分别为随机种子 0 和 1；无斑误报为无斑图片中平均被错误预测为白斑的面积百分比。

| 方法 | 正样本 Dice | 小斑 Dice | 面积绝对误差（百分点） | 无斑误报面积（%） |
|---|---:|---:|---:|---:|
| 现网白斑初稿（理想皮肤） | 0.403 | 0.045 | 15.35 | 17.72 |
| 简单合成 | 0.731 / 0.584 | 0.603 / 0.367 | 1.55 / 3.38 | 0.87 / 3.46 |
| 多样合成 | 0.760 / 0.717 | 0.666 / 0.587 | 1.50 / 1.69 | 0.70 / 0.81 |
| 多样 + 光度增强 | 0.729 / 0.712 | 0.622 / 0.592 | 1.72 / 1.67 | 0.86 / 0.71 |
| 多样 + 增强 + 一致性 | 0.753 / 0.730 | 0.649 / 0.629 | 1.53 / 1.65 | 0.64 / 0.73 |

5 轮时部分种子无斑误报面积接近 20%，15 轮时多样合成及其增强组的两次结果波动有所减小；简单合成仍有较大差异。15 轮时，一致性组与单独增强组在此测试集上数值不同，但只有两个种子，且复查使用已观察过的测试集，不能判定一致性在真实场景有效或具有统计显著性。

训练图像、标签与生成器对测试集有天然结构匹配，现网规则未针对这些仿真图调优；合成网络高于规则不能视为真实日记页的提升。


## 解释边界

- 现网对照调用相同算法源码，但使用本机 OpenCV 5 而非报告提到的远端环境；仅作受控方法对照，不能称作生产线上效果。
- 按验证集的正例 Dice 选阈值，可能容忍无斑样本误报；未来应预先约束负样本误报，在验证集内确定可行阈值，再在独立测试上冻结评价。
- 15 epoch 复查是在看到 5 epoch 测试集表现后安排的，两个结果均为探索性；此测试集已不适合做最终模型选择的盲测。
- 不同随机种子、合成训练和测试仍共享工程假设；观察到的收益不能推广到真实照片，不能用于诊断或决定用户病情变化。
- 本次没有评估身体部位、肤色群体、公平性、皮肤范围误差、真实面积、重复拍摄及真实白斑识别。

## 后续工作

1. 建立新的合成器和未使用过的测试种子：至少在纹理、斑块形态、背景、噪声、光照与样本来源等方面独立；并预注册正例重叠和无斑误报的联合门槛。
2. 检验预训练视觉编码器：项目有 SAM ViT-B 权重，但本机缺少 `segment_anything`、`torchvision`，仍需解决运行依赖、计算成本及训练来源披露；无法仅据现有材料排除其预训练见过目标病灶。与随机初始化模型做等条件消融。
3. 增加可控皮肤轮廓、非皮肤、遮挡与不可判读区域；执行真正端到端的五类分割。加入成对拍摄变化验证与全新保留集。
4. 如果用户允许已有真实病例和标注仅用于最终独立测试，则在训练与模型选择完全冻结后，按人分组开展独立评估，明确授权；否则仅报告合成和一致性结果，不能声称真实场景准确率显著提升。

完整脚本、配置、复现说明与机器可读结果见同目录 README 和 JSON。两次使用同一测试集，不得择优当作盲测。
