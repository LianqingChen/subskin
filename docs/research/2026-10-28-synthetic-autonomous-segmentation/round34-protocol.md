# 第三十四轮预设：弱色差配对训练

固定第29轮 96 对自动合成训练图、配对顺序、数量（192、阳/阴各96）、原掩码、验证集；对每个底图的24对按 pair id 排序轮流将正例修改为 clean+(positive-clean)×0.25、×0.50、×1.00，各8对（总32/32/32）；无斑图不变。掩码与正例形状均为程序干预参考，弱色差可能不可见，本轮没有观察者验证，该标签不等同临床病灶。两组所有参考掩码、背景、无斑训练图和验证图一致，只改64张正例图的强度。与第30轮原配对 batch 训练相同架构、优化器、原损失、同步增强、随机种子19/43及早停；对照复用第30轮对应冻结权重，候选从头训练。第26轮已定门槛25验证阳性平均召回≥0.30且7阴性最多2张误报；无通过则不产生gated模型。验证集也被用于早停，负例数量少且相关，不是临床门槛。

新生成另两张 AI 虚拟底图，仅用于第33轮相同配对生成机制的64张四档保留测试（16组各 0、0.25、0.50、1.00）；与所有先前虚拟来源及训练验证哈希隔离，测试机制已知但新底图未用于训练及模型选择。冻结模型和规则后分别用项目 evaluator 和原0.7未复核策略比较每档 Dice、召回、16张阴性任意误报、面积误差、重拍、复核及正式面积输出；同组跨档高度相关，不能当独立患者。不基于测试改权重、阈值或挑模型；所有失败如实保留，报告合格模型及普通最优模型，后者未通过不得用作上线建议。

只有两个随机种子、两个合成测试源及相同程序病灶生成机制，训练与测试伪标签并非临床真值，生成模型预训练来源未知；不能推断真实效果或99.99%。不使用真实患者照片、人工白斑圈选；研究模型 synthetic、registry禁用且哈希不变，不修改共享后台或部署。
