# 第六十四轮：固定尺度平滑差分

日期：2026-10-30。**结论：固定尺度平滑改善了部分低色差小斑覆盖，但误检增加，整体通过率下降；不适合直接作为自动训练标签。** 12 个预设场景中单控制基线通过 5 例，平滑方案通过 4 例；两方案均有 3 例因位置超出皮肤核心被拒绝。

## 试验

依照[预设方案](round64-protocol.md)，沿用第62轮两张虚拟源、生成模型产生的 A/B/C 控制、12 个程序化已知干预场景和相同配准。基线以 B−A 校准、C−A 检查阴性漂移、E−A 产生正例差分；候选对这三种 Lab 编码亮度差分均采用 σ=2 像素高斯平滑，然后沿用相同阈值规则及质量门槛。已知大小核心仅用于评分，未用于预测。第62轮各成功场景的基线指标及阈值均复现。

| 指标 | 基线 | 平滑 |
|---|---:|---:|
| 全部条件通过 | 5/12 | 4/12 |
| 腿部低色差原位置：小核心确认召回 | 0.107 | 0.804 |
| 腿部低色差原位置：小核心确认∪未知覆盖 | 0.643 | 0.946 |
| 腿部低色差原位置：确认精确率 | 0.602 | 0.691 |
| 腿部中等色差原位置：确认精确率 | 0.931 | 0.658 |
| 腿部高色差原位置：确认精确率 | 0.735 | 0.352 |
| 手部低色差镜像位置：小核心确认召回 | 0 | 0 |

腿部控制图右半确认变化为 0.066%→0.385%；该值依然低于1%控制门槛，但正例精确率仍明显下降。低色差腿部小斑找回更多像素，精确率却仍低于0.8门槛；手部镜像低色差仍未检出。以上精确率排除了预设混合边缘，不代表边界圈选准确；未知覆盖不是确认白斑。

## 复核和限制

[逐例结果及确认／未知图](round64-artifacts/completed/)、[研究脚本](round64.py)、[预设规则](round64-protocol.md)可复核；平滑信号测试通过（pytest 存在 asyncio 配置警告），37 个输出文件与执行目录的哈希一致，registry 保持禁用且前后哈希一致。无模型训练、启用或部署。

结果仅来自两张已观察虚拟源，使用同一 C 图构建阴性与程序正例；场景并不独立，程序色变和排除的混合边缘也不是实际生成白斑的独立真值。不能以此推断不同肤色或真实患者照片的准确率，更不能证明 99.99%。没有使用真实患者照片或人工圈画；图像生成模型预训练来源未知。下一步应在独立来源和独立控制上研究既能保留小斑又限制漂移误检的方案，并使用包含边界的完整评价；继续固定门槛而非在同批数据上反复调参。
