## 0. 结论速览（一页纸）

| 问题 | 结论 |
|---|---|
| SubSkin 现在靠什么赚钱 | **什么都没有。** 代码库中零支付、零会员、零积分、零广告、零推荐返利。唯一的"门槛"是控成本用的限流：访客 AI 问答 5 次/日（`web/backend/api/rag.py:58`）、登录用户 20 次/分钟（`app/middleware/rate_limit.py`）。微信/支付宝仅接了 OAuth **登录**（`services/wechat_auth.py`、`alipay_auth.py`），未接支付。 |
| 最核心的商业资产是什么 | 不是 AI 问答，也不是社区，而是**「记录」模块沉淀的纵向病程数据 + 已经建好的合规基座**（单独同意、审计日志、4 级数据分级、28 项医评合规自检）。一次问答/一次识别都可被替代；跨越复诊周期的连续记录 + 可向医生呈现的整理物是别人短期抄不走的。 |
| 核心盈利层（0–12 个月） | ① 病友「记录整理增值」订阅（复诊资料包 / 周期报告 / 治疗时间线）；② 药企**疾病教育与患者支持项目（PSP）**的合规承接——2026-01-30 芦可替尼乳膏（百卢妥®）获 NMPA 批准，中国白癜风首次有靶向药，药企患教预算窗口正在打开；③ 皮肤科机构「患者授权随访」轻量 SaaS 试点。 |
| 辅助盈利层 | 体检报告深度解读按份付费；合规临床试验招募导流（信息展示 + 患者主动报名）；合规的非药品护理/遮盖/防晒精选（需 EDI 与严格的非疗效表述）；自愿支持与 AI 创意周边小额收入。 |
| 远期盈利层（12 个月+） | 真实世界研究（RWS）与科研合作（需伦理审查 + 独立同意）；带病体健康险/创新支付合作；家用光疗设备的合规服务（器械备案门槛高）。 |
| 绝对不做 | 医院竞价排名 / 推荐位 / 导诊返佣；付费删差评或置顶好评；疗效承诺、治愈率宣传；AI 直接诊断或生成处方；出售/授权可识别的患者数据；把「测量精度」「隐私保护」「导出自己的数据」设为付费墙。 |
| 最大风险 | 不是没人付钱，而是**在没有付费数据时用堆功能掩盖价值未验证**。因此本报告要求商业化按「验证 → 试点 → 扩张」三道门（Gate）推进，任一 Gate 未过就停下来复盘，而不是往下走。 |

## 1. 分析基线：SubSkin 今天到底有什么

### 1.1 已上线/在测的六大能力与其商业含义

| 需求书中的功能 | 站内模块 | 代码事实（可验证） | 商业含义 |
|---|---|---|---|
| AI 智能问答 | 问答 `/` | RAG：DashScope `qwen-plus` 默认，备选火山/DeepSeek/Moonshot/MiniMax/智谱/OpenAI（`utils/llm_config.py`）；向量 `text-embedding-v4`；知识库为 PubMed 摘要 + 849 篇 PMC 全文（`data/fulltext/`）+ ClinicalTrials.gov 日更 dump（`data/raw/`）；三套系统提示词均以「不构成医疗诊断」收尾并拒绝直接诊断 | 流量入口与信任建立器。**本身不适合收费**（可替代性高、且收费会诱发"付费=更准"的误导）。价值在于把用户引导到「记录」并沉淀上下文。 |
| AI 白斑识别 | 记录 `/assessment` | 多模型流水线：VLM（qwen-vl-max）定位 + SAM（`models/sam_vit_b_01ec64.pth`）+ nnU-Net（火山 ML 平台）+ 患者级随机森林像素分类自进化闭环（`models/vasi.py`）；自训 RGB U-Net 仍是 **未验证基线**（`ml/rgb_segmentation/README`：随机初始化、覆盖 0%） | 差异化最强的技术资产，但**不能宣称临床级精度**。定位必须是「辅助测量工具」而非「辅助诊断」——这直接决定了是否落入 NMPA 三类器械监管（见 §7.1）。 |
| 白斑病情变化对比 | 记录 → 白斑对比 / 白斑报告 | 两张照片或两次记录对比、四种视图（动画/叠影/滑块/并排）、可靠共同范围量化、手动对齐（`DEPLOY_LOG.md` 2026-09-16）；`treatment_events` 表已含治疗事件与自付费用字段；`skin_reports` 可生成分享链接 | **付费能力的核心载体。** 「跨越 3–6 个月看得见变化」是病友愿意为之付费的唯一稀缺物；也是机构随访与药企 RWE 的数据底座。 |
| 体检报告智能解读 | 体检解读 | PDF/DOCX/图片解析 → LLM 结构化解读（`services/medical/report_interpreter.py`），红/黄/绿风险分级，参考区间库 `data/medical_knowledge/reference_ranges.json`，报告对比 | 中频、强需求（白癜风常伴甲状腺/免疫指标监测），适合**按份付费**或作为订阅权益。必须维持「解读≠诊断」。 |
| 病友内容分享 | 分享 `/community` | 图文/视频/长文/治疗分享（`treatment_share_json` 结构化模板）、关注/推荐/同城流、收藏夹、草稿、匿名发帖、前置规则引擎 + 后置 LLM 复审 | 留存与信任层，**不直接收费**。是药企患教与招募合规触达的"场"，前提是内容与商业信息严格隔离。 |
| 治疗经验社区分享 | 公益 `/hospitals` | 医院目录（7 家编辑种子 `web/app/src/data/hospitals.ts` + 社区补充）、医院详情页、六维就医体验（**无疗效维度**）、费用透明、举报/申诉（3 个工作日 SLA）、社区公约、交互地图（在测） | 品牌护城河：中国白癜风赛道被莆田系与竞价排名污染十余年，「不排名、不导流、不收医院钱」本身就是最强差异化。**它的商业价值是间接的**：换取用户信任与药企/学术机构的合作意愿。 |

### 1.2 已经建好、但常被忽视的商业化基座

| 基座 | 位置 | 为什么重要 |
|---|---|---|
| 单独同意体系 | `user_consents`（terms/privacy/ai_data/medical_photo）、`health_consent` 强制勾选、`services/consent.py` | 任何 B 端（机构/药企/科研）付费都建立在「患者明确授权的范围」之上，没有这一层就没有可卖的服务。 |
| 不可篡改审计日志 | `audit_logs` + `services/audit.py` | 回应 PIPL、医疗纠纷举证、合作方尽调的关键证据链。 |
| 4 级数据分级与脱敏 | `AGENTS.md` L1–L4、`utils/redact.py`、凭证图仅作者可读 | 让「机构只看患者授权范围」在技术上可执行。 |
| 医评合规自检 28 项 | `docs/specs/2026-09-11-medical-review-compliance-checklist.md` | 已把「不做排名、不导流、不付费删评」写成代码约束与公约，可直接对外作为平台原则宣示。 |
| 医生认证与邀请 | `is_doctor`、`doctor_verifications`、`doctor_invitations` | 机构/医生端产品的身份基础已存在，不必从零开始。 |
| 用药提醒 | `/api/medication`、`medication_reminders` | 药企 PSP 数字化承接（依从性支持）的现成组件。 |
| 事件埋点与增长看板 | `user_events`、`services/analytics.py`、管理后台 Dashboard | 可扩展为付费漏斗与留存分析，但**目前没有付费/用量/成本维度**。 |

### 1.3 明确缺失（会直接卡住商业化）

1. **无用量与成本计量**：LLM 调用不记录 token 与费用，只有进程内令牌桶限流（重启即清零）。任何分层额度、按次付费、B 端结算都需要先补 `usage_ledger`。
2. **无订单/订阅/支付回调**：需新增 `orders`、`subscriptions`、`entitlements`，接微信支付/支付宝商户（已有 OAuth 基础，非从零）。
3. **无 AIGC 标识**：2025-09-01 起《人工智能生成合成内容标识办法》与 GB 45438-2025 要求 AI 生成图文加显式 + 隐式标识；目前 AI 问答、白斑分割图、对比动画、AI 创意图均未系统化标识。
4. **医院资料库过薄**：7 家编辑种子医院不足以支撑「公益」作为全国性入口。
5. **PIA 与律师意见未完成**（合规清单第五节 A/B 项）——机构/药企合作尽调必问。
6. **无医生端/机构端界面**：`is_doctor` 只是布尔标记，没有工作台。

## 2. 赛道属性：白癜风垂直病友市场的独特结构

### 2.1 患者规模（口径必须注明）

| 口径 | 数值 | 来源 |
|---|---|---|
| 中国六省市流调标化患病率 | 0.56% | [PubMed 22859054](https://pubmed.ncbi.nlm.nih.gov/22859054/) |
| 上海成人社区流调 | 粗 0.91% / 标化 0.67% | [Ann Palliat Med](https://doi.org/10.21037/apm-21-1738) |
| 药企（康哲/德镁）披露口径 | 约 1030 万患者，其中非节段型约 820 万 | [HKEX 公告 2026-01-30](https://www1.hkexnews.hk/listedco/listconews/sehk/2026/0130/2026013000224_c.pdf) |
| 媒体/科普常用口径 | 2283 万（2021）至约 3000 万 | [医药魔方](https://bydrug.pharmcube.com/news/detail/f171f970561caeb76929dd3c3c6bae6c) |
| 全球终身患病率（Lancet Public Health 建模） | 0.36%，中国 0.22% | [DOI](https://doi.org/10.1016/s2468-2667(24)00026-4) |

**对外统一表述建议**：「中国白癜风患者约 1000 万–3000 万（不同口径），其中半数以上 20 岁前发病」。不要选一个数字当事实。

### 2.2 市场规模与支付结构

- 全球白癜风治疗市场 2025 年约 18.4 亿美元，中国 2026 年约 1.6 亿美元（[Fortune Business Insights](https://www.fortunebusinessinsights.com/zh/industry-reports/vitiligo-treatment-market-100580)）。这是**药品/治疗**市场，不是数字健康市场；SubSkin 可触达的是其周边的信息、随访、患教与研究预算。
- 中国互联网问诊价格带：图文 19–120 元/次，家庭医生 99–500 元/月（[好大夫](https://www.haodf.com/neirong/wenzhang/7187618027.html)、[平安好医生参考价](https://www.chnweiyu.com/zsiwd/202512/937715.html)、[丁香医生 49 元以下筛选](https://news.qq.com/rain/a/20250519A027PB00)）。这给 C 端定价提供了心理锚点：**病友对"数字健康服务"的可接受单价在几十元到一两百元区间**。
- 历史上白癜风患者最大的支出流向是莆田系医院与竞价广告：医疗关键词 CPC 曾被炒到 100 元以上，部分医院推广费占营收 70–80%（[新浪科技 2015](http://tech.sina.com.cn/i/2015-03-26/doc-icczmvun7136260.shtml)）。**这说明患者不是没钱，而是钱被花在了错误的地方**——一个可信平台的价值恰在于把这部分焦虑支出转化为理性支出。

### 2.3 2026 年的关键拐点：靶向药时代到来

| 药物 | 状态 | 对 SubSkin 的含义 |
|---|---|---|
| 芦可替尼乳膏（Opzelura / 百卢妥®，Incyte 原研，康哲/德镁引进） | **NMPA 2026-01-30 获批**，12 岁以上面部非节段型 | 中国首个白癜风靶向药上市 → 药企需要患者教育、依从性支持、真实世界疗效记录；美国 WAC 2094 美元/支，中国定价与支付方案待观察（[新华网](https://app.xinhuanet.com/news/article.html?articleId=f0b82d1e95afedfa5b6cded544c159b8)、[Opzelura 定价](https://www.opzelura.com/vitiligo/cost)） |

## 3. 盈利模式全景拆解

按**付费方**分四组、共 17 个模式。每个模式给出：机制、依托的现有功能、合规边界、可借鉴案例、收入量级估算方法。

### 3.1 C 端：病友付费（7 个）

**C1 记录整理增值订阅（复诊资料包 / 周期报告 / 治疗时间线）**
- 机制：基础记录、对比、历史查看、数据导出永久免费；付费的是**自动整理与交付物**——按复诊周期生成给医生看的 1 页摘要（部位、面积变化曲线、用药与光疗事件、体检指标趋势、本次想问医生的问题清单）、季度/年度 PDF 报告、跨设备长期高清原图存储。
- 依托：`vasi_assessments`、`spot_comparisons`、`skin_reports`、`treatment_events`、`medical_reports`——数据全部已有，缺的是"编排 + 导出 + 计费"。
- 合规边界：报告首尾必带「辅助记录，不构成诊断」；不得把测量可靠性、风险提示、隐私保护做成会员特权；不得用"用完额度"引导过度拍照。
- 案例：SkinVision 单次 €10–25、年费 €50–100（[SkinVision 定价](https://skinvision.zendesk.com/hc/en-gb/articles/22945140402844-Pricing-and-Refunds)），但用途不同、仅作打包结构参照。
- 估算法：付费用户数 × 年 ARPU。`docs/research/2026-09-20-business-model/assessment.md` 已给试探定价 49 元/90 天 → 169 元/年，本报告沿用并在白皮书中设 A/B 价格试验。

**C2 体检报告深度解读（按份）**
- 机制：基础解读免费（已上线）；付费项为「多份报告纵向趋势 + 白癜风相关指标专项解读（甲功、免疫、维生素 D、微量元素）+ 就诊问题清单」，可选人工（认证医生/药师）复核加价。
- 依托：`medical_reports`、`report_interpreter.py`、报告对比。
- 合规边界：解读 ≠ 诊断；人工复核者需执业资质且以「健康咨询」而非「诊疗」名义（否则触《互联网诊疗监管细则》第 13/18/21 条：不得首诊、AI 不得替代医师、不得 AI 开方，[卫健委](https://www.nhc.gov.cn/yzygj/c100068/202203/2072f0e8988249e59d942e1b2a933916.shtml)）。
- 估算法：单价 9.9–29 元/份（对标图文问诊下限）× 份数。

**C3 AI 深度分析按次付费（多模态/长上下文）**
- 机制：基础问答与识别免费额度维持；付费仅覆盖高成本调用（如全身多部位一次性测量、长病史个性化综述）。
- 合规边界：**不得**制造"免费版不准、付费版准"的暗示；付费只对应算力与时长，不对应结论质量。
- 判断：**优先级低**。它与 C1 重叠、且极易被解读成"AI 医生收费"。建议并入 C1 权益而非独立售卖。

**C4 就诊前准备服务（半人工）**
- 机制：复诊前 48 小时，由平台运营（非医生）基于用户授权资料整理"就诊准备单"，人工核对图片质量与时间线，用户确认后导出。本质是 C1 的高触达版本，用于验证期。
- 依托：C1 数据 + 管理后台。
- 合规边界：运营人员不给医疗建议，只做资料整理；需在同意页说明"人工可见你的授权资料"。
- 估算法：按次 29–59 元；验证期 5–10 笔真实付费即达目标（与 assessment.md 一致）。

**C5 心理与生活课程（合作分成）**
- 机制：与有资质的心理机构/皮肤科护理团队合作，提供病耻感应对、青少年家长课程、遮盖化妆教学等付费课程，平台分成。
- 依托：问答的心理陪伴模式（`hermes_plan/2026-07-30` 提及）、分享的心理支持板块。
- 合规边界：课程内容不涉及疗效；心理服务提供者具备资质；未成年人内容需监护人同意。
- 案例：Vitiligo Society UK 以会员制 + 讲座运营（[官网](https://vitiligosociety.org/)）。

**C6 非药品护理精选（遮盖液、防晒、温和护肤）**
- 机制：编辑精选 + 病友实测口碑，联营或佣金；**不卖药、不卖器械**。
- 合规边界：需 ICP + EDI 许可（[健康界](https://www.cn-healthcare.com/articlewm/20220815/content-1418508.html)）；商品页与科普/社区内容**不得同页出现**（《互联网广告管理办法》与 2025《医疗广告认定指南》，[市场监管总局](https://www.samr.gov.cn/ggjgs/tzgg/art/2025/art_fe4ab107d0784ee7afd212d16e6345e8.html)）；文案禁止任何"改善白斑/促进复色"类疗效表述。
- 判断：可做，但要有独立的「精选」入口，与公益/分享物理隔离。

**C7 AI 创意与周边、自愿支持**
- 机制：白斑轮廓艺术（`assessment_story.py` 已有探索）实体化为明信片/贴纸；「支持 SubSkin」自愿打赏；公益项目透明募资。
- 合规边界：打赏不换取任何内容特权；募资需依托有资质的公募/慈善主体。
- 判断：收入小，但对品牌与社区归属感有价值；成本几乎为零。

### 3.2 B 端：医院、诊所、医生付费（3 个）

**B1 患者授权随访 SaaS（机构版）**
- 机制：患者在 SubSkin 主动授权某医院/医生查看其记录摘要；机构端获得批量随访视图（复诊前自动汇总、变化预警、依从性提醒）。按机构固定年费或按实际服务患者数计费。
- 依托：`is_doctor`、`doctor_verifications`、`audit_logs`、单独同意体系、记录数据。
- 合规边界：机构**只**能看患者明确授权范围，不得访问社区用户库；平台**不**向机构出售线索、不排名、不导流（合规清单第 3/4/25 项）；机构付费与平台上任何公开信息呈现无关。
- 案例：Miiskin 机构端按使用计费（[Miiskin Pro](https://miiskin.com/pro/plans-pricing/)）；优麦医生 D 端覆盖 95% 皮肤科医生但主要收入来自药企（[优麦](https://www.umer.com.cn/aboutus/)）——提示**医生喜欢 ≠ 医院采购**。
- 估算法：机构数 × 年费（试点建议 1–3 万元/年/科室，按人工节省时长定价）。

**B2 医生个人版工具**
- 机制：认证医生免费使用基础随访视图；付费项为批量导出、科研级数据整理、病例集管理。
- 判断：作为 B1 的漏斗上游，先免费获取医生，不急于收费。

**B3 机构培训与标注服务**
- 机制：向皮肤科/教学医院提供白斑分割标注工具（管理后台已有 `ImageLabeling`/`LabelingWorkspace`）与标注培训。
- 判断：非主线，机会型收入。

### 3.3 B 端：药企、器械、CRO 付费（5 个）

**B4 疾病教育与认知项目（Disease Awareness / 患教）赞助**
- 机制：药企出资，平台产出**不含产品名、不含疗效对比**的疾病科普专题（如"JAK 抑制剂时代的白癜风治疗选择""如何客观记录疗效"），页面显著标注「本专题由 XX 支持，内容由平台独立编写并经医学审核」。
- 依托：问答知识库、分享科普、公益治疗知识页（`/hospitals/treatments`）。
- 合规边界：处方药不得向公众做广告（《广告法》第 15 条），因此**只能做疾病教育不能做产品推广**；赞助信息与内容分离；不得设"就医/购药跳转"。
- 案例：银屑病病友互助网 20 年靠诺华/礼来/强生/利奥的患者福利项目赞助维持公益运营（[yxb365](https://www.yxb365.cn/xwzx/6679.html)）；MyHealthTeam 靠药企赞助年收入约 740 万美元、27M 患者（[MyHealthTeam](https://myhealthteam.com/recent-news/myhealthteam-announces-new-pharma-marketing-solutions-for-2025/)）。
- 估算法：项目制，国内皮肤科患教项目单项常见量级为数万至数十万元（**不确定**，需一手询价）。

**B5 患者支持项目（PSP）数字化承接**
- 机制：药企为已处方患者提供的用药提醒、涂抹指导、不良反应上报入口、定期拍照记录与随访——由 SubSkin 以白标或联名方式承接，药企按入组患者数付费。患者**自主选择**加入，与普通用户完全隔离。
- 依托：`medication_reminders`、记录模块、通知系统、单独同意。
- 合规边界：入组需单独同意与项目说明；数据仅用于该 PSP，且优先以去标识化汇总回传；不得借 PSP 向未处方用户推广产品；不良事件上报走药企药物警戒流程。
- 案例：IncyteCARES / Opzelura On Trac 患者支持（[IncyteCARES](https://www.incytecares.com/dermatology-opzelura/)）；礼来/镁信健康银屑病患者福利项目（[生物谷](https://news.bioon.com/article/474a6e62290a.html)）。
- 估算法：入组患者数 × 人年服务费。

**B6 临床试验招募信息服务**
- 机制：平台展示经 CDE 登记的白癜风试验（数据源已有：`data/raw/clinical_trials_*.json`），用户**主动**填写意向，经同意后转交申办方/CRO；按有效转介或项目固定费计费。
- 合规边界：只做信息展示与自愿报名，**不**做筛选医学判断；所有内容注明申办方与登记号；受试者补贴由申办方支付（参考：口服药 III 期补贴约 4000 元/人，[试药招聘网](https://shiyao.net.cn/post/1702.html)）；招募费率不公开、需询价（**不确定**）。
- 案例：PatientsLikeMe 以研究合作与试验支持为主要收入（[PLM 官方说明](https://support.patientslikeme.com/hc/en-us/articles/201245750-How-does-PatientsLikeMe-make-money)）；国内伊顿健康专营招募。

**B7 器械/护理品牌合规内容合作**
- 机制：308 家用光疗仪、遮盖液品牌出资制作"如何正确使用光疗仪/遮盖产品"的中立教程，标注赞助。
- 合规边界：器械广告需审查批文；平台不销售三类器械（需《医疗器械经营许可证》）；避免任何疗效承诺。
- 判断：可做，量小，优先级低于 B4/B5。

**B8 真实世界研究（RWS）与科研合作**
- 机制：与研究机构/药企合作，基于**去标识化 + 患者逐项独立同意 + 伦理审查**的数据开展研究（如"外用 JAK 治疗 24 周 F-VASI 变化的真实世界分布"）。
- 合规边界：PIPL 第 28–30 条（敏感信息单独同意，[网信办](https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm)）；普通使用同意**不能**视为科研授权；1 万人以上敏感个人信息出境需安全评估（[2024 数据跨境规定](https://www.cac.gov.cn/2024-03/22/c_1712776611775634.htm)）→ 合作方须境内处理；不出售任何可识别数据。
- 案例：23andMe 药企数据授权 2000 万美元/年（[23andMe](https://www.23andme.org/media-center/press-releases/23andme-announces-collaboration-extension-new-data-licensing/)）——**仅证明模式存在**，其后续隐私争议与破产重组更是警示。
- 判断：远期。前提是记录数据量与质量达到研究级，且 PIA 完成。

### 3.4 其他付费方（2 个）

**B9 商业健康险 / 带病体保险 / 创新支付合作**
- 机制：保险公司或创新支付平台（如镁信健康类）购买 SubSkin 的记录服务作为投保人增值权益，或以 SubSkin 记录作为疗效随访依据。
- 判断：远期，需保险合作资质与精算对接。

**B10 公益基金与政府项目**
- 机制：申请皮肤病患者关爱基金、罕见病/慢病数字化项目补贴。
- 判断：机会型，可作为公益模块的运营经费来源，合规成本低。

## 4. 六维评级与优先级排序

### 4.1 评分规则

六维、每维 1–5 分（5 = 最好），加权求和，满分 5.0。权重反映本赛道特点：**合规是生死线，贴合核心功能决定能否复用现有资产**。

| 维度 | 权重 | 5 分含义 | 1 分含义 |
|---|---|---|---|
| 合规风险（低=高分） | 25% | 无需新资质，无广告法/诊疗/器械/PIPL 触点 | 明确触碰红线或需三类器械证 |
| 贴合核心功能 | 20% | 直接复用记录/问答/解读现有数据与代码 | 需另起一条产品线 |
| 盈利能力 | 15% | 单客价值高或规模可放大 | 小额、天花板低 |
| 长期可持续 | 15% | 与用户利益一致、不透支信任 | 一次性或消耗信任 |
| 变现难度（低=高分） | 15% | ≤1 个季度可上线并收到钱 | 需 1 年以上、多方合同 |
| 用户接受度 | 10% | 病友天然理解并认可付费理由 | 病友会反感或误解 |

### 4.3 排序结论与依据

**核心盈利层（0–12 个月主攻）**

1. **C1 记录整理增值订阅** — 唯一同时满足"复用全部现有数据""与用户利益一致""无需新资质"的模式。它把 SubSkin 从"工具"变成"病程档案"，也是 B1/B5/B8 的数据前提。风险在于付费意愿未验证，因此用 C4 半人工版先跑 90 天验证（详见白皮书 §4）。
2. **B5 药企 PSP 承接 → B4 患教赞助** — 2026 年靶向药获批带来的窗口期最多 12–18 个月（第二、第三家药企进场前）。B5 单客价值最高但合同周期长；B4 合规更清晰、启动更快。两者共享同一套"内容独立 + 赞助标注 + 单独同意"的治理框架，应同步启动商务接触，以 B4 先落地、B5 跟进。
3. **B1 机构随访 SaaS（试点）** — 医生痛点真实（门诊 3 分钟、复诊说不清），但"医生喜欢"到"医院付款"路径长。定位为**1 个付费试点**目标，不预设规模收入。

**辅助盈利层**

- C2 体检解读按份、C4 就诊准备：与 C1 互补，可作为订阅权益或单点付费入口。
- B6 招募信息服务：数据源与合规框架现成，收入取决于试验数量（2026–2027 年国内白癜风 III 期/桥接试验预计增加）。
- C6/C5/C7/B2/B7：低风险补充，各自贡献不大，但共同构成"非医疗、非疗效"的多元化收入，降低对药企单一付费方的依赖。

**远期盈利层（12 个月+）**

- B8 RWS：收入潜力最大、合规门槛最高。需要 PIA、伦理合作方、研究级数据质量三件事全部到位。
- B9 保险：需要 C1 留存数据证明"记录行为与就医结果相关"。
- B10：随时可申请，不作为经营依赖。

## 6. 优劣势与 AI 赛道机会

### 6.1 SWOT

| | 有利 | 不利 |
|---|---|---|
| **内部** | **S1** 纵向记录 + 对比 + 报告的完整链路（竞品无）；**S2** 合规基座领先（单独同意/审计/分级/28 项自检）；**S3** "不排名不导流"的公益定位在被污染的赛道中稀缺；**S4** 多模型可切换的 AI 架构（国产模型优先，天然满足境内处理）；**S5** PubMed/ClinicalTrials 自动化数据管线；**S6** PWA 跨端、无应用商店抽成 | **W1** 零变现设施、零用量计量；**W2** 自训分割模型未经验证，精度不能对外宣称；**W3** 医院库仅 7 家种子；**W4** 无医生/机构端界面；**W5** 无付费/留存实测数据；**W6** PIA 与律师意见未完成；**W7** 单人/小团队，商务与医学审核人力不足 |
| **外部** | **O1** 2026 年靶向药获批，药企患教/PSP/RWE 预算打开；**O2** 多款 JAK 处于 III 期，招募需求上升；**O3** 国家"人工智能+医疗卫生"实施意见（2025-10）鼓励规范应用；**O4** 患者对莆田系与竞价广告的不信任是长期存在的空白；**O5** 国产大模型成本持续下降 | **T1** 医疗广告认定趋严（2025《医疗广告认定指南》把"科普 + 跳转"认定为变相广告）；**T2** AI 辅助诊断被归三类器械，功能定位一旦越界即需注册；**T3** 京东健康等综合平台以 AI + 电商切入皮肤科；**T4** 药企可能自建 App 或选择更大的患者平台；**T5** AIGC 标识与算法备案义务增加合规成本；**T6** 医疗数据出境监管使境外模型/云不可用 |

### 6.2 AI 时代的核心差异化优势（可对外表述）

1. **"看得见的变化"而非"AI 医生"**：市场上 AI 皮肤应用多做"识别/分诊"（SkinVision、优智 AI），SubSkin 做的是**纵向量化 + 可解释对比**。这一定位既是产品差异化，也是监管上的"工具"而非"辅助决策"（见 §7.1）。
2. **患者自主的数据主权**：所有 B 端价值都经由患者授权流转，平台不做数据中介。这是与 23andMe 式模式的根本区别，也是药企/机构在 PIPL 下敢合作的原因。
3. **RAG 有出处 + 自动化文献管线**：新药、新试验能在 24 小时内进入知识库（`data/raw/clinical_trials_*.json` 日更），这是人工科普号做不到的时效性。
4. **国产多模型可切换**：不依赖单一供应商、成本可控、数据不出境；DeepSeek/豆包/Qwen 的成本曲线让"免费额度"可以持续。
5. **合规先行的公益模块**：在莆田系历史阴影下，"不收医院一分钱"是任何后来者难以复制的信任资产。

| 机会 | 窗口期 | 抓住的前提 |
|---|---|---|
| 靶向药上市后的疗效记录需求 | 2026–2027（第二家药企进场前） | C1 交付物成熟 + B5 商务接触在 2026 Q4 前启动 |
| III 期/桥接试验招募 | 2026–2028 | B6 页面与同意流程上线，与 1–2 家 CRO 建立联系 |

## 7. 风险研判与避坑规则

### 7.1 合规风险（生死线）

| 风险 | 法规依据 | 触发场景 | 避坑规则 |
|---|---|---|---|
| AI 功能被认定为**辅助诊断医疗器械（三类）** | NMPA 分类目录 21-04；《人工智能医疗器械注册审查指导原则》（[NIFDC](https://www.nifdc.org.cn/nifdc/bshff/ylqxbzhgl/qxxxgk/fljd/202505140845291560902.html)） | 输出"是/不是白癜风""建议用药""疾病分期结论" | 所有 AI 输出限定为**测量、对比、整理、科普**；禁止疾病判定与治疗建议；文案用"面积占比变化"而非"病情好转/恶化" |
| **变相医疗广告** | 《广告法》16/17 条；《医疗广告管理办法》7 条；2025《医疗广告认定指南》 | 科普页出现医院推荐、疗效对比、购药/挂号跳转；对比报告配"有效"文案 | 内容与商业物理隔离；赞助标注；禁词库（治愈/根治/有效率/最佳/首选/推荐这家）；对比报告只呈现数据不做评价 |
| **AI 越界诊疗** | 《互联网诊疗监管细则》13/18/21 条 | 体检解读给出诊断、AI 回答"你该吃什么药" | 解读 ≠ 诊断的固定声明；问答提示词已拒绝直接诊断（`services/rag.py`），需加输出后过滤；任何人工复核者以"健康咨询"名义且具资质 |
| **敏感个人信息处理不合规** | PIPL 28–30、55–56 条；《网络数据安全管理条例》 | 未单独同意即把病情图片送 LLM；机构看到未授权数据；未做 PIA | `ai_data`/`medical_photo` 同意已实现，需扩展到每一项 B 端授权；PIA 正式报告上线前完成；授权范围逐项、可撤回、留审计 |
| **数据出境** | PIPL 38–39；《促进和规范数据跨境流动规定》 | 使用境外模型 API 或境外云处理病情图片 | 仅用境内部署/境内节点模型；OpenAI 等作为最末备选且默认关闭；合同约束合作方境内处理 |
| **AIGC 未标识** | 《人工智能生成合成内容标识办法》（2025-09-01）；GB 45438-2025 | AI 问答文本、分割图、对比动画、创意图无标识 | 显式标识（"AI 生成"角标/文字）+ 隐式标识（文件元数据 AIGC 字段）；分享海报同样适用 |
| **经营资质缺失** | ICP/EDI；互联网药品/器械信息服务备案（2025 年第 123 号，改审批为备案） | 上线付费服务或电商 | 付费前办 ICP 证；电商前办 EDI；涉药品/器械信息展示（含试验药物介绍）前完成备案 |
| **未成年人** | PIPL 31 条 | 患儿家长上传儿童照片 | 监护人同意流程；儿童数据更严格的存储与展示限制 |

### 7.2 商业化风险

| 风险 | 表现 | 避坑规则 |
|---|---|---|
| 付费墙误伤信任 | 把测量、历史、导出设为会员权益 → 用户认为"不付钱就看不到自己的病情" | 铁律：本人数据的查看与导出永久免费；付费只对应**额外整理与交付物** |
| 过度依赖单一药企 | 一家药企赞助占收入 >50% | 内容独立条款写入合同；同时接触 ≥2 家药企；C 端收入作为独立性底座 |
| "医生喜欢 ≠ 医院采购" | B1 试用医生多、付款为零 | 试点前找到预算负责人；按节省人力时长定价；没有付款意向不投入机构端重开发 |
| 用假指标自我安慰 | 用 DAU、拍照次数衡量"长期追踪价值" | 北极星指标改为"完成第 2/3 次有效记录并在复诊中实际使用报告的用户数" |
| 定价锚定错误 | 对标问诊价却卖"整理"服务 | 用 A/B 价格试验（白皮书 §4.3）而非拍脑袋；先按次再订阅 |

### 7.3 用户运营风险

| 风险 | 避坑规则 |
|---|---|
| 社区被卖药/卖偏方/医院水军渗透 | 现有规则引擎 + LLM 复审 + 举报阈值已在；增加"商业推广"举报类别与自动降权 |
| 焦虑型用户过度拍照/过度解读 | 产品层面：设置"下次建议记录时间"（按治疗周期 4–12 周）；不做拍照打卡激励 |

### 7.4 AI 算法风险

| 风险 | 避坑规则 |
|---|---|
| 分割/测量不稳定被当"病情变化" | 对比报告只在"可靠共同范围"内给量化（已实现）；不满足条件时明确"本次不可量化"而非给数字 |
| 深肤色、毛发区、光照差异下的偏差 | 图像质量门禁（`image_quality_tags` 已有）；公开说明局限性 |
| LLM 幻觉与引用错误 | 引用可点击到 PubMed；来源分级；"我不确定"策略；输出后规则过滤禁词 |
| 自进化闭环漂移 | 模型版本表已在（`vasi_model_versions`）；人工抽检比例与回滚 SOP |
| 对外宣称精度 | 在完成独立验证前**不得**对外给出准确率数字（`ml/rgb_segmentation/README` 已自述为未验证基线） |

### 7.5 医疗内容风险

- 所有科普需医学审核人（皮肤科执业医师或药师）署名或审核记录；
- 新药内容只讲机制、适应症、常见不良反应与"请咨询医生"，不讲价格比较与购买渠道（处方药）；
- 用户治疗分享（`treatment_share_json`）中的"效果"字段仅第一人称过程描述，不进聚合（合规清单第 2 项已实现）；
- 定期复审旧内容（>18 个月标注"时间较早"，可沿用医评做法）。

### 7.6 行业竞争风险

- 综合平台（京东健康等）以流量与药品电商切入：SubSkin 不在流量与电商上竞争，只在**纵向记录深度与信任**上竞争；
- 药企自建 App：以"已有真实社区 + 患者自主授权"作为外包理由，并接受白标；
- 后来者复制"记录"功能：护城河是数据连续性与合规基座，而非单一功能——加快 C1 交付物成熟度。

## 8. 收入情景模型（仅为量级演算，非预测）

**所有输入均为假设**，用于说明"哪一档收入来自哪里、对什么敏感"。实际数字必须以白皮书 §4 的验证结果替换。

### 8.1 情景 A：12 个月内仅 C 端自我维持

| 假设 | 数值 |
|---|---|
| 稳定活跃用户（月） | 10,000 |
| C1 年费转化率 | 3%–5% |
| C1 年费 | 169 元 |
| C2/C4 按次付费用户占比 | 5%，年均 2 次 × 29 元 |
| 年收入 | C1 ≈ 5.1–8.5 万元；C2/C4 ≈ 2.9 万元；**合计 ≈ 8–11 万元** |
| 年直接成本 | LLM 推理 + 存储带宽 + 支付手续费 + 客服/退款（需实测；当前无计量） |

结论：仅靠 C 端只能覆盖服务器与模型成本，**养不起团队**。它的意义是验证价值与建立独立性。

### 8.2 情景 B：C 端 + 1 个药企患教项目 + 1 个机构试点

| 假设 | 数值 |
|---|---|
| 情景 A 全部 | ≈ 8–11 万元 |
| B4 疾病教育专题 1 项 | 10–30 万元（**不确定**，需一手询价） |
| B1 机构试点 1 家 | 1–3 万元/年 |
| **合计** | **≈ 20–45 万元** |

结论：B 端一个项目即抵 C 端全年。**但 B 端不确定性极高**，合同签署前不计入。

### 8.3 情景 C（18–24 个月）：加入 PSP 与招募

| 假设 | 数值 |
|---|---|
| B5 PSP 入组 500 人 × 人年服务费 200–500 元 | 10–25 万元 |
| B6 招募 2 个项目 | 项目费不确定 |
| 情景 B | 20–45 万元 |
| **合计** | **≈ 30–70 万元 + 招募** |

### 8.4 敏感性

- 对 **C1 转化率**最敏感的不是价格而是"交付物是否在复诊中被医生真的看了"——这决定续费。
- 对 **B 端**最敏感的是"是否在靶向药上市后 12 个月内建立首个药企合作"。
- 成本侧最大不确定项是 **LLM 推理**，必须先补用量计量再谈毛利。
