## 1. 问题定义

**目标**：在随访照片中自动识别并标注白癜风白斑区域（红色标注），支持跨时间、跨姿态、跨光照的量化对比。

**白斑的医学与成像特性**（决定算法设计）：
- 白斑是**黑色素细胞脱失**，表现为**红色素(a*)与黄色素(b*)降低、亮度(L*)升高**；
- 治疗中的白斑多为**部分脱色**（浅粉/浅褐），不是纯白，与正常肤色的色差很小；
- 白斑边缘是**渐变**的，不存在"断崖式"色值跳变（§2 实测证明）；
- 白斑可出现在**任何皮肤区域**，包括眉周、鼻侧、口周、发际线——不能假设"五官区域无白斑"。

**核心难点**：
1. 自拍照片**光照严重不均**（上亮下暗，同一张脸内 L* 跨度可达 25~30），光照差异**远大于**白斑与正常肤色的色素差异；
2. 白斑与正常肤色**无断崖边界**，任何绝对色值阈值都会同时标错大量像素；
3. 不同照片的角度、光线、衣服颜色不同，直接比较像素色值无效。

## 2. 实证发现（全部来自真实实验，是方法设计的依据）

以下实验以患者手工标注（132万px，覆盖眉周/鼻/嘴周/下巴/颈部的"整片关注区"口径）为金标准。

### 2.1 色值对比统计（原图，未校准）

| 通道 | 白斑区中位 | 正常皮肤中位 | 分离度 Cohen d |
|---|---|---|---|
| L*（亮度） | 59.6 | 47.8 | +0.79 |
| a*（红绿） | 16.0 | 13.0 | +0.89 |
| b*（黄蓝） | 17.0 | 20.0 | -0.02（不可分） |
| 彩度 C | 24.0 | 23.9 | +0.40（不可分） |

**单通道阈值误判率**：L* 56%/73%，a* 53%/70%（正常误判/白斑误判）。
→ 结论：**没有任何单一色值通道能干净分离白斑与正常皮肤**。

### 2.2 边缘断崖检验

横穿标注边界采样，内侧 5-15px 带 vs 外侧 5-15px 带：

| 通道 | 跨边缘跳变 | 带内噪声(σ) | 信噪比 |
|---|---|---|---|
| L* | 0.9 | 17.2 | ≈0.0 |
| a* | 0.3 | 5.2 | ≈0.1 |
| b* | 0.1 | 5.4 | ≈0.0 |

→ 结论：**不存在断崖式波动**。色值沿边界平滑渐变（剖面：L* 从 74 渐降到 45，跨度 300px）。梯度图上真正的强边缘是眼睛/鼻梁/发际线等**结构边缘**，不是白斑边界。

### 2.3 光照归一化实验（Retinex/MSR）

对 a* 通道做多尺度 Retinex 光照归一化后，白斑区 vs 非标注区分离度 **Cohen d = +0.00**（原图 +0.89）。
→ 结论：原图上测到的微弱色差**几乎全部来自光照**，真实色素差极小。单张原始照片上做颜色自动分割**原则上不可行**。

### 2.4 关键转折：对齐 + 色彩校准后的色空间可分

4 张照片对齐（相似变换到 900×1200 统一画布）+ 校准（灰世界白平衡 + 鼻梁参考 ROI 均值平移）后：
- 同一解剖位置（面部中心）的色值在 4 张照片间高度稳定：L* 60.8/61.6/64.3/59.2，a* 9/8/8/9，b* -4/-3/-4/-2；
- 无监督 K-means(L*, 彩度C) 分离出的白斑簇中心 **[L*≈64.1, C≈6.4]** vs 正常簇 **[L*≈44.2, C≈8.1]**——彩度出现明显分层。

→ 结论：**先把颜色空间统一，色值规律才可学习**。这是全部方法的第一前提。

### 2.5 监督像素分类器效果（金标准 = 患者一次手工标注）

特征 = (L*, a*, b*, C, 归一化y, 归一化x)，随机森林：

| 验证项 | 结果 |
|---|---|
| 5 折交叉验证像素准确率 | **0.988 ± 0.001** |
| 同图复现：自动预测 vs 手工标注 | **IoU = 0.84** |
| 跨照片预测面积（4 张，画布坐标） | 45.0万 / 45.3万 / 49.6万 / 46.6万 px（手工口径 41.3万） |
| 跨照片互相一致性 | IoU 0.62 ~ 0.80（最低值反映病灶真实缩小） |

特征重要性：归一化y 0.315 > a* 0.212 > x/b*/C 各约 0.14 > L* 0.05。
→ 坐标特征有效且必要（对齐画布上解剖位置固定，坐标是合法先验，不是作弊）。

### 2.6 画布裁剪陷阱（v1→v3 的根因）

患者标注的**前额发际线横带**（原图 y688-802）投影到 900×1200 画布是**负坐标**；**颈部衣领区**（原图 y2630-3172）投影到画布 y1069-1391，**底部超出 1200**。
→ 原画布把训练与预测都裁掉了这两个区域，导致必然漏检。
→ 修复：**扩展画布到 900×1600**（上+150，下+250），校准用原流水线参数（验证与原校准图差异均值 1.48，仅 JPEG 压缩误差）。

### 2.7 标注口径的显式约定

患者选择"**整片关注区**"口径（包含病灶中心及周边可能受累皮肤，如鼻梁、人中），而非"精确脱色核心"。自动方法复现的是**这个口径**（画布面积 ≈41-47 万 px）。若需要"精确皮损"口径（16-19 万 px，含排除块），请使用 §4.6 的无监督 K-means 引擎。两套口径不可混用比较。

## 3. 方法总体架构

```
原照片(任意分辨率/光照)
  │
  ├─[阶段1] 定位与对齐 ──────── 关键点检测 → 相似变换 → 统一画布
  │                            (面部: MediaPipe 468点; 其他部位见 §6)
  │
  ├─[阶段2] 色彩校准 ────────── 灰世界白平衡(逐通道增益) +
  │                            参考ROI(本人正常皮肤)均值平移
  │                            → 跨照片统一色空间
  │
  ├─[阶段3] 扩展画布 ────────── 画布必须覆盖全部可能病灶区域
  │                            (发际线、颈部、肢体远端)，
  │                            校准参数原样应用到扩展区
  │
  ├─[阶段4] 像素分类器 ──────── 监督: 随机森林, 特征=(L*,a*,b*,C,y,x)
  │                            无监督(冷启动): K-means(L*,彩度C)
  │
  ├─[阶段5] 后处理 ──────────── 形态学开闭运算 → 连通域过滤 →
  │                            (可选)肤色邻域校验
  │
  └─[输出] 掩膜逆变换回原图坐标 → 红色半透明叠加 + 轮廓描边
```

**为什么是这套架构**：§2 证明单图色值不可分（光照压制色素信号）；对齐+校准消除光照与构图差异后，色值规律稳定可学；一次人工标注提供"口径定义"，之后全自动。

## 4. 各阶段详细设计（含全部参数）

### 4.1 阶段1：定位与对齐

- **面部**：MediaPipe Face Landmarker（468 点），取 5 关键点（双眼、鼻、两嘴角），最小二乘求相似变换矩阵 M（2×3 扩展为 3×3），把原图变换到 900×1200 画布，双眼瞳距归一化到固定值（本项目 ipd=378px）。
- **输出**：`transforms.json`，每张照片一个 3×3 矩阵（原图→画布），以及画布上的 `target_landmarks`（所有照片共享同一套目标坐标）。
- **要点**：矩阵必须持久化——掩膜逆变换回原图靠它。

### 4.2 阶段2：色彩校准（两步，均为全局线性变换）

```
步骤1 灰世界白平衡:  gain_c = mean(全图) / mean(通道c)，img *= gain
步骤2 参考ROI匹配:   img += (ref_mean_bgr − cur_roi_mean)
```

- **参考 ROI**：选本人**确定无白斑**的正常皮肤（本项目：鼻梁两侧两个 40×40 方块，y500-540, x358-398 / x494-534）。
- **参考目标均值** `ref_mean_bgr`：取 4 张照片 ROI 均值的平均（本项目 [151.7, 145.1, 157.3]），使所有照片颜色锚定到同一目标。
- **校验**：参考 ROI 的 L* 极差应 < 1（本项目 0.42）才算稳定。
- **输出**：`calibration.json`（wb_gains 每照片 3 通道、ref_mean_bgr、ref_lab、ipd_px、roi）。
- ⚠️ **致命陷阱**：参考 ROI 若落在白斑上，整个校准失效（见 §8-1）。必须验证或用自适应方法选 ROI。

### 4.3 阶段3：扩展画布

- 画布尺寸原则：**覆盖全部可能病灶区**。面部方案：900×1600（原画布 900×1200，上方 +150 覆盖发际线，下方 +250 覆盖颈部衣领）。
- 实现：变换矩阵左乘平移矩阵 `T = [[1,0,0],[0,1,OFF_Y],[0,0,1]]`，用 `T@M` 做 warp。
- 校准应用：`wb_gains` 直接乘（不在扩展图上重算灰世界均值！）；参考 ROI 坐标加 `OFF_Y` 偏移后计算平移量。
- **黑边处理**：`warp` 后 `max(通道)>10` 作为有效像素掩膜，训练/预测均排除黑边。

### 4.4 阶段4A：监督像素分类器（主方案，需一次人工标注）

**训练数据构造**（以第一张照片的人工标注为标签）：
1. 人工标注掩膜（原图坐标）经 `T@M` 投到扩展画布；
2. 正样本：标注区内随机采样 **40000** 像素；
3. 负样本：标注区外（有效像素内）随机采样 **40000** 像素；
4. （可选增强）难负样本：眼球/眉毛毛发/背景等易误检区额外采样作为负例——实测对"白衣不误标"很关键。

**特征向量**（6 维，全部在扩展画布校准图上计算）：
```
[L*, a*, b*, C=hypot(a*,b*), y/EH, x/EW]
```
Lab 转换：`cv2.cvtColor(BGR2LAB)`，L×=100/255，a/b 减 128。

**模型**：`sklearn.ensemble.RandomForestClassifier(n_estimators=250, max_depth=18, n_jobs=-1)`。

**预测**：逐像素 `predict_proba`，阈值 **0.5**（召回优先可降到 0.45）。

### 4.5 阶段5：后处理

```
1. 形态学闭运算(椭圆核5×5) → 填小孔、连接断点
2. 形态学开运算(椭圆核5×5) → 去小噪点
3. 发际线以上区域(扩展画布顶部)额外强开运算(核11×11)，防背景误标
4. 连通域过滤: 逆变换回原图坐标后, 保留面积 >= 300px 的连通域(原图坐标)
5. (可选) 肤色邻域校验: 掩膜 25px 半径内肤色占比 >= 0.15 才保留
```

**输出**：掩膜经 `inv(T@M)` 逆变换回原图坐标，`>127` 二值化；叠加红色（`0.4×原色 + 0.6×红`）并描边。

### 4.6 阶段4B：无监督冷启动（无人工标注时的替代方案）

没有任何人工标注时（新患者/新部位），用已验证的 K-means 引擎：

```
1. 几何区域约束: 面部椭圆 ∪ 颈部矩形（由关键点推算，排除背景/衣物）
2. 区域内对 (L*, 彩度C) 做 K-means(k=2)
3. 白斑簇 = "更亮且更低彩度"的簇;合理性检查:
   白斑簇 C < 正常簇 C 且 白斑簇 L* > 正常簇 L*（否则判为彩度反转,结果作废）
4. 高光上限: L* > 88 的像素排除（抑制镜面反光）
5. 排除块清零: 仅排眼球本体/眉毛毛发/鼻孔/唇黏膜/发际线以上
   ——切勿排除眉周/鼻侧/口周皮肤（那里正是白斑高发区）
6. 肤色邻域校验 + 连通域过滤(≥150px)
```
参考实测：本项目 20260731 聚类中心 白斑簇[64.07, 6.41]、正常簇[44.17, 8.13]，sane=通过。

### 4.7 两种方案的取舍

| | 监督分类器(§4.4) | 无监督K-means(§4.6) |
|---|---|---|
| 需要人工 | 一次标注 | 零 |
| 复现患者口径 | ✅ IoU 0.84 | 口径不同（精确皮损） |
| 跨照片稳定性 | 高（同色空间内） | 中（依赖聚类合理性） |
| 适用 | 随访跟踪（同患者多张照片） | 冷启动/首张照片 |

## 5. 参考实现（已验证代码核心）

### 5.1 扩展画布校准图生成

```python
EW, EH, OFF_Y = 900, 1600, 150   # 扩展画布尺寸与偏移

def extended_calibrated(photo, tf, cal):
    """原图 -> 扩展画布 -> 与流水线口径一致的色彩校准。"""
    M = np.array(tf["transforms"][photo], np.float64)
    T = np.array([[1, 0, 0], [0, 1, OFF_Y], [0, 0, 1]], np.float64)
    orig = cv2.imread(photo)
    warped = cv2.warpPerspective(orig, T @ M, (EW, EH),
                                 flags=cv2.INTER_LINEAR, borderValue=(0, 0, 0))
    # 步骤1: 用已保存增益(切勿在扩展图上重算灰世界均值)
    g = np.array(cal["wb_gains"][photo], np.float32)
    img = np.clip(warped.astype(np.float32) * g, 0, 255)
    # 步骤2: 参考ROI均值平移(坐标加 OFF_Y)
    ref = np.array(cal["ref_mean_bgr"], np.float32)
    ys, xs   = np.mgrid[500+OFF_Y:540+OFF_Y, 358:398]
    ys2, xs2 = np.mgrid[500+OFF_Y:540+OFF_Y, 494:534]
    cur = np.vstack([img[ys, xs].reshape(-1, 3),
                     img[ys2, xs2].reshape(-1, 3)]).mean(0)
    img = np.clip(img + (ref - cur), 0, 255).astype(np.uint8)
    return img, warped, M   # warped 用于生成有效像素掩膜(>10)
```

### 5.2 Lab 特征与训练/预测

```python
def lab_of(bgr):
    lab = cv2.cvtColor(bgr, cv2.COLOR_BGR2LAB).astype(np.float32)
    lab[..., 0] *= 100.0 / 255.0
    lab[..., 1] -= 128.0
    lab[..., 2] -= 128.0
    return lab

def feats(lab, yy, xx, EH, EW):
    L, a, b = lab[..., 0], lab[..., 1], lab[..., 2]
    return np.column_stack([L[yy, xx], a[yy, xx], b[yy, xx],
                            np.hypot(a, b)[yy, xx],
                            yy.astype(np.float32) / EH,
                            xx.astype(np.float32) / EW])

# --- 训练 ---
img31, warp31, M31 = extended_calibrated("第一张.jpg", tf, cal)
T = np.array([[1,0,0],[0,1,OFF_Y],[0,0,1]], np.float64)
uc = (cv2.warpPerspective(user_mask*255, T@M31, (EW, EH),
        flags=cv2.INTER_LINEAR) > 127).astype(np.uint8)
valid = warp31.max(2) > 10                      # 排除黑边
lab31 = lab_of(img31)
ys, xs = np.where((uc > 0) & valid)             # 正样本
yn, xn = np.where((uc == 0) & valid)            # 负样本
X = np.vstack([feats(lab31, ys[ip], xs[ip], EH, EW),   # 采样4万
               feats(lab31, yn[iq], xn[iq], EH, EW)])  # 采样4万
y = np.concatenate([np.ones(len(ip)), np.zeros(len(iq))])
clf = RandomForestClassifier(n_estimators=250, max_depth=18,
                             n_jobs=-1, random_state=0).fit(X, y)

# --- 预测 ---
imgp, warpp, Mp = extended_calibrated("新照片.jpg", tf, cal)
labp = lab_of(imgp)
Xp = feats(labp, *np.where(np.ones((EH, EW), bool)), EH, EW)  # 全图
prob = clf.predict_proba(Xp)[:, 1].reshape(EH, EW)
prob[warpp.max(2) <= 10] = 0
pred = (prob > 0.5).astype(np.uint8)
k = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (5, 5))
pred = cv2.morphologyEx(cv2.morphologyEx(pred, cv2.MORPH_CLOSE, k),
                        cv2.MORPH_OPEN, k)
pred = (pred & (warpp.max(2) > 10)).astype(np.uint8)

# --- 逆变换回原图 + 红色叠加 ---
warp = cv2.warpPerspective(pred*255, np.linalg.inv(T@Mp),
                           (orig.shape[1], orig.shape[0]), borderValue=0)
mask = (warp > 127).astype(np.uint8)
# 连通域 >= 300 保留后叠加:
vis = orig.copy()
vis[mask>0] = (vis[mask>0].astype(np.float32)*0.4
               + np.array([0,0,255],np.float32)*0.6).astype(np.uint8)
```

完整可运行版本见项目 `pipeline/auto_label_v3.py`（面部专用，含发际线顶部强开运算）。

## 6. 泛化到其他身体部位（手、脚、胳膊、腿、背、腹）

色值空间方法（§4.2/4.4/4.6）**与身体部位无关**——白斑在任何皮肤上都表现为 a*/b* 降低、L* 升高、彩度降低。需要替换的只是**阶段1 的定位方式**：

### 6.1 定位策略（按部位选择）

| 部位 | 定位方式 | 归一化基准 |
|---|---|---|
| 面部 | MediaPipe Face Landmarker 468点 | 瞳距 IPD |
| 手 | MediaPipe Hand Landmarker（21点） | 掌宽或中指长 |
| 全身/四肢/躯干 | MediaPipe Pose（33点）或人体检测框 | 肩宽或躯干长 |
| 局部特写（无完整肢体） | 皮损区域检测或固定拍摄协议 | 参照物（见 6.3） |

对齐目标：与面部同理，选定 2-5 个稳定解剖点，相似变换到统一画布，使同一解剖位置在不同照片间坐标一致（坐标特征才有效）。

### 6.2 参考 ROI 策略

- **首选**：同一张照片内、病灶邻近的**本人正常皮肤**（同一张照片内光照一致，比跨照片参考更稳）；
- 若照片内找不到确定正常的皮肤：用该患者历史照片中已确认正常的区域，或用灰世界白平衡单独工作（降级）；
- ROI 有效性自检：ROI 内彩度应处于"正常肤色"范围（C 通常 8~30），若 C 异常低（<5）说明 ROI 可能落在白斑上，必须重选。

### 6.3 面积归一化

跨照片面积对比必须除以一个身体尺度基准（面部用 IPD²；四肢用肢体宽度²；无基准时要求拍摄协议包含参照物，如硬币/色卡）。

### 6.4 部位特异性注意点

- **手足**：角质层厚、褶皱多，L* 天然偏高且纹理强——建议特征中加入局部方差或用更大形态学核；
- **躯干**：体毛会产生细碎低彩度像素——连通域最小面积阈值提高到 ~1000；
- **衣物边界**：白衣/浅色衣物与白斑色值接近，务必用几何区域约束或身体分割先排除衣物（本方案坐标特征+难负样本已验证可区分白衣）。

## 7. 完全自动化演进路线（无人工干涉的终态设计）

当前方案等级为 **L1（一次人工标注，此后全自动）**。通向"完全自动"的四级路线：

### L1 → L2：冷启动自动化（已具备，§4.6）
新患者首张照片无人工标注时，用无监督 K-means(L*,彩度) + 几何区域 + 合理性校验自动出初版掩膜。患者确认一次后即升级为 L1。

### L2 → L3：大模型视觉候选 + 色值验证闭环（推荐实现）
```
1. 多模态大模型(具备分割/定位能力)对新照片输出:
   - 疑似白斑区域的粗掩膜或边界框（top-K 候选）
2. 每个候选用色值规则验证:
   - 候选区域内彩度 C 中位数 < 邻近正常皮肤 C 中位数 × 0.85
   - 且 L* 中位数 > 邻近正常皮肤
   → 通过 = 确认白斑; 不通过 = 丢弃(如反光/白衣/疤痕)
3. 用确认的候选作为伪标签训练/更新像素分类器
4. 分类器输出精修掩膜(边缘级), 大模型候选负责召回
```
分工原则：**大模型管"在哪里像白斑"（语义/召回），色值引擎管"是不是真的"（验证/精度）**。二者互补——大模型单独用会把反光/浅色衣物当白斑，色值引擎单独用会漏掉弱对比病灶。

### L3 → L4：自学习闭环（终态）
- 每次识别结果与患者反馈（或随访照片间的面积连续性检查）自动沉淀为新训练样本；
- 跨时间一致性作为自动质检：同一患者相邻两次随访的预测掩膜互相 IoU 应 > 0.5，骤变自动触发复核；
- 训练集覆盖多部位后，形成部位无关的通用分类器。

### 自动质检指标（无人值守时的异常报警）
| 指标 | 正常范围 | 异常处理 |
|---|---|---|
| 预测面积/上次随访面积 | 0.5 ~ 2.0 倍 | 超出→标记复核 |
| 预测掩膜与几何区域交叠率 | > 90% | 低于→定位失败 |
| 白斑簇合理性(§4.6-3) | sane=true | 反转→作废重来 |
| 参考ROI彩度 | > 5 | 低于→ROI疑似在白斑上 |

## 8. 失败模式与陷阱清单（全部实测踩坑）

1. **参考 ROI 污染**：参考皮肤本身有白斑 → ΔE/校准全面失效，只检出镜面高光。→ 必须验证 ROI 彩度正常或自适应选点。
2. **排除块过度激进**：把眉毛/鼻子/嘴周整块排除 → 恰好排掉了白斑高发区。→ 只排"确定非皮肤"的结构：眼球本体、眉毛毛发、鼻孔、唇黏膜、发际线以上。
3. **画布裁剪**：对齐画布未覆盖病灶分布区（发际线/颈部被裁掉）→ 训练与预测盲区。→ 画布尺寸先评估病灶分布再定。
4. **单图绝对阈值**：未校准图上任何色值阈值都被光照支配。→ 一切分割必须在对齐+校准后的色空间进行。
5. **灰世界白平衡的副作用**：会同时压低正常肤色与白斑的彩度，可能削弱区分。→ 校准后以参考 ROI 锚定，不做全局直方图拉伸。
6. **布尔掩膜索引陷阱**：uint8(0/1) 数组被当作整数行索引导致内存爆炸。→ 索引前 `.astype(bool)`。
7. **OpenCV 版本**：OpenCV 5.0 移除 Haar 级联、`cv2.kmeans` API 变化。→ 关键点用 MediaPipe，聚类用 sklearn。
8. **标注口径混淆**：整片关注区（41-47万画布px）与精确皮损（16-19万）是两套口径，IoU 跨口径比较无意义。→ 全链路锁定一种口径。
9. **误把"位置先验"当作弊**：对齐画布上坐标是合法特征（解剖位置固定），去掉坐标特征反而漏检。→ 保留。
10. **逆变换输出尺寸**：`warpPerspective` 输出尺寸必须是目标坐标系尺寸（原图尺寸），误用源尺寸会导致错位。

## 9. 数据结构与接口规范

### transforms.json（对齐输出）
```json
{
  "canvas": [900, 1200],
  "target_eyes": [[x,y],[x,y]],
  "target_landmarks": [[x,y]x5],     // 左眼,右眼,鼻,左嘴角,右嘴角(画布坐标,所有照片共享)
  "landmarks_original": {"照片名": [[x,y]x5]},
  "transforms": {"照片名": [[3x3 相似变换矩阵]]}   // 原图→画布
}
```

### calibration.json（校准输出）
```json
{
  "wb_gains": {"照片名": [gB, gG, gR]},
  "ref_mean_bgr": [B, G, R],          // 全局目标均值
  "ref_lab": [L, a, b],
  "ipd_px": 378.0,                    // 面积归一化基准
  "roi": [{"y": [y0,y1], "x": [x0,x1]}, ...]   // 原画布坐标
}
```

### 文件组织（参考项目结构）
```
项目根/
├── <照片>.jpg                     # 原图(不修改)
├── pipeline/
│   ├── common.py                  # lab_of 等基础函数
│   ├── 01_align.py … 03_segment.py  # 对齐/校准/无监督分割
│   └── auto_label_v3.py           # 监督自动标注(主方案)
└── output/
    ├── aligned/ (对齐图 + transforms.json)
    ├── aligned/calibrated/        # 校准图
    ├── masks/                     # 分割掩膜(画布坐标)
    └── auto_v3_<照片>.png         # 原图坐标红色标注
```

### 验收指标
- 同图复现：自动掩膜 vs 人工标注 **IoU ≥ 0.75**（实测 0.84）；
- 跨照片一致性：相邻随访互相 **IoU ≥ 0.5**（实测 0.62-0.80）；
- 校准稳定性：参考 ROI 的 L* 照片间极差 **< 1.0**（实测 0.42）。
