### 公开 API 契约
```
GET /api/knowledge/cards?topic=&preview=1
  → { topics:[{key,label}], items:[CardSummary] }
  CardSummary = { slug, topic, title, summary, evidence_level, source_count,
                  reviewed_at, ai_assisted, status }
GET /api/knowledge/cards/{slug}?preview=1
  → Card = CardSummary + { body_md, sources:[Source], next_review_at, related:[slug], disclaimer }
  Source = { type:'pmid'|'doi'|'nct'|'guideline'|'url', ref, title, url, year, evidence_level }
GET /api/knowledge/pipeline?preview=1
  → { updated_at, items:[{ key, drug_zh, drug_en, mechanism, route, sponsor, phase,
       regions:[{region,status,date}], latest_event, event_date, sources:[{label,url}],
       checked_at, status }] }
GET /api/knowledge/digests?limit=&preview=1
  → { items:[{ key, title_zh, title_en, one_liner, why_it_matters, limitations,
       study_type, sample_size, is_preprint, published_on, journal, url, pmid, status }] }
GET /api/knowledge/research
  → { purposes:[{purpose,title,description,open,active:{value,status,note}}], projects:[], note }
```
`preview=1` 仅对 `is_admin` 用户生效（附 draft 等未发布内容，含 status）；其他人忽略。

### 管理 API
```
GET  /api/admin/knowledge/{kind}?status=      kind ∈ cards|pipeline|digests
POST /api/admin/knowledge/{kind}/{id}/transition { to, note, reviewer_label }
GET  /api/admin/knowledge/{kind}/{id}/logs
```
