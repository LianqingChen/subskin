# 白斑识别全自动自循环优化方案（测评 + 对比报告）

> **日期**：2026-08-27
> **依据**：`hermes_plan/VITILIGO_AUTO_SEGMENTATION_METHOD.md`（实测验证方法，同图复现 IoU 0.84、跨照片一致性 IoU 0.62~0.80）
> **目标**：完全不需要人为干预，靠大模型 + 患者级像素分类器精准识别全部白斑，并追踪每处白斑随时间的变化；系统自循环持续提升准确率。
>
> **本文档是实施契约**：§1 现状 → §2 设计决策 → §3 架构 → §4-§10 分模块设计 → §11 验收 → §12 部署。

## 1. 现状盘点（三份代码分析报告的结论）

### 1.1 测评识别链路（活跃）
`vasi.py:_call_vasi_api`：质检 → 灰世界预处理 → **VLM 候选**（qwen-vl-max 输出 skin bbox + 疑似白斑 bbox/center/edge_points）→ **VLM 引导 SAM 分割** → 元数据富化 → VASI 公式。三级兜底：自动 SAM → tiling → nnU-Net 远程。**每张照片独立无状态处理**。

### 1.2 对比报告链路（活跃）
`spot_compare.py`：VLM 双图对比（复色/颜色/边缘/趋势投票）+ **CV 交叉验证**（`_cv_measure` 在未校准原图上用 HSV/YCrCb 绝对阈值，每次重算，**不复用 VASI 已存的 SAM 掩膜**）+ 质量系数 + dHash 近重复短路。`photo_align.py` 提供 ORB+RANSAC 配准热力图（仅可视化，不参与分割）。

### 1.3 自进化栈（2026-06-13 起整体禁用）
`vasi_feedback.py` / `vasi_evaluator.py` / `vasi_param_optimizer.py` / `experiments/vasi_evolution.py` / `vasi_prompt_evolver.py` / `vasi_rl_optimizer.py` 六个工厂函数全部 `return None`（原因：数据量不足以支撑 RL）。后果：反馈 API 503、`vasi_training_samples` 表不再增长、进化全靠管理员手动。**唯一沉淀的原料**是 `vasi_assessments.contour_diff`（用户修正 vs AI 的 Dice）。

### 1.4 与文档方案的差距（按严重度）
| # | 缺口 | 影响 |
|---|---|---|
| G1 | **对齐 + 色彩校准 + 统一画布完全缺失** | 文档 §2.3/§2.4 证明：未校准单图色值被光照支配，颜色分割原则上不可行；当前所有 CV 验证踩了 §8-4 的坑 |
| G2 | **患者级像素分类器缺失**（RF 监督 / K-means 冷启动） | 无"色值引擎管精度"，SAM/VLM 单飞会把反光/白衣/疤痕当白斑 |
| G3 | L3「色值验证闭环」缺失 | VLM 候选未经 C<0.85×邻近皮肤 且 L* 更高的确认/丢弃 |
| G4 | 自学习闭环零激活 | 准确率无法随使用提升 |
| G5 | 无物理面积归一化 + 无病灶身份追踪 | 只能比"相对比例"，无法追踪每一处白斑的生死 |
| G6 | 无自动质检门禁（文档 §7 指标表） | 无人值守时无异常报警 |
| G7 | 三套趋势口径不一致（"恶化/加重"、±5%/±12%） | 患者看到矛盾结论 |

## 2. 核心设计决策

**D1 — 以「患者级对齐+校准+像素分类器」为第二引擎，与 VLM/SAM 组成共识系统。**
文档方法只需每患者每部位 1 次标注即可训练（IoU 0.84），K-means 冷启动甚至零标注即可用。**恰好绕开"自进化栈因数据不足被禁用"的死结**：不需要 200 张跨患者样本，每位患者几张随访照片就能收敛。

**D2 — 分工原则（文档 §7 L3）**：VLM/SAM 管"哪里像白斑"（召回），患者像素分类器 + 色值验证管"是不是真的"（精度），两者 IoU 共识定置信度，分歧交 LLM 裁判（裁剪局部图二次询问）→ 裁决结果作为伪标签回喂训练。

**D3 — 无人干预 = 自动终审 + 被动纠错**：共识达标且质检门禁通过时评估**自动 finalize**（不再需要用户点确认）；用户在结果页仍可修正（修正自动成为训练样本）。患者模型越练越准 → 自动终审比例自然上升。

**D4 — 自循环闭环四步**：采集（用户修正 + LLM 裁判伪标签）→ 训练（患者 RF 重训 + shadow 评估）→ 部署（优于旧模型才替换，自动回滚保底）→ 质检（文档 §7 指标自动巡检）。全部由后台循环驱动，**零管理员操作**。

**D5 — 对比追踪基于统一画布**：同一患者同部位照片在统一画布上预测掩膜 → 画布坐标面积除以身体尺度基准归一化 → 跨照片按 IoU 匹配病灶身份 → 每处白斑独立轨迹（新增/扩大/缩小/消失/复色）。

**D6 — 安全底线**：所有新路径均为加法；模型不可用时优雅降级到现状行为；自动终审仅在门禁全过时生效；LLM 裁判限速限成本；患者模型仅患者本人可用。

## 4. 患者级时空画布管线（`services/vasi_canvas.py`，新建）

### 4.1 定位与对齐
- **面部**：MediaPipe Face Landmarker（468 点）取 5 关键点（双眼、鼻、两嘴角），最小二乘相似变换到统一画布 **900×1600**（上 +150 覆盖发际线、下 +250 覆盖颈部），瞳距归一化 ipd=378px。目标关键点 = 该患者该部位首张照片的关键点（后续照片对齐到它）。
- **手部**：MediaPipe Hands（21 点）；**躯干/四肢**：MediaPipe Pose（33 点，取肩/髋稳定点）；两者用相似变换到各自画布（画布尺寸 = 首张照片按基准尺度归一化后取覆盖范围）。
- **局部特写/无法检测关键点**：对齐降级为**恒等变换**（原图即画布），标记 `aligned=false`，追踪口径退化为"皮肤区域占比"并如实提示。
- 变换矩阵持久化（每张照片一份，逆变换回原图用）。

### 4.2 色彩校准（文档 §4.2）
1. 灰世界白平衡：逐通道增益（在**原图**上计算，应用到画布图，不在扩展图上重算）。
2. 参考 ROI 均值平移：自动选点——优先同一张照片内病灶邻近、确定正常的皮肤块（排除 VLM/SAM 病灶掩膜周边区域），**彩度自检 C>5**（文档 §6.2）；首张照片选好后锚定 `ref_mean_bgr` 为该患者该部位基准，后续照片平移至此基准。
3. 校验：参考 ROI 的 L* 照片间极差 < 1.0 视为校准稳定（文档 §9）。
4. 输出 `calibration.json`（wb_gains、ref_mean_bgr、ref_lab、roi、ipd_px）。

### 4.3 输出约定
`canvas_json` 快照随评估存库（transforms + calibration + 画布参数 + aligned 标志 + 质量分数），供对比/追踪链路复用，**避免重复计算**。

## 5. 患者级像素分类器（`services/vasi_patient_model.py`，新建）

### 5.1 冷启动：K-means（文档 §4.6，零标注可用）
1. 几何区域约束（皮肤掩膜 ∪ 白斑扩张区，排除背景/衣物）；
2. 对 (L*, 彩度C) 做 K-means(k=2)；
3. 白斑簇 = 更亮且更低彩度的簇；合理性检查：`白斑簇C < 正常簇C 且 白斑簇L* > 正常簇L*`，否则作废；
4. 高光上限 L*>88 排除；仅排眼球/眉发/鼻孔/唇黏膜/发际线以上；
5. 形态学开闭 + 连通域过滤（≥150px）+ 肤色邻域校验。
通过合理性检查的 K-means 掩膜**同时作为首张照片的伪标签**（口径=精确皮损），可立即训练 RF。

### 5.2 监督：随机森林（文档 §4.4）
- 特征 6 维：`[L*, a*, b*, C=hypot(a*,b*), y/EH, x/EW]`（校准画布上计算）；
- 正样本：标注/伪标签区内随机采样 ≤40000；负样本：区外有效像素随机采样 ≤40000，**额外采样难负例**（眼球/毛发/白衣/背景）；
- 参数：`RandomForestClassifier(n_estimators=250, max_depth=18, n_jobs=-1, random_state=0)`；
- 预测：全画布逐像素 `predict_proba`，阈值 0.5（召回优先 0.45），黑边（`max(channel)<=10`）置零；
- 后处理：闭运算(椭圆5×5) → 开运算(椭圆5×5) → 发际线以上额外强开(11×11) → 逆变换回原图 → 连通域 ≥300px。

### 5.3 训练源（自循环燃料，全部无人干预）
| 源 | 触发 | 口径 |
|---|---|---|
| 用户修正掩膜（已有 `user_lesion_layer`） | 用户修正轮廓时 | 用户口径（最高权重） |
| K-means 冷启动掩膜 | 首张照片、合理性检查通过 | 精确皮损 |
| **LLM 裁判伪标签**（新增） | SAM 与患者模型分歧、VLM 复核裁决 | 语义口径 |
| 跨照片共识掩膜 | 相邻随访画布掩膜 IoU>0.5 的双确认区 | 稳定区 |

### 5.4 持久化与版本
- 模型文件：`data/vasi_models/{user_id}/{body_site}/model.joblib`；
- 注册表 `patient_models` 表：版本、训练源统计、shadow Dice、is_active；
- **shadow 评估**：用留出的 20% 修正掩膜评估新旧模型 Dice，**更优才激活**；退化自动回滚到上一活跃版本。

## 6. 共识引擎与自动终审（集成进 `vasi.py` assess）

```
SAM 掩膜(原图坐标) + 患者模型掩膜(画布→逆变换原图坐标)
   │
   ├─ 双方都有结果: 计算 IoU
   │    IoU ≥ 0.5 → 共识命中, conf = 0.6 + 0.4×IoU
   │    IoU < 0.5 → 分歧
   │
   ├─ 只有一方有结果 → 分歧（疑似漏检/误检）
   │
   └─ 分歧处理:
        1. 色值验证(画布上): 候选区 C中位 < 邻近正常皮肤C中位×0.85 且 L*更高 → 确认
           不通过 → 丢弃(反光/白衣/疤痕)
        2. 仍无法裁决 → LLM裁判: 裁剪局部区域送 VLM 问"是否为白斑"（限速）
           裁决=伪标签, 入训练队列
```

**自动终审条件**（全部满足才 `status=active`，无需用户确认）：
1. 质检 overall ∈ {good, acceptable}；
2. 共识命中（IoU≥0.5）或色值验证明确通过；
3. 文档 §7 质检门禁通过（面积比、交叠率、ROI 彩度）；
4. 患者模型存在（冷启动后）或 K-means 合理性通过。
不满足 → 维持 draft，用户可修正（修正自动入库）。`auto_finalized=true` 记录在评估上，前端展示"AI 已自动确认"。

## 7. 对比与追踪升级（`spot_compare.py` / `skin_report.py`）

### 7.1 画布面积追踪（替换 `_cv_measure` 为主证据）
- 图对对比时：取两图各自的 `canvas_json` + 患者模型掩膜（或复用评估已存的 `ai_lesion_layer`/`user_lesion_layer` 逆变换到画布）→ **画布坐标面积 px** → 除以身体尺度基准²（面部 IPD²；其他部位画布基准尺度²；恒等对齐时退化为皮肤区域占比）。
- `size_change_percent` 主证据改为画布面积变化；旧 `_cv_measure` 降级为兜底（患者模型/画布不可用时）。
- 自动质检：面积比超出 0.5~2.0 → 不伪造结论，标记"拍摄条件变化，建议复核"。

### 7.2 病灶身份匹配与轨迹（新表 `lesion_tracks`）
- 同患者同部位按时间排序的每张照片画布掩膜 → 贪心匹配（相邻两次 IoU>0.3 或中心距 < 画布边长 5%）→ 同一病灶获得稳定 `track_key`；
- 每处病灶轨迹：`新增 / 扩大 / 缩小 / 消失 / 复色(内部出现色素岛)` + 面积曲线；
- 跨时间一致性自动复核：相邻两次掩膜 IoU < 0.5 且面积比正常 → 触发 LLM 裁判复核该病灶（限速），复核结果修正轨迹。

### 7.3 口径统一（修复 G7）
- 趋势词统一为"好转/稳定/加重"；VASI 趋势与 spot_compare 阈值统一为 ±10%（面积）与 ±5%（VASI 分）；
- 缓存 key 加入 `model_version`，模型升级后旧缓存自动失效。

### 7.4 周报/月报
- 对比报告复用画布掩膜与 `lesion_tracks`，输出每病灶面积变化表与"最大变化病灶"提示。

## 8. LLM 自循环引擎（`services/vasi_autoloop.py`，新建 + lifespan 后台任务）

### 8.1 重新启用反馈收集（最小范围）
- `get_feedback_collector` 与 `get_evaluator` 工厂解除 `return None`（其余 RL/prompt/param 进化器保持禁用，避免未经验证的大动作）；
- 用户修正/评分/停留/分享信号重新入 `vasi_feedback_signals`；修正掩膜重新入 `vasi_training_samples`（Dice、面积误差留痕）。

### 8.2 后台循环（lifespan 启动，周期可配，默认每 10 分钟）
```
loop:
  1. [采集] 扫描新用户修正 + LLM裁判伪标签 + K-means冷启动伪标签 → 训练队列
  2. [训练] 队列中每 (user_id, body_site): 重训 RF → shadow 评估(留出修正掩膜)
  3. [部署] 新模型 Dice 优于当前活跃 → 激活并写 vasi_model_versions;
           连续 2 次劣于基线 → 自动回滚
  4. [裁判] 处理分歧队列: 裁剪区 VLM 复核(每分钟 ≤2 次, 成本护栏)
  5. [质检] 对近 24h 评估跑 §7 指标巡检 → 异常写 auto_loop_runs + admin 可见
  6. [统计] 写 auto_loop_runs 审计行(触发原因/结果/耗时)
```
- 所有步骤 try/except 隔离，单点失败不影响下一轮；
- 进化器仍是 DB 版本化（`vasi_model_versions`），回滚只读历史。

### 8.3 数据量自适性
- 患者模型：每患者每部位 ≥1 张带掩膜照片即可训练（冷启动当天就有）；
- 跨患者泛化不做（保护隐私 + 数据不足），RL/prompt 进化器留待样本量达标后由后续迭代开启。

## 11. 实施顺序与验收

| 步骤 | 内容 | 验收 |
|---|---|---|
| 1 | 安装 mediapipe+scikit-learn，下载 face/pose/hand landmark 模型 | venv import 通过；模型文件就位 |
| 2 | `vasi_canvas.py`（对齐+校准） | 单测：同一张脸两次变换，画布坐标一致；ROI 彩度自检逻辑通过 |
| 3 | `vasi_patient_model.py`（K-means+RF+持久化） | 单测：合成图 K-means 合理性检查；RF 训练/预测/逆变换闭环 |
| 4 | 数据模型 + 迁移 | 新表/新列 additive 创建成功 |
| 5 | `vasi.py` 共识+自动终审集成 | 无患者模型时行为与现状一致（回归）；有模型时共识 JSON 正确 |
| 6 | `spot_compare.py` 画布面积+病灶匹配 | 图对对比走画布主证据；轨迹表写入 |
| 7 | `vasi_autoloop.py` + lifespan | 后台循环启动；模拟修正掩膜触发训练/部署/审计 |
| 8 | API：tracking/self-learning 状态端点 + assess 响应扩展 | 新端点返回轨迹与自学习状态 |
| 9 | 前端三页改造 | 视觉验收 + 类型检查通过 |
| 10 | 部署 staging + DEPLOY_LOG | staging 验证；用户确认后 prod |

**总体验收（对应文档 §9 + 目标）**：
- 患者有 ≥2 张同部位随访照片时：系统自动对齐+校准，自动识别全部白斑，自动终审无人工确认；
- 相邻随访画布掩膜 IoU ≥ 0.5（文档实测 0.62~0.80 水平）；
- 每处白斑有独立轨迹（新增/扩大/缩小/消失）与归一化面积曲线；
- 用户每次修正（若有）自动提升该患者后续识别准确率（shadow Dice 单调提升）；
- 全流程零管理员操作，`auto_loop_runs` 有完整审计。

## 12. 部署与安全

- 依赖安装与模型下载只影响服务器本地，不重启服务；
- 后端代码变更共享 backend（影响三环境）→ **重启前明确告知用户**；
- 前端先 `npm run build`（staging），用户确认后再 `deploy:prod`；
- 患者模型/画布数据按 L3 隐私处理：仅 owner 可经 API 访问，不进日志、不进 Git；
- `data/vasi_models/`、mediapipe 模型目录加入 `.gitignore`。
