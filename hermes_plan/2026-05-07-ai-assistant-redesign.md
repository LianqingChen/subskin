# AI助手页面改造计划

**日期**: 2026-05-07
**参考**: 豆包AI助手页面设计

## 设计分析

参考设计的核心特征：
- 纯白背景，大量留白，视觉极简
- **胶囊分段选择器**切换模式（快速/专家），选中态淡蓝背景+蓝字，未选中透明+黑字
- 标题 "使用专家模式开始对话" + 灰度提示文字
- **悬浮输入容器**：大圆角浅灰背景，底部带功能按钮（深度思考、智能搜索）
- 无冗余装饰，信息层级清晰

## 改造目标

> 简洁、明了、功能清晰

## 具体改动

### 1. ChatAssistantPage.vue — 整体重构

**Header 区域**：
- 去掉大蝴蝶（55vh 占据太多空间）
- 改为紧凑的顶部导航：左侧菜单图标，右侧新建对话图标
- 中间放置胶囊分段选择器 `[💡 智能问答] | [💚 心理陪伴]`

**内容区**：
- 去掉原来的卡片叠加布局（`margin-top: 55vh`）
- 改为全屏白色背景，聊天内容从胶囊选择器下方开始
- 模式切换时，提示文字跟随变化：
  - 智能问答：「循证医学知识，随时为你解答」
  - 心理陪伴：「温暖倾听，安静陪伴」

**输入区**：
- 改为悬浮式大圆角容器（`border-radius: 24px`）
- 输入框 placeholder: "输入你的问题..."
- 底部功能按钮行：
  - 智能问答模式：`[🔍 循证医学] [📚 知识库]` + 语音按钮
  - 心理陪伴模式：`[🌿 心情记录] [🧘 正念呼吸]` + 语音按钮

### 2. ChatPanel.vue — 简化

- 去掉内部 header（模式标题），由外层统一管理
- 输入框移除外层，ChatPanel 只负责消息展示 + 预设问题
- 聊天消息气泡保持现有样式

### 3. CounselingPanel.vue — 简化

- 去掉内部 header
- 心情记录、正念呼吸移到输入区的功能按钮
- CBT 想法记录保持
- 消息展示保持

## 文件改动清单

1. `web/app/src/views/ChatAssistantPage.vue` — 重写
2. `web/app/src/components/assistant/ChatPanel.vue` — 精简头部和输入区
3. `web/app/src/components/assistant/CounselingPanel.vue` — 精简头部和输入区

## 保持不变的

- chatStore 逻辑
- API 调用方式
- 流式响应处理
- 危机检测逻辑
- 预设问题数据
- 历史对话功能
