## 二、白癜风患者核心痛点分析

| # | 痛点 | 深层需求 | 现有平台满足度 |
|---|------|---------|--------------|
| 1 | **信息焦虑** — 刚确诊时极度恐慌，网上信息鱼龙混杂，莆田系医院广告满天飞 | 可信的、结构化的、个性化的疾病知识 | ❌ 百度/知乎充斥广告 |
| 2 | **孤独感与病耻感** — 身边没人理解，不敢暴露患处，社交退缩 | 安全的、匿名的、被理解的倾诉空间 | ⚠️ 贴吧/QQ群质量低、广告多 |
| 3 | **治疗效果不可量化** — 治了半年不知道有没有效，全凭感觉 | 客观的、可视化的、持续的病情追踪 | ❌ 没有任何平台做到 |
| 4 | **医患信息不对称** — 3分钟门诊说不清楚，报告看不懂 | 诊前准备 + 报告解读 + 治疗方案理解 | ❌ 好大夫只能挂号 |
| 5 | **治疗信心崩塌** — 反复发作、看到别人治不好就绝望 | 真实的、可验证的康复案例 + 同伴支持 | ⚠️ 碎片化、无法验证 |
| 6 | **病因不明、方案迷茫** — 不知道为什么会得，不知道怎么选治疗方案 | 个性化病因分析 + 循证治疗路径 | ❌ 完全空白 |

## 三、核心价值主张

### 一句话定位

> **"AI驱动的白癜风全程管理平台"** — 不只是社区，而是每个白友的AI私人健康管家 + 病友互助网络。

### 核心差异化价值（传统平台做不到的）

| 价值点 | 传统社交媒体 | SubSkin AI社区 |
|--------|------------|---------------|
| **病情客观记录** | 发照片靠肉眼对比 | AI自动量化白斑面积/严重度，生成趋势曲线 |
| **AI病因探索** | 搜到什么看什么 | 基于用户日记/饮食/压力/环境数据，AI发现个人可能的诱因模式 |
| **智能治疗档案** | 零散聊天记录 | AI自动从帖子/对话中提取用药/治疗信息，构建个人治疗时间线 |
| **可信知识获取** | 广告+谣言 | RAG基于PubMed文献+诊疗指南，每条回答有出处 |
| **AI生活记录** | 手动写日记 | 对话式记录 → AI自动结构化（心情/饮食/睡眠/用药/患处变化） |
| **智能匹配** | 随机刷到 | 按病型/部位/治疗方案/城市匹配相似病友 |
| **疗效众验** | individual 经验 | 聚合匿名数据：同病型/同方案的有效率统计 |
| **危机干预** | 无 | AI检测心理危机信号，主动提供支持和资源 |

## 四、最核心最能吸引用户的功能点（MVP优先级）

### 🥇 第一梯队 — 核心留存引擎

1. **AI病情日记 + 智能追踪**
   - 对话式记录（"今天吃了什么、心情怎样、患处有没有变化"）
   - AI自动提取结构化数据（饮食/情绪/用药/睡眠/压力）
   - 与VASI评估联动 → 自动生成周报/月报
   - **杀手级功能**：AI发现个人诱因模式（"你连续3周熬夜后，白斑边缘有扩散趋势"）

2. **AI问答 + 可信知识库**（已有，需强化）
   - 已有RAG基础，需增加：个性化上下文（"根据你的治疗档案..."）
   - 社区经验聚合（"有12位同病型白友分享过308激光经验"）

3. **真实治疗经验社区**（已有，需聚焦）
   - 结构化治疗分享模板（方案/周期/效果/费用）
   - 治疗时间线可视化
   - 疗效可验证（关联VASI评估数据）

### 🥈 第二梯队 — 增长飞轮

4. **AI治疗档案**
   - 自动从日记/帖子/报告中提取治疗事件
   - 生成个人治疗时间线
   - 复诊前一键生成"给医生看的摘要"

5. **智能病友匹配**
   - 相似病友推荐（同病型/同部位/同方案/同城市）
   - "和你情况相似的白友，最近都在讨论..."

6. **群体疗效洞察**（匿名聚合）
   - "使用308激光+他克莫司的非节段型白友，3个月改善率约62%"

### 🥉 第三梯队 — 生态完善

7. 视频分享（治疗vlog、心路历程）
8. 医生入驻 + 在线科普
9. 临床试验匹配
10. AI心理陪伴升级（CBT引导、正念练习）

## 五、冷启动策略

### 核心原则：先做工具，后做社区

> 社区冷启动最大陷阱：没有内容 → 没有用户 → 没有内容。
> 解法：用AI工具价值吸引用户，用社区沉淀用户。

### Phase 1：AI工具引流（0-3个月）

**切入点：AI白斑测评 + AI问答**

- 这两个功能不需要社区内容就能独立提供价值
- 推广渠道：
  - 小红书/抖音：发"AI测白斑"的体验视频（天然传播性）
  - 白癜风贴吧/QQ群：分享"免费AI测评"工具
  - 搜索引擎SEO：白癜风相关长尾词
- 关键指标：日活测评次数、AI问答次数

### Phase 2：日记习惯养成（3-6个月）

**切入点：AI病情日记**

- 引导测评用户开始记录
- AI对话式记录门槛极低（聊天就行）
- 每周生成"病情周报" → 用户有获得感
- 可选公开 → 自然产生社区内容
- 关键指标：7日留存、日记连续记录天数

### Phase 3：社区网络效应（6-12个月）

**切入点：结构化治疗分享 + 病友匹配**

- 有3个月以上日记的用户 → 邀请分享治疗经验
- AI辅助生成分享帖
- 相似病友互相看到 → 产生连接
- 关键指标：发帖率、互动率、好友数

### 种子用户获取

| 渠道 | 策略 | 预期效果 |
|------|------|---------|
| 白癜风贴吧 | 以患者身份分享AI测评体验 | 精准但慢 |
| 小红书 | "AI帮我记录白癜风治疗100天"系列 | 传播性强 |
| 抖音/快手 | 短视频：AI测评过程 + 治疗对比 | 曝光大 |
| 白癜风QQ群/微信群 | 群内分享工具链接 | 精准转化高 |
| 皮肤科医生 | 邀请医生推荐患者使用 | 信任背书 |
| SEO | 白癜风知识长尾词 | 持续被动流量 |

## 七、技术架构演进建议

```
当前架构（够用）                    未来架构（用户>1万后）
─────────────────                  ─────────────────────
SQLite单库                    →    PostgreSQL + Redis缓存
单机Uvicorn                   →    Nginx负载均衡 + 多Worker
本地文件存储                   →    阿里云OSS（图片/视频）
同步LLM调用                   →    异步任务队列（Celery/RQ）
全量向量搜索                   →    向量数据库（Milvus/pgvector）
PWA                          →    PWA + 微信小程序（扩大触达）
```

当前阶段建议：SQLite + 单机完全够用（日活<1000），不要过早优化。把精力放在功能价值上。

## 九、总结

> SubSkin的核心竞争力不是"社区"，而是"AI驱动的白癜风全程健康管理"。
> 社区是留存手段，AI工具是获客引擎，数据是终极壁垒。

冷启动最佳切入点 = **AI白斑测评（已有）+ AI病情日记（待建）+ 周报/洞察（待建）**

闭环：**测评 → 记录 → 洞察 → 再测评**，用户不需要等社区有人就能获得完整价值。
