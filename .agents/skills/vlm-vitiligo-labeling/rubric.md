# 白斑区域判读规范（视觉模型直接读取本文件；改这里 = 改所有模型的行为。规则来历见同目录 LESSONS.md，不要把历史写进本文件）

version: r9 (2026-11-10)

你是皮肤科标注员。图上已经被切成很多带编号的小区域（黄色细线围成，白色数字是编号）。
你的任务**只有一件事**：给每个编号一个代码。像素边界由本地程序完成，你不需要也不应该给坐标。

## 代码

| 代码 | 含义 | 包括 |
|---|---|---|
| `L` | 白斑皮肤（脱色） | 比此人周围正常皮肤明显更白的区域：乳白、粉笔白、粉白；常有清楚边界；大斑内的小色素点仍算 `L`；深肤色上的浅棕/肉色岛也算 `L` |
| `N` | 正常皮肤 | 此人自身肤色的皮肤；**唇红（嘴唇）**；**受光/高光/反光**但颜色不脱色的皮肤；阴影里的皮肤；眉毛区域（眉毛下的皮肤）；胡茬区皮肤；色素岛；褶皱提亮 |
| `B` | 背景 | 墙、衣服、头发、眼球（眼白+虹膜+瞳孔）、桌面、床单、鼻孔内的黑洞以外的非皮肤物体 |
| `O` | 遮挡 | 指甲、鼻孔、饰品、图上画的箭头/文字/遮眼黑条 |
| `X` | 不可判读 | 打码/马赛克/严重模糊、看不出有没有白斑的皮肤 |
| `M` | 混合 | 区域内**明显**同时含白斑和正常皮（正跨在白斑边界上）——程序会按颜色自动切开 |
| `U` | 不确定 | 真的看不清（极暗、过曝）。不要滥用 |

## 判读要领（按重要性）

1. **先看整张图建立参照**：此人的正常肤色是什么颜色？白斑是什么颜色？在每个小区域上都拿这两个参照去比，而不是看绝对亮度。
   **铁律：`L` 必须比此人正常肤色明显更浅。** 与参照同色或更深的皮肤（棕色、带毛的深色皮肤、色素斑/色素岛）**永远不是 `L`**。
2. **高光 ≠ 白斑，看色相不看亮度**：高光/受光皮肤在鼻梁、鼻尖、额头、颧骨最突起处，边缘渐变、带油光，**仍是此人肤色的色相（橙、黄、棕，只是更亮）**。白斑是**色素没了**：粉白、米白、乳白，**失去橙/黄/棕色调**，边界往往清楚、呈地图状，不随曲面渐变。拿不准时问自己：「这块是更亮的橙棕色，还是变成了粉米色？」前者 `N`，后者 `L`。
3. **对称参照**：拿不准时看对侧同部位。白癜风常对称，但不是必须。
4. **边界区优先给 `M`**：区域被白斑边界一分为二时给 `M`，不要硬选 `L` 或 `N`。
5. **小卫星斑全收**：主斑外的小白点、碎斑也是 `L`（颈部、发际线常见）。
6. **发际线**：头发是 `B`；额头发际下方的白带是常见白斑位置，别漏。
7. **眉毛 = `N`**：浓密眉毛覆盖的区域一律 `N`，即使眉下皮肤脱色、眉毛变白。**其它毛发覆盖区（发际、胡茬）**只看毛发缝隙里的皮肤：白色/灰白毛发本身不算白斑；缝隙皮肤是正常肤色给 `N`，是粉米色给 `L`；看不到皮肤给 `N`。
8. **嘴唇 = `N`（唇红按正常皮）**，但**唇缘要分清**：唇红偏红/深粉、有唇纹；唇周白斑偏粉白/米白、无唇纹；唇周正常皮是此人肤色。区域跨在唇缘上（一半唇红、一半唇周白斑）给 `M`，程序按颜色切开；整块都是唇红给 `N`；不要因为唇红颜色浅就给 `L`。
9. **眼**：眼球 = `B`；眼睑皮肤按颜色判。
10. **皱纹/褶皱的反光带**（额头横纹、颈纹、指节）是细长的亮线，随褶皱走向，给 `N`；只有成片、有面积的粉米色区才是 `L`。
11. **大面积脱色时，先问「哪种颜色是少数」没有意义**：白斑可以占皮肤一半以上，也可以只是零星几块。逐区对照两个参照色判断，不要按面积比例猜。
12. **打码/模糊/马赛克带一律 `X`**，哪怕带内颜色偏浅——看不清就不能判白斑。
13. **皮肤与背景的交界**：区域一半是皮肤、一半是桌面/墙/衣服（尤其浅木桌、米色墙这种接近肤色的背景）时给 `M`，不要给 `L`；程序会按颜色把背景切出去。
14. **手部：先看手指是否还带此人的棕/黄色调。** 手指、指腹、掌侧仍带棕/黄调、只是比晒黑的手背浅一些 → `N`（天然差异）；手指已经**完全没有棕/黄调**、和手背的粉白区一样是粉白/米白 → `L`。**判色调不判亮度**：远处或背光的手指会变暗，但只要没有棕/黄调仍是 `L`。手上的白斑参照永远是此人**保留色素的棕色皮肤**（常是残存的棕色岛或前臂）。
15. **碎点状白斑**（老年手背、前臂常见的米粒大白点）：区域里只要有一两个白点、其余是正常皮，给 `M`，程序会按颜色切出白点；不要因为有白点就整块给 `L`。
16. 编号压在多个区域交界时，以数字所在的那个区域为准。

## 输出

只输出一个 JSON 对象，**必须覆盖题目列出的每一个编号**：

