# 日记合并到白友圈 · 重构迁移方案

## 目标架构

```
之前：/diary（DiaryEntry+DiaryImage）+ /community（Post+PostImage）  ← 两套记录
之后：/community（Post+PostImage，唯一记录入口）
      ├─ 私密帖 = 个人病情日记（AI 自动提取+图片分析）
      ├─ 公开帖 = 分享到白友圈
      └─ AI 报告层：基于全部帖子内容 + 图片分析，生成周报/月报/对比报告
底部导航：问答 / 测评 / 白友圈（3 Tab，去掉日记）
```

**核心原则**：AI 能力的核心逻辑（LLM 调用、视觉分析、报告生成）**全部复用**现有代码，只是把数据源/触发点从 DiaryEntry/DiaryImage 切到 Post/PostImage。报告系统的查看页/海报/PDF/分享基本不动。

---

## 一、后端改动（全部 additive，后端共享需谨慎）

### 1. PostImage 加字段（照搬 DiaryImage 的 5 字段 + user_id）
`database/models.py` PostImage 类新增：
- `user_id`（冗余，方便按用户查图/历史对比）
- `body_site`、`capture_date`（部位 + 拍摄日期）
- `visual_analysis_json`（轻量视觉分析结果）
- `analysis_status`（pending/analyzing/light_done/failed）
- `vasi_assessment_id`（关联深度 VASI）
- 配套 `ensure_post_image_columns()` 迁移函数（ALTER TABLE，仿 `ensure_diary_columns`），在 main.py 启动调用

### 2. Post 加字段
- `ai_summary`（AI 摘要，列表/卡片展示用）
- `ai_extracted_json`（完整提取结果：心情/睡眠/用药/压力/患处，存 JSON）
- 配套 `ensure_post_columns()` 迁移函数

### 3. 新建 `services/post_ai.py`（复用 diary_ai / diary_image 核心）
- `extract_post_structure(post_id)`：复用 `diary_ai._call_llm_extraction` + `EXTRACTION_PROMPT`，操作 Post（写 ai_summary/ai_extracted_json）+ 同步 TreatmentEvent
- `analyze_post_images_async(post_id)`：复用 `diary_image.analyze_light`，遍历该帖 PostImage 逐张分析，写 visual_analysis_json
- 不改 diary_ai/diary_image 原文件（迁移期保留兼容）

### 4. 发帖触发 AI（`api/community.py` create_post）
在现有 `moderate_post` 线程旁（~L285），仿 diary.py 的双线程模式，加：
- `extract_post_structure(post.id)` daemon 线程
- `analyze_post_images_async(post.id)` daemon 线程
- **所有帖子都触发**（按你的选择）

### 5. CommunityService.create_post / update_post 支持图片元信息
- `image_urls: List[str]` → 新增 `image_metas: List[{url, body_site, capture_date}]` 参数
- PostImage 创建时写入 body_site/capture_date/user_id
- update_post 重建图片时同步
- `models/community.py` 的 PostImageModel/PostCreate schema 同步加字段

### 6. 报告数据源改造（`services/skin_report.py`）
- `generate_comparison_report` 的 `image_ids` 从 DiaryImage.id **改为 PostImage.id**
- `_build_points` 从查 DiaryImage 改为查 PostImage（含 visual_analysis_json/vasi_assessment_id）
- 趋势计算/指标/LLM 叙事/海报逻辑**全部不变**
- 源数据上下文 `_collect_diary_context` 改为查该用户相关 Post（私密帖的文字+提取结果）

### 7. 数据迁移脚本 `scripts/migrate_diary_to_posts.py`
- 遍历 194 条 DiaryEntry → 创建 Post（is_private=true，category=白白日记，content=raw_text，mood 映射，diary_date=entry_date，ai_summary/ai_extracted_json 迁移）
- 遍历 DiaryImage → 创建 PostImage（关联新 Post，迁 visual_analysis_json/body_site/capture_date）
- 幂等：用 DiaryEntry.post_id（已预留外键）避免重复迁移
- 迁移后校验数量
